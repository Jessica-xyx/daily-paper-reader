## 摘要
LLM智能体越来越多地在多个会话中维护个人记忆，但这些记忆可能相互冲突。偏好取决于上下文，行为会演变，来源也可能相互矛盾。当查询缺乏上下文、时间或来源权威来解释冲突时，将某一条记忆视为确定无疑的，会把未解决的冲突转化为不合理的、过度自信的行动。现有的基准测试从相互矛盾的证据中恢复出一个答案，却忽略了智能体是否能够识别欠定性、保留备选方案、寻求缺失信息并选择适当的行动。我们引入了\textsc{TANGLE}——一个针对真正无法解决的记忆冲突的基准，其全称是\underline{T}esting \underline{A}gents' \underline{N}avigation of \underline{G}enuine, \underline{L}atent, and \underline{E}ntangled Memory Conflicts。它包含40个角色和三种类型共541个实例：上下文分区冲突（CPC）、行为振荡冲突（BOC）和来源矛盾冲突（SCC）。我们评估了两种设置——一种有精选记忆的oracle设置，一种从多会话对话中提取记忆的pipeline设置——在五个维度上：冲突感知、因果推理、置信度校准、澄清寻求和记忆忠实度。实验揭示了pipeline的挑战。在精选记忆下，模型识别冲突比校准行动或寻求针对性澄清更为可靠。在端到端的pipeline记忆中，提取过程无法保留下游推理所需的承载冲突的关系。策略比较表明，当行动必须反映冲突时，固定规则是不够的。这些发现推动了冲突感知行动策略（CAAP）的产生，该策略利用可用证据使行动适应每种冲突。\textsc{TANGLE}将冲突处理定义为识别欠定性、保留相互矛盾的证据，并在不强制给出确定性答案的情况下采取行动。

## Abstract
LLM agents increasingly maintain personal memory across sessions, but it can conflict. Preferences depend on context, behavior evolves, and sources can conflict. When a query lacks context, time, or source authority to interpret conflict, treating one memory as definitive converts unresolved conflict into an unjustified, overconfident action. Existing benchmarks recover one answer from conflicting evidence, overlooking whether agents recognize underdetermination, preserve alternatives, seek missing information, and choose appropriate actions. We introduce \underline{T}esting \underline{A}gents' \underline{N}avigation of \underline{G}enuine, \underline{L}atent, and \underline{E}ntangled Memory Conflicts (\textsc{TANGLE}), a benchmark for genuinely unresolvable memory conflicts. It comprises 541 instances across 40 personas and three types: Context-Partitioned Conflict (CPC), Behavior-Oscillation Conflict (BOC), and Source-Contradiction Conflict (SCC). We evaluate two tracks---an oracle track with curated memory and a pipeline track that extracts memory from multi-session dialogues---on five dimensions: conflict perception, causal reasoning, confidence calibration, clarification seeking, and memory faithfulness. Experiments reveal pipeline challenges. With curated memory, models recognize conflicts more reliably than they calibrate actions or seek targeted clarification. With end-to-end pipeline memory, extraction fails to preserve conflict-bearing relations needed for downstream reasoning. Policy comparisons show fixed rules are insufficient when actions must reflect conflict. These findings motivate Conflict-Aware Action Policy (CAAP), which adapts actions to each conflict using available evidence. \textsc{TANGLE} frames conflict handling as recognizing underdetermination, retaining conflicting evidence, and acting without forcing a definitive answer.

## 1. 论文的核心问题与整体含义

### 研究动机与背景

LLM智能体正从无状态的助手演变为跨会话维护**持久个人记忆**的系统。记忆的增加带来了一个新的可靠性问题：**记忆并非总是一致的**。

- 个人偏好依赖于上下文（同一个偏好在不同场景下适用性不同）；
- 用户行为随时间演变，可能长期处于非收敛的振荡状态；
- 来自不同来源的信息（如自述、行为推断、官方记录）可能相互矛盾。

当查询**未提供**解析冲突所需的上下文、时间锚点或来源权威性时，记忆库本身**不支持唯一正确答案**。此时，如果智能体将某一条记忆视为"确定答案"，就会产生**过度自信或不恰当的行动**。

### 现有基准的缺陷

论文指出现有记忆冲突基准的两大局限：

1. **单答案恢复范式**：将冲突建模为"可恢复唯一答案"的问题（如时间最近性、多数投票），鼓励模型将冲突强行压缩为一个值，而不是识别欠定性。
2. **单轨评估设计**：不分隔"记忆提取"与"冲突推理"，导致失败溯源不清晰——无法判断是证据缺失还是推理失败。

### 核心论点

> 冲突处理不是"解决冲突"，而是**识别欠定性（underdetermination）、保留冲突证据、在未确认前选择恰当行动**。

## 2. 方法论

### 2.1 问题形式化

- 设记忆库 $M = \{m_1, \dots, m_n\}$（含冲突承载记忆，n为记忆条目数）加上同域干扰记忆 $D = \{d_1, \dots, d_k\}$；
- 给定用户查询 $q$（不指明当前相关变量），智能体产生响应 $r$。
- **Oracle轨道**：$r = f(M \cup D, q)$，模型直接接收精选记忆。
- **Pipeline轨道**：$r = f(\hat{M}, q)$，其中 $\hat{M} = g(S)$，$g$ 为记忆提取系统，$S = (s_1, \dots, s_T)$ 为多会话对话历史。

### 2.2 冲突分类学（TANGLE核心结构）

| 冲突类型 | 缩写 | 实例数 | 潜在变量 | 数学刻画 |
|---|---|---|---|---|
| **上下文分区冲突** | CPC | 193 | 未观测上下文 $c$ | $m_i$ 成立当且仅当 $c \in C_i$，且 $\{C_i\}$ 不相交 |
| **行为振荡冲突** | BOC | 121 | 振荡相位 $z_t$ | 轨迹 $v_{t_1}, v_{t_2}, \dots$ 非收敛（反复逆转、部分保留、幅度漂移） |
| **来源矛盾冲突** | SCC | 227 | 来源可靠性 $w(s)$ | $v_j \ne v_k$（不同来源对同一方面报告冲突值） |

### 2.3 数据构造

- **角色−方面本体**：基于Persona Hub种子，筛选40个多样角色（年龄、职业、收入、家庭结构、健康、地域）；每个角色只映射13–15个相关生命方面（共46个方面，覆盖10个领域）；
- **实例生成**：约束式生成器产出6–8条冲突记忆 + 1–2条中性背景记忆 + 自然查询；记忆为第三人称情景陈述（18–32词）；两条完整性约束：非泄漏规则（单条记忆不得直接说出结论）+ 模式平衡（冲突子类型分布多样化）；
- **查询设计**：CPC隐藏上下文变量；BOC/SCC使用开放式委托请求（不含时间锚点或显式冲突线索）；
- **Pipeline对话**：用Claude Sonnet 4.6将同一组记忆转化为10–18个月的多会话对话（平均64.5个会话/角色，约48K tokens/角色），冲突记忆分散在不同会话，夹杂干扰会话。

### 2.4 评分标准（D1–D5 + D6）

| 维度 | 名称 | 评估内容 |
|---|---|---|
| D1 | 冲突感知 | 是否识别并表达记忆中的矛盾 |
| D2 | 因果推理 | 是否基于具体记忆证据进行因果/来源可靠性分析 |
| D3 | 置信度校准 | 置信度是否与证据强度匹配（条件化vs过度承诺） |
| D4 | 澄清寻求 | 信息寻求是否指向未解决的核心变量 |
| D5 | 记忆忠实度 | 事实声明能否溯源到记忆库、无捏造 |
| D6（附加） | 承诺适当性 | 62个高风险SCC实例（医疗、授权领域）的三元安全旗标（安全/部分/不安全），不计入总分 |

每个维度独立评分（0–4），不同冲突类型有对应的评分锚点。

### 2.5 冲突感知行动策略（CAAP）

两阶段策略：
1. **决策阶段** $\pi^{dec}_\theta$：输出内部决策记录 $z$（什么不确定、缺什么信息），选择动作 $a \in \mathcal{A}$；
2. **实现阶段** $\pi^{real}_\theta$：基于可见记忆、查询和选定动作生成最终响应。

动作空间：$\mathcal{A} = \{commit, conditionalize, clarify, verify, defer, reversible\_trial\}$。
原则：选择证据能支撑的**最不谨慎**动作，错误后果严重时提高谨慎级别。

## 6. 主要结论与发现

1. **识别−行动差距（Recognition-to-Action Gap）**
   - 即使在完整oracle记忆下，最强模型总分不足15/20；
   - 模型识别冲突（D1）和记忆忠实度（D5）较强，但置信度校准（D3）与澄清寻求（D4）最弱——D4是**所有模型**的瓶颈；
   - BOC中此差距最明显：D5为3.52–3.55，D3仅0.65–1.03，D4仅0.65–0.69。

2. **冲突结构决定难度**
   - CPC最容易（14.79/14.96），SCC中等（11.92/11.58），BOC最难（10.81/10.14）——BOC要求推断时间稳定性，而不是在竞争命题中做选择。

3. **记忆提取是pipeline的主要瓶颈**
   - Letta完整保留目标冲突的比例为91.7%，Mem0为69.1%，A-mem为47.0%，MemOS为46.2%；
   - 部分检索（PARTIAL）保留了答案相关内容，但**破坏了决定内容解释方式的关系**（如BOC的相位轨迹、CPC的上下文分区、SCC的来源归属）；
   - 当冲突结构完整时，各系统下游D1/D2差异较小——bottleneck在记忆构建，而非推理。

4. **干扰记忆造成累积损害**
   - 从N=0到N=6，总平均分从13.26降至12.63（GPT-5.4评判）；13.35→12.48（Opus）；
   - D1（感知）受影响较小，D2–D4（推理、校准、澄清）下降更大——噪声削弱的是**检测后的推理**而非初始感知；
   - CPC受影响最明显。

5. **固定策略结构性失败**
   - 严格最近性/多数投票/固定来源优先级在每条实例上都强行提交一个值；
   - 多数投票在CPC中28.0%平局，71.5%的案例优势不超过1票；
   - 词汇检测器召回率仅0.181，无法捕捉时间、上下文或来源依赖的冲突；
   - "仅提问"和"仅条件化"虽避免了承诺，但缺少对冲突的解释。

6. **CAAP的有效性**
   - Sonnet 5：总分提升2.01（14.37→16.38），D3大幅改善（1.85→2.60），D4改善（1.12→1.75）；
   - GPT-4o：D3/D4/D5均提升，总分+1.16；
   - Gemini 3.1 Pro：D3改善但D4下降，总分变化不大（+0.23）；
   - CAAP的动作分布随冲突类型分化：BOC倾向reversible_trial（Sonnet 5达68%），CPC倾向conditionalize/clarify，SCC倾向verify；
   - 结论：CAAP是**正向基线而非上界**——收益取决于底层模型对选定动作的可靠实现。

## 7. 优点与亮点

1. **问题定义创新**：将冲突处理从"恢复唯一答案"转向"在欠定性下认知行为评估"，更贴近真实应用的安全性需求；
2. **双轨道设计**：oracle vs. pipeline清晰隔离记忆构建与冲突推理的失败源，是方法论上的重要改进；
3. **细粒度多维度评分**：D1–D5五维度独立评分，可精确诊断模型在哪一环节失效，而非单一正确率；
4. **冲突分类学丰富**：三种冲突类型下覆盖17种CPC上下文分区、8种BOC振荡形状、10种SCC来源矛盾类型，结构多样性高；
5. **严格的非泄漏约束**：记忆生成和查询设计遵循非泄漏规则，确保冲突只能从聚合证据中重构；
6. **角色生态真实**：40个多元角色（含慢性病、残疾、移民、看护者等）覆盖广泛生活处境，冲突设定有生态效度；
7. **双评判者独立报告**：避免单一LLM评判者的偏差，且提供人工标注可靠性验证；
8. **CAAP策略推荐**：提供了超越固定规则的可操作性策略，动作空间设计合理。

## 8. 不足与局限

1. **评估模型均为2026年时的前沿模型**，非公开/不可复现的闭源API模型，实验可再现性受限；
2. **LLM评判者的固有偏差**：尽管双评判者一致性较高（r=0.838），但两者均由LLM构成，可能共享系统偏差；BOC维度评判分歧较大（附录I案例显示对同一响应GPT-5.4评8分、Opus评9分或11分 vs 7分）；
3. **CAAP有效性依赖底层模型的实现可靠性**：Gemini 3.1 Pro的D4反而下降，说明策略分层并不能完全克服模型本身的弱点；
4. **BOC从根本上最难**，但模型最高仅约10–11/20分，且CAAP对BOC的提升仍然有限——时间模式重构仍是开放挑战；
5. **干扰项实验规模较小**（60实例），且干扰项数量仅到N=6，未测试更高噪声水平；
6. **缺少真实用户数据的验证**：所有数据均为合成生成，尽管有

6. **缺少真实用户数据的验证**：所有数据均为合成生成，尽管有Persona Hub角色库支撑和生态效度设计，但仍无法完全替代真实用户长期记忆场景中的噪声、不一致性和隐私约束；

7. **角色数量偏少**：40个角色虽覆盖多元人口特征，但相对真实世界偏好空间的巨大维度仍显不足，基于此的分类学普适性有待更大规模验证；

8. **记忆提取系统版本锁定**：Letta、Mem0等开源记忆系统迭代迅速，本次测评结果仅反映论文写作时特定版本的性能，不能代表系统长期演进后的状态；

9. **记忆库规模与现实差距**：每个角色约48K tokens的多会话历史对现代LLM上下文窗口而言仍属"中等规模"，真实用户跨越数年的记忆体量可能达到数百万tokens，记忆提取与冲突管理面临的可扩展性问题未被触及；

10. **时间尺度局限**：冲突对话模拟控制在10–18个月内，对于BOC这类需要长期观测的行为振荡，更长时间跨度（数年）下的模式稳定性与漂移尚未被探索；

11. **未见对动作效用（action utility）的直接建模**：CAAP选择动作但并未显式建模不同动作（如ask vs. trial）对真实用户满意度的长期后果，评估仍以单次响应质量为主。

## 9. 开放问题与未来方向

1. **记忆蒸馏与冲突保留的平衡**：如何在记忆压缩/遗忘过程中仍然保留支撑欠定性判断的结构化冲突证据，是不与现有记忆系统冲突的核心挑战；
2. **主动记忆维护（proactive memory maintenance）**：当前智能体只能被动应对查询，未来应研究在对话间隙主动识别、记录和向用户澄清冲突的机制；
3. **策略-实现两阶段架构的通用化**：CAAP的分层思想是否可推广到其他欠定性场景（如医疗决策、法律推理），以及如何设计更好的实现阶段监督；
4. **多轮澄清中的记忆更新**：当用户澄清后，智能体应在何处更新记忆、如何保留冲突历史的同时收敛到用户当前偏好；
5. **跨语言与跨文化冲突**：当前数据集为英文，不同文化背景下的冲突表达与处理规范可能显著不同；
6. **可解释审计**：在安全敏感场景（医疗、授权），智能体如何在记忆检索和决策链条上提供可审计的证据追踪。

## 10. 总体批评性评估

### 10.1 贡献评级

从问题定义（重构欠定性）、方法论（双轨道+多维评分）、数据资产（可复现的541实例基准）、实践洞察（识别−行动差距与记忆构建瓶颈）四个维度来看，本文构成该方向一次**基础性贡献**。它第一次将哲学认识论中的"欠定性"概念引入LLM记忆评估，并给出了可操作的评分与策略框架。

### 10.2 核心短板

本文最大的瓶颈在于**评估本身依赖不可复现的黑箱模型**。响应模型与评判模型全部为闭源API（且版本标识如"GPT-5.4"、"Claude Sonnet 5"在以往惯例中属于前沿模型命名），研究者无法确认这些模型在论文时的实际能力水准与后续变化，这降低了结果在社区内被独立复现验证的可能性。其次，合成数据虽然设计精巧，但与真实用户记忆的差距从未被定量标定。

### 10.3 一句话总结

> **本文不是在问"模型能否在冲突记忆中找回正确答案"，而是在问"模型能否在不存在唯一正确答案时仍保持诚实、谨慎与有用"——在这个问题上，它提出了目前最系统的评估框架，也诚实地展示了所有前沿模型都远未合格。**
