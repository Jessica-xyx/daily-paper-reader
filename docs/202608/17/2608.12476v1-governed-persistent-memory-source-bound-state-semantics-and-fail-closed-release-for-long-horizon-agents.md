## 摘要
长期智能体记忆通常被视为“选择-存储-检索”，但检索本身并不决定矛盾、被取代、被撤回、被删除或过时的记录是否可能支持对外声明。我们引入受管持久记忆（GPM），一种可审计的双时态状态转换模型，具有源绑定准入、派生生命周期状态、当前公共屏障以及故障关闭的结构化释放。五条可执行条款涵盖了账本完整性、源绑定、冲突隔离、撤回或删除后的不复活，以及在经过验证的单一头部上基于新视图的精确声明闭合。在预先指定的哈希冻结的3,600案例GPM-ReleaseBench上，GPM匹配所有完整结果；三个故意简化的完整策略中最强者匹配1,800/3,600，并在50%的违规案例上做出不匹配的释放。一次独立的密封端到端服务评估在八个查询族上进行了实际摄取与释放。在其公开披露的V3分支中，受管通道在2,400/2,400聚类上正确，而未经受管的本地Qwen2.5-7B为600/2,400；它修复了全部1,800个基线失败且无回归（单侧95%下限分别为99.875%和99.834%）。后续的V5重新密封（覆盖中文和英文命令分支，固定生成日期，且冻结后无归约器修订）再次在每个分支上获得2,400/2,400。一个独立于生产代码的有限模型探索了331,776个语义状态和1,990,656个查询状态，未发现全契约反例；100,000条轨迹的三引擎差分产生零不匹配。这些是有界的契约与实现结果，而非开放世界模型准确性或世界真实性的证据。密封服务评估中的受管答案是确定性服务输出；7B结果是未受管对照，并非声称语言模型本身变得完全准确。

## Abstract
Long-term agent memory is usually treated as select--store--retrieve, but retrieval does not decide whether contradictory, superseded, retracted, deleted, or stale records may support an outgoing claim. We introduce Governed Persistent Memory (GPM), an auditable bitemporal state-transition model with source-bound admission, derived lifecycle state, current public barriers, and fail-closed structured release. Five executable clauses cover ledger integrity, source binding, conflict isolation, non-revival after retraction or deletion, and exact claim closure over a fresh view at one verified head.   On a prespecified hash-frozen 3,600-case GPM-ReleaseBench, GPM matches all complete outcomes; the strongest of three intentionally simple complete policies matches 1,800/3,600 and makes unmatched releases on 50% of violation cases. A separate sealed end-to-end service evaluation exercises real ingestion and release across eight query families. In its publicly disclosed V3 arm, the governed lane is correct on 2,400/2,400 clusters versus 600/2,400 for ungoverned local Qwen2.5-7B; it repairs all 1,800 baseline failures with no regression (one-sided 95% lower bounds 99.875% and 99.834%). A later V5 reseal over Chinese- and English-command arms, with generation-date pinning and no post-freeze reducer amendment, again obtains 2,400/2,400 per arm. A production-code-independent finite model explores 331,776 semantic and 1,990,656 query states without a full-contract counterexample, and a 100,000-trace three-engine differential yields zero mismatches.   These are bounded contract and implementation results, not open-world model accuracy or evidence of world truth. Governed answers in the sealed service evaluation are deterministic service outputs; the 7B result is the ungoverned comparison, not a claim that a language model itself became perfectly accurate.

## 1. 核心问题与整体含义

- **研究动机**：长期智能体记忆通常被简单视为“选择—存储—检索”，但检索本身并不能判断一条候选记录是否因矛盾、被取代、撤回、删除或过期而无法用于支持对外声明。一个提取错误可能被反复召回、总结、写回，最终“固化”为看似稳定的历史，导致错误随时间传播。
- **核心问题**：持久记忆在何种状态语义下才允许支持一个对外声明？论文提出，需要把“可检索”和“可公开断言”严格区分开。
- **整体含义**：作者提出 **受管持久记忆（Governed Persistent Memory, GPM）**，一个可审计的双时态状态转换模型，通过源绑定准入、派生生命周期状态、当前公共屏障以及故障关闭的结构化发布机制，确保对外声明只基于一致、有效且经过验证的记忆状态。

## 2. 方法论

### 核心思想
- 将记忆流程拆分为外部源获取、认证事件注册、可选声明准入、追加式账本、公共投影、候选排序、不可信声明提出、本地结构化释放决策等阶段。
- 检索只负责排序，不能决定公共可断言性；只有通过了契约检查的声明才能被释放。

### 关键技术细节
- **事件账本**：事件 $e_i$ 包含序列号、事务时间 $\tau_i$、有效时间 $t_i$、类型、负载、前一哈希 $h_{i-1}$ 和自哈希 $h_i$，形成链式哈希账本；事务时间必须非递减，指数可注入但与权威段分离并接受审计。
- **声明模型**：声明包含用户、事实标识、实体、属性、值、有效区间、事务时间、来源证明、被取代事实、支持标签。生命周期状态由事件派生，而非由调用方自由指定。
- **事件类型**：`episode.add`、`fact.quarantine`、`fact.assert`、`fact.retract`、`user.delete`，分别对应源剧集追加、失败准入隔离、源绑定断言、撤回、用户删除屏障。
- **五个可执行条款 I1–I5**：
  - **I1 账本完整性**：序列、前驱、哈希、段库存和索引分片承诺一致。
  - **I2 语法源绑定**：每个公共事实必须有直接、同用户的源字节证据；推断事实被隔离；但 I2 不保证语义蕴含。
  - **I3 冲突隔离**：未解决冲突的双活跃声明不能同时作为公共事实出现。
  - **I4 公共不复活**：当前头部下的撤回和删除策略即使在请求历史前缀时也生效，被撤回/删除的事实及其绑定剧集不能通过历史读取、旧索引或物化投影复活。
  - **I5 结构化释放闭合**：每个释放的结构化答案声明必须精确匹配新公共视图中的可断言事实，并提供非空且匹配的源事实标识集合。
- **释放门协议**：先读取已验证头部 $h_b$，构造新视图 $V_b = V_{pub}(u,t,\tau;h_b)$，检查每个结构化声明 $a$ 的绑定（要求来源 ID 非空且落在匹配该归一化事实的公共事实集合内），计算声明多重集摘要 $D_A = H(\text{canon}(\gamma(A)))$，再重读头部 $h_a$。只有 $h_a = h_b$ 且声明集非空且全部绑定才发布；$h_b \neq h_a$ 时错误并返回无记录；否则弃权。
- 本地决策记录绑定声明显式多重集、策略和归一化器版本、用户、查询哈希、快照和已验证头部；验证者会拒绝头部过期的记录。

## 7. 局限性与有效性威胁

- **基准自研风险**：GPM-ReleaseBench 与 Governed-QA Sealed 均由本项目自行设计，无独立第三方标注；隐藏集虽采用哈希冻结与 AES-256-GCM 密封，但内容仍是作者定义的合成样例，可能隐含设计者自身的契约直觉。
- **对比基线过弱**：对标的是"故意简单的完整策略"（Raw append、Latest-first、Flat conflict-preserving），而非 Mem0、MemGPT、MemOS、TOKI、MemIR、MemoRepair 等实际部署的完整记忆系统。StateFuse 仅在共享契约子集上比较，无法覆盖完整管道的差异。
- **外部有效性证据不足**：LongMemEval 作为干净任务控制两次因语义判断门失败而被降级为描述性负面证据，意味着在真实自然语言任务上的整体准确性没有得到正面验证。
- **缺少人类评估**：全流程无人类标注或人工可接受性审查，结构化释放匹配可能漏掉真实用户对相关性、语气与可信度的直觉。
- **性能与部署场景单薄**：性能测试仅在单机 Windows/Node.js 环境完成，未涉及分布式部署、并发写入、多租户隔离、审计日志长期归档等生产约束。

## 8. 对领域的启示与未来工作

- **理论启示**：将"可检索"与"可公开断言"分离，用双时态事件账本派生声明生命周期，为长时程智能体记忆提供了形式化、可审计的状态语义框架，直接回应了"错误记忆反复回捞、固化"这一被长期忽视的故障模式。
- **工程启示**：释放门协议以"读取已验证头部→构造视图→绑定检查→重读头部"的乐观并发校验，把来源绑定从提示词层面的"软约束"变成了可验证的"硬契约"；这种思路可以迁移到工具调用结果缓存、多智能体共享记忆等场景。
- **未来方向**：与主流记忆系统（Mem0、MemGPT 等）做对抗性比较；引入人类标注与真实世界长时对话数据；将源绑定语义扩展到多模态记忆与跨语言语用；探索分布式环境下的账本一致性与审计性能。

## 9. 总体评价

- **在自定边界内证据链极其严密**：密码密封的隐藏集、331,776 状态全枚举、六守卫突变反例、三实现 100,000 轨迹差分、1,800 个反事实修复且 0 回归——这种"正确性工程"式的严谨性在记忆系统文献中罕见。
