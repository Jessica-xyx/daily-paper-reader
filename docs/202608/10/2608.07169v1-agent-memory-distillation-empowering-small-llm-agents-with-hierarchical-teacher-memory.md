## 摘要
记忆系统在提升代理性能方面已显示出潜力，但其潜力对于小型语言模型而言仍 largely unexplored，这些模型难以自行生成足够多的成功轨迹。我们提出代理记忆蒸馏（AMD），一种无需训练的训练-free框架，通过层级记忆将结构化知识从大型教师代理迁移至小型学生代理。AMD从成功的教师轨迹中构建三种互补的记忆类型：工作流记忆编码任务级策略，子任务记忆提供中间粒度的具体行为示例，函数记忆捕获每个函数的调用约定和常见陷阱。工作流记忆和子任务记忆在每个任务开始时主动注入，而函数记忆则在工具调用错误时被动检索。我们使用四个学生模型（4B-8B参数）在三个工具使用基准上评估了AMD，以GPT-5-mini作为教师，在AppWorld、BFCL V3和ToolSandbox上分别实现了27.2个百分点、11.2个百分点和3.4个百分点的平均准确率提升，并且始终优于现有的基于记忆的基线。进一步分析表明，子任务记忆贡献了最大的提升，教师有效性取决于教师能力和学生兼容性，4B规模的学生从AMD中获益最多。

## Abstract
Memory systems have shown promise for improving agent performance, but their potential remains largely unexplored for small language models, which struggle to generate sufficient successful trajectories on their own. We propose Agent Memory Distillation (AMD), a training-free framework that transfers structured knowledge from a large teacher agent to a small student agent through hierarchical memory. AMD constructs three complementary memory types from successful teacher trajectories: Workflow memory encodes task-level strategies, Subtask memory provides concrete behavioral examples at an intermediate granularity, and Function memory captures per-function calling conventions and common pitfalls. Workflow and Subtask memories are injected proactively at the start of each task, while Function memory is retrieved reactively upon tool-calling errors. We evaluate AMD on three tool-use benchmarks using four student models (4B-8B parameters) with GPT-5-mini as the teacher, achieving average accuracy gains of 27.2%p, 11.2%p, and 3.4%p on AppWorld, BFCL V3, and ToolSandbox, while consistently outperforming existing memory-based baselines. Further analysis shows that Subtask memory contributes the largest gains, teacher effectiveness depends on both teacher capability and student compatibility, and 4B-sized students benefit most from AMD.

## 2. 论文提出的方法论

### 核心思想
作者提出 **Agent Memory Distillation (AMD)**——一个 **无需训练（training-free）** 的框架。核心思路是**将教师智能体的成功经验转化为三层互补的层级记忆**，以与学生模型的容量和认知能力对齐，使教师知识对小模型“可访问”。

### 三层记忆结构

**① Workflow Memory（工作流记忆）——任务级策略**
- 从成功教师轨迹中提炼一段自然语言的高层任务完成策略。
- 内容涵盖：涉及的应用和工具、关键前提条件、决策规则、验证线索和常见失败模式。
- 具体动态输入值（如ID、凭据、路径）会被替换为类型化占位符（如 `<ID>`、`<EMAIL>`），确保对新任务的可迁移性。
- **注入方式**：任务开始时主动注入系统提示。

**② Subtask Memory（子任务记忆）——中间粒度行为示例**
- 每条教师轨迹被分解为一系列语义连贯的子任务片段（如“认证服务”“批量审批”），每个片段包含具体的可执行工具调用/代码、对应观察结果、简短标签和描述。
- 为学生提供“中间层”的参考范例——比任务计划具体，比单次函数调用宏观。
- **注入方式**：学生模型先将任务指令分解为至多6个子任务标签，以此检索最匹配的子任务片段，与工作流记忆一起在任务开始时主动注入系统提示。

**③ Function Memory（函数记忆）——细粒度工具调用知识**
- 从成功轨迹中提取每个函数的具体调用示例，包括：函数名、实际调用代码、上下文（解释调用原因）、返回观察结果（如有），以及API文档/参数/响应模式。
- **注入方式**：**被动/反应式注入**——仅在工具调用出错时，根据失败函数名称检索并附加到错误消息中，提供即时纠正指导，不在正常执行时占用上下文。

### 检索机制
- 所有记忆条目使用 OpenAI 的 `text-embedding-3-small` 预编码，通过余弦相似度检索。
- 低于最小相似度阈值（δ）的候选被丢弃；主实验中 k=1。
- 子任务记忆检索中实施去重，避免重复注入。

### 关键算法流程（文字描述）
1. **任务开始前**：用任务指令查询工作流记忆库，将最佳工作流提示词注入系统提示。
2. **任务开始前**：学生模型将任务分解为至多6个子任务标签；每个标签独立检索子任务记忆，查重后注入系统提示。
3. **执行循环**：若上一步返回错误，从错误信息中提取失败函数名，查询函数记忆库，将匹配的教师示例附加到上下文；否则按正常流程生成工具调用。
4. 循环迭代至任务完成或达到最大步骤（40步）为止。

## 6. 论文的主要结论与发现

1. **AMD 显著且一致地优于所有基线**：在 AppWorld、BFCL V3、ToolSandbox 上平均提升 27.2%p、11.2%p、3.4%p（相对零样本），并在所有模型和基准组合下超越 ReasoningBank、MemP、SASM。
2. **小模型可达到甚至超越教师水平**：Gemma4-E4B（54.17%）和 Qwen3-8B（51.79%）在 AppWorld 上超越 GPT-5-mini（50.00%）；Gemma4-E4B 和 Qwen3-8B 的跨基准平均值也超过教师——说明AMD蒸馏的是可迁移的决策模式，而非单纯的模仿。
3. **子任务记忆（Subtask memory）贡献最大**：在 AppWorld 上，将 ST 加入 WF 带来高达 +25.0%p 的增量，是三层记忆中最关键的组件。
4. **教师有效性取决于教师能力与学生兼容性的双重因素**：对8B学生，教师准确率是可靠预测因子；对4B学生，中等能力的GPT-5-mini 反而优于更高准确率的 DeepSeek V4 Pro，说明知识呈现形式与学生理解能力之间的匹配更为关键。
5. **4B规模学生获益最大**：准确率增益峰值出现在4B（+34.52%p）；1.7B受能力限制吸收有限，8B/14B已接近教师水平、增益空间变小。
6. **k=1 的精确检索优于多记忆注入**：增加检索数量会引入噪声，对小模型造成干扰，尤其在子任务记忆上（精度从 49.40% 单调降至 33.34%）。
7. **最优记忆表示因层级而异**：高层规划知识用自然语言最优（49.40% vs. 44.05%），低层执行知识用具体代码最优（49.40% vs. 23.21%）。
8. **AMD 提升交互效率**：显著减少学生完成任务所需步数，使其轨迹更接近教师的效率水平。

## 7. 优点

1. **问题识别精准**：论文系统性地指出了“朴素教师记忆迁移对小模型无效”这一被忽略的问题，并给出清晰的能力差距分析。

3. **层级记忆结构具有原则性**：将任务级、子任务级、函数级三种粒度有机整合，对应规划、执行、纠错三种能力维度，设计逻辑清晰且动机充分。
4. **主动注入与被动检索的混合策略**：规划与参考知识预先注入，错误纠正按需触发——在提供有效指导的同时避免持续膨胀上下文，兼顾效果与效率。
5. **对记忆表示形式的深入探讨**：不同粒度信息采用不同表示（自然语言 vs. 代码），而非一刀切，这种“表示对齐”视角具有较强的启发性。
6. **实验严谨而全面**：包含消融分析、教师/学生规模效应、鲁棒性验证（跨分割/自排除/重复运行）、定性与定量双重佐证。
7. **异常发现如实报告**：教师能力与学生增益不一致（4B学生受益于中等教师）、LLaMA3.1-8B加Function记忆反而下降等现象均被记录并给出了合理分析。

## 8. 不足与局限

1. **评估范围受限**：仅在基于文本的工具使用基准上验证（Python API调用、结构化函数调用），未覆盖多模态环境（如视觉引导操作）、开放式代码生成任务等更复杂的智能体场景。
2. **记忆静态化**：记忆在离线阶段固定构建，推理过程中保持冻结，无法纳入学生在测试时的新成功/失败经验，也无法适应教师演示与学生实际遇到任务之间的分布偏移。
3. **教师选择问题悬而未决**：教师能力与学生兼容性之间的平衡关系在文中被确认但未解决——如何自动选择最优教师仍是开放问题。
