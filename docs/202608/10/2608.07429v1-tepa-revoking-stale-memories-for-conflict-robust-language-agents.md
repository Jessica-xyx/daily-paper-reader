## 摘要
长期记忆使语言智能体能够复用过去的事实、偏好和任务经验。持久性也带来了一个核心的可证伪性问题：当世界发生变化时，过时的记忆可能仍然可检索并污染提示。我们将这种失败模式表征为记忆污染：由较新的冲突证据已被取代的活跃记忆引起的退化。我们引入了TEPA，一种可撤销的证据-记忆机制，使有效性成为记忆的显式状态。TEPA将观察表示为带键的先例，并在新证据在同一键下与活跃先例冲突时撤销它们，从而允许检索从当前证据中提取，同时保留已撤销的历史以供审计。在受控的隐藏机制漂移、真实的文件支持的可执行漂移以及偏好更新流中，撤销防止过时的活跃记忆在反转后保留在检索集中。在50个种子的受控漂移中，仅追加和最后写入获胜的记忆在完全反转期间降至无记忆以下（仅追加和最后写入获胜均为0.210，无记忆为0.309，TEPA为0.950），相同的模式在实际文件执行下重现（仅追加为0.203，无记忆为0.298，TEPA为0.950）。在干净的MemoryAgentBench SH-6k上，TEPA匹配强大的最后写入获胜缓存，确认当前键替换是单跳事实整合的决定性操作。在多跳和超长上下文MemoryAgentBench设置上的边界测试暴露了超越事实级有效性跟踪的检索链和上下文选择瓶颈。总之，这些结果确立了生命周期撤销作为智能体必须证伪、审计和随后重新提升演化知识的核心记忆操作。

## Abstract
Long-term memory enables language agents to reuse past facts, preferences, and task experience. Persistence also creates a central falsifiability problem: when the world changes, stale memories can remain retrievable and pollute the prompt. We characterize this failure mode as memory pollution: degradation caused by active memories that newer conflicting evidence has superseded. We introduce TEPA, a revocable evidence-memory mechanism that makes validity an explicit state of memory. TEPA represents observations as keyed precedents and revokes active precedents when fresh evidence contradicts them under the same key, allowing retrieval to draw from current evidence while preserving revoked history for audit. Across controlled hidden-regime drift, real file-backed executable drift, and preference-update streams, revocation prevents stale active memory from remaining in the retrieval set after reversal. In controlled drift over 50 seeds, append-only and last-write-wins memory fell below no memory during full reversal (append-only and last-write-wins both 0.210, no memory 0.309, TEPA 0.950), and the same pattern reproduced under real file execution (append-only 0.203, no memory 0.298, TEPA 0.950). On clean MemoryAgentBench SH-6k, TEPA matches a strong last-write-wins cache, confirming that current-key replacement is the decisive operation for single-hop fact consolidation. Boundary tests on multi-hop and very long-context MemoryAgentBench settings expose retrieval-chain and context-selection bottlenecks beyond fact-level validity tracking. Together, these results establish lifecycle revocation as a core memory operation for agents that must falsify, audit, and later re-promote evolving knowledge.

- **问题定义**：论文将这种失败模式命名为**记忆污染（Memory Pollution）**，即“由已被较新冲突证据取代的活跃记忆引起的退化”。传统概念漂移（concept drift）关注的是分类器或分布的变化，而记忆污染在语言智能体中的独特之处在于：过时的记忆是**被插入提示词中的文本证据**。
- **核心矛盾**：持久记忆既有价值（复用经验），也有风险（陈旧证据主导当前交互）。即使一条记忆“相关、近期”并且曾经正确，一旦其值被取代，它依然是错误的——**相关性和有效性是两种不同的维度**。
- **研究意义**：本文首次将“生命周期撤销（lifecycle revocation）”确立为语言智能体记忆系统的一项核心操作，与记忆的写入、检索、遗忘并列，为必须处理不断演化知识的智能体提供了关键的机制基础。

### 2. 论文提出的方法论

#### 2.1 核心思想
- **TEPA**（**T**rial-validated **E**vidence-memory with **P**recedent **A**rchive）是一种可撤销的证据-记忆机制，其核心思想是：**将“有效性（validity）”从记忆的隐含属性提升为显式状态**。
- 记忆不再只是“存在与否”，而是具有完整的生命周期状态：**Hypothesis（候选）→ Active（活跃）→ Revoked（已撤销）**，已撤销的记忆保留在归档中供审计，但不再参与常规检索。

#### 2.2 关键技术细节

**（1）带键先例（Keyed Precedent）表示**
- 每条观测被转换为一个先例：\( p = (k, v, s, f, \sigma, \tau) \)，其中 \( k \) 为冲突键（conflict key），\( v \) 为断言的取值，\( s \) 为支持计数，\( f \) 为冲突计数，\( \sigma \) 为生命周期状态，\( \tau \) 为创建时间。
- 键提取器 \( \kappa(x) \) 和值提取器 \( \nu(x) \) 将证据映射为键值对（如 `capital(france) → "Paris"`）。
- 两条证据冲突的条件为：共享同一键但断言不相容的值。

**（2）生命周期更新规则（Algorithm 1）**
- 当新证据到来时，TEPA 将其与活跃先例中最具相同键的先例比较：
  - 若值**相同** → 支持计数 \( s \) 加一；
  - 若值**不相容** → 冲突计数 \( f \) 加一。
- **撤销条件**（满足其一即撤销）：
  - 后验均值 \( q(p) = \frac{s + \alpha}{s + f + \alpha + \beta} \)（Beta-Bernoulli 模型，\( \alpha = \beta = 1 \)）低于阈值 \( \theta_{rev} \)（默认 0.3），且总观测数 ≥ \( n_{min} = 5 \)；
  - 或同一键下最近结果数 ≥ \( n_{rec} = 3 \) 且近期成功率低于 \( \theta_{rec} = 0.34 \)。
- **提升机制**：当某键-值对积累 ≥ \( \theta_{prop} = 3 \) 个支持后进入 Hypothesis 状态，后验达到 \( \theta_{pro} = 0.6 \) 或通过试验验证后，提升为 Active。

**（3）TEPA-Full 试验验证变体**
- TEPA-Full 增加“先试验再提升”的步骤：在提升候选先例前，由任务执行器在保留任务集 \( H \) 上运行最多 3 次试验（1 次支持任务、1 次反事实任务、1 次污染检查）。至少 60% 试验为正且至少 1 次支持任务成功时才提升。
- 这一变体在偏好更新场景中尤其重要，可防止错误候选被激活。

**（4）理论保证**
- 论文用简洁的风险模型说明了撤销的必要性：若追加式记忆以概率 \( \xi \) 暴露过时值、下游决策以概率 \( \eta \) 遵循过时值，则相对撤销式记忆至少产生 \( \xi\eta \) 的额外 0–1 风险。当过时暴露的损害超过当前证据的收益（\( \xi\eta > b \)）时，追加式记忆必然比无记忆更差——这正是记忆污染的形式化条件。

#### 3.2 对比方法（机制基线）
- **无记忆（No Memory）**：不暴露任何存储证据，度量基础任务难度。

- **最后写入获胜（Last-write-wins）**：每个键只保留最新值（强单跳替换基线）。
- **时间近因（Temporal Recency）**：按时间偏好最新。
- **语义检索（Semantic Retrieval）**：按词汇相关性排序。
- **滑动窗口（Sliding Window）**：只保留固定最近窗口。
- **反应式遗忘（Reactive Forgetting）**：检测到失败后全局重置。
- **冲突感知近因（Conflict-aware Recency）**：仅在检索时折叠同键冲突。
- **Oracle Reset**：知道真实阶段边界（诊断性上界）。

### 6. 论文的主要结论与发现

1. **追加式记忆确实可以劣于无记忆**：在完全反转阶段，追加式和最后写入获胜分别降至 0.210（受控）和 0.203（可执行），显著低于无记忆基线（0.309 / 0.298），产生正的污染指数。
2. **冲突键撤销可以防止这种失败**：TEPA 在受控和可执行环境中均达到 0.950 的完全反转成功率，远高于所有非撤销方法；反应式遗忘（0.796）虽有改善但仍明显落后。
3. **撤销是决定性操作**：TEPA-NoRev 消融后崩溃至 0.211，与追加式几乎相同；这证明生命周期状态转移（而不是记忆内容本身）是鲁棒性的来源。
4. **在干净的单跳场景中，当前键替换即足够**：MemoryAgentBench SH-6k 上 TEPA 与最后写入获胜持平（0.890），说明在没有噪声和推理需求的条件下，最新值替换已足够，复杂生命周期机制的价值体现在可推断性需求更高的场景。
5. **验证和撤销发挥互补作用**：偏好更新中，试验验证过滤候选提升、生命周期撤销清除旧活跃偏好，两者缺一不可。
6. **边界瓶颈明确**：多跳关系检索（MH-6k: 0.040）和超长上下文选择（SH-262k: 0.000）是超越事实级有效性跟踪的下一层挑战。

### 7. 优点

- **问题定义清晰且重要**：将“陈旧记忆污染提示词”这一普遍但此前未被系统研究的现象形式化为记忆污染，并定义了量化指标（MPI）。
- **方法设计优雅**：将有效性作为一等公民（显式状态），在保留审计追溯能力的同时实现检索净化，一种机制同时解决“可用性”（检索只含当前证据）和“可审计性”（历史可溯）。
- **理论衔接务实**：用简洁的风险模型证明撤销的必要性（\( \xi\eta > b \) 条件），不过度承诺全局最优。
- **实验设计的对照质量高**：共享评估器和配对统计检验有效隔离了记忆机制的影响；多个模型无关的机制基线覆盖了替代方案的完整光谱。
- **消融实验令人信服**：撤销开关的消融（0.950 → 0.211）直接证明了核心贡献的因果作用；超参数附近扰动变化小，增强了机制稳定性。
- **边界探索诚实**：主动报告多跳和超长上下文中的失败，勾勒出方法的适用边界和未来的研究方向。
- **可扩展性好**：微基准显示 TEPA 的键查询时间为 O(1) 量级（0.216–0.301 微秒），在大规模场景下与最后写入获胜相当。

### 8. 不足与局限

- **对键提取质量的强依赖**：TEPA 假设可以从证据中提取有用的冲突键，这自然地适用于偏好槽、实体属性和工具机制记录，但对于冲突关系隐含的开放式记忆来说是一个困难问题。虽然补充材料提供了键噪声审计（20% 噪声下 TEPA 从 0.950 降至 0.777），但真实开放域 LLM 解析键的鲁棒性仍未验证。
- **理论保证范围受限**：Proposition 1–3 仅适用于单键、单值替换的简化模型，不涉及多跳推理、跨键组合或长期上下文选择。
- **实验覆盖的结构单一**：所有受控场景本质上都是“同键值替换”模式；没有覆盖部分语义重叠、跨键歧义、渐变漂移或周期性回摆等更丰富的真实世界变化模式。
- **TEPA 无法纠正参数化知识**：论文明确承认，如果没有任何相关证据被检索，TEPA 无法修正模型自身的参数化事实知识。
- **未报告完整系统的端到端收益**：论文声明其目的是测量一种记忆操作而非构建完整助手系统；因此没有完整的部署型智能体端到端评估。
- **算力信息缺失**：未报告 GPU 型号、数量和训练/评估总时长，降低了对结果可复现成本的评估能力。
- **边界结果暴露真实局限**：MH-6k（0.040）和 SH-262k（0.000）的结果表明，在面对需要链式检索和极长上下文选择的任务时，事实级有效性跟踪远远不足——TEPA 在此类场景中几乎失效。

### 总结

TEPA 通过将“有效性”作为记忆的显式生命周期状态，解决了语言智能体长期记忆中“过时记忆污染提示词”这一核心问题。其核心贡献是确定性地识别并撤销被更�新冲突证据取代的先例，同时保留审计线索。实验在受控漂移、真实工具执行、偏好更新和 MemoryAgentBench 四个层次上系统性地验证了：撤销可以防止追加式记忆在完全反转时“劣于无记忆”的灾难性退化。这种方法论的严谨性和问题定义的清晰度是其突出优势，但对键提取质量的依赖和复杂推理场景下的失败也为其应用划定了明确的边界。
