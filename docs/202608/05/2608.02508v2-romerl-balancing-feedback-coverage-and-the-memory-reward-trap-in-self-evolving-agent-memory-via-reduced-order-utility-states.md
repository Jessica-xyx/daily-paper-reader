## 摘要
面向自进化LLM智能体的基于学习的记忆系统面临两个紧密耦合的挑战。首先，轨迹索引的效用随交互历史增长，从而将有限的反馈分散到不断扩展的状态空间中。其次，由于轨迹级别的奖励被联合分配给共同检索的记忆，不相关的经验可能收到误导性的效用更新，进而陷入记忆-奖励陷阱。为解决这些挑战，我们提出了降阶记忆强化学习（RoMeRL），该方法利用按结果极性和记忆动态分解的固定维度每任务记忆状态来表示不断增长的轨迹索引效用空间。RoMeRL通过一组固定的语义坐标纳入新经验，这些坐标的内容随时间更新或替换，从而将反馈集中在有界的效用支持上。理论上，我们表明这种降阶参数化增加了每个效用坐标接收的平均反馈，并在通用坐标转移模型下刻画了错误坐标的稳态占用率。实证上，在ALFWorld和LifelongAgentBench上，RoMeRL提升了任务性能，将Cold-Q比率降低了80.0%，反馈密度提高了约6.0倍，维护的记忆大小减少了84.4%，并将LLM调用次数削减了21.1%。这些结果表明，降阶效用状态支持高效的自进化智能体记忆，同时限制了持续的奖励污染。代码可在 https://github.com/YOUNG-fnxm/RoMeRL 获取。

## Abstract
Learning-based memory systems for self-evolving LLM agents face two tightly coupled challenges. First, trajectory-indexed utilities grow with the interaction history, thereby dispersing limited feedback over an ever-expanding state space. Second, because trajectory-level rewards are jointly assigned to co-retrieved memories, irrelevant experiences may receive misleading utility updates and consequently enter the memory-reward trap. To address these challenges, we introduce Reduced-Order Memory Reinforcement Learning (RoMeRL), which represents the growing trajectory-indexed utility space using a fixed-dimensional per-task memory state factorized by outcome polarity and memory dynamics. RoMeRL incorporates new experiences through a fixed set of semantic coordinates whose contents are updated or replaced over time, thereby concentrating feedback over a bounded utility support. Theoretically, we show that this reduced-order parameterization increases the average feedback received by each utility coordinate and characterize the steady-state occupancy of erroneous coordinates under a generic coordinate-transition model. Empirically, across ALFWorld and LifelongAgentBench, RoMeRL improves task performance, reduces the Cold-Q ratio by 80.0%, increases feedback density by approximately 6.0 times, reduces the maintained memory size by 84.4%, and cuts LLM calls by 21.1%. These results show that reduced-order utility states support efficient self-evolving agent memory while limiting persistent reward contamination. Code is available at: https://github.com/YOUNG-fnxm/RoMeRL

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：LLM 智能体本质上是无状态的（stateless），难以跨交互累积和复用经验。记忆系统通过存储和检索历史经验来解决这一问题。近期研究从手工流程（如 reflection、summarization）转向**基于学习的记忆优化**，从下游任务结果中梯度式地学习记忆的生成、检索与效用，从而使记忆系统在交互中自进化（self-evolving），而无需更新底层 LLM。
- **核心问题（双重挑战）**：
  1. **反馈分散**：轨迹索引（trajectory-indexed）的效用状态随交互历史不断增长，每个新存储的轨迹引入新的可学习效用变量，而有限的反馈（任务级奖励）被分散到不断扩展的状态空间，导致大量记忆“冷启动”（Cold-Q）、更新集中、反馈密度低。
  2. **记忆-奖励陷阱（Memory-Reward Trap, MRT）**：由于轨迹级奖励是对共同检索到的多个记忆联合分配的，弱相关、含噪声、过时或失败的经验在成功片段中被检索到时，也会收到正向效用更新，尽管它们并未对成功做出因果贡献。作者用实验证明，加强探索（如 UCB）虽能提高记忆覆盖、缓解冷启动，却因暴露更多弱相关记忆于错误奖励传播而**降低任务性能**——这就是“探索-污染困境”。
- **根本追问**：如何在不扩大受错误奖励传播影响的效用支撑的前提下，提高记忆反馈覆盖？作者将此归因于轨迹索引效用学习本身的缺陷，并提出用**降阶效用状态**来替代不断增长的轨迹索引效用空间。

## 2. 方法论（RoMeRL 核心思想与关键细节）

### 2.1 理论分析（问题建模）

- **定义 1（轨迹索引记忆效用）**：定义记忆 \(m_i\) 的经验效用 \(\hat{Q}_i\) 为观测奖励均值，并区分**观测效用** \(\mu_i = E[R_t \mid m_i \in S_t]\) 与**边际效用** \(\theta_i = v_i^1 - v_i^0\)（有无该记忆的干预结果之差）。观测归因偏差 \(a_i = \mu_i - v_i^1\)，总信用差距为 \(v_i^0 + a_i\)。
- **定理 1（Gap–Variance 分解）**：
  \[
  E[(\hat{Q}_i - v_i^1)^2] = a_i^2 + \sigma_i^2 / n_i, \quad
  E[(\hat{Q}_i - \theta_i)^2] = (v_i^0 + a_i)^2 + \sigma_i^2 / n_i
  \]
  额外反馈仅降低方差项，**不能消除任务基线 \(v_i^0\) 和归因偏差 \(a_i\)**。
- **定义 2（记忆-奖励陷阱）**：当 \(\theta_i \le 0\) 但 \(\mu_i - v_i^0 > 0\) 时，无正向边际贡献的记忆仍可能因观测收益高于基线而被 Q 更新强化。由于 \(E[|B_t|] = N_t \rho_t\)，受陷阱影响的预期支撑随状态维度 \(N_t\) 增长。
- **定理 2（充分反馈预算）**：在满足全池估计（误差 \(\epsilon\)、置信 \(1-\delta\)）条件下，所需反馈和轨迹预算为：
  \[
  F_T = O\left(\frac{N_t}{\epsilon^2} \log\frac{N_t}{\delta}\right),\quad
  T = O\left(\frac{N_t}{k\epsilon^2} \log\frac{N_t}{\delta}\right)
  \]
  即随记忆数量 \(N_t\) 线性增长，强化了维度诅咒。

### 2.2 降阶记忆状态设计

- **核心思想**：用**固定维度**的每任务状态 \(Z_{g,t} \in \mathbb{R}^4\) 替代不断增长的轨迹索引状态 \(Q_t \in \mathbb{R}^{N_t}\)。状态按两个二元因素分解：
  - **结果极性** \(O = \{+, -\}\)（成功/失败证据）
  - **记忆动力学** \(D = \{C, A\}\)（巩固/自适应）
  - 其笛卡尔积给出四个语义坐标：\(I_{fact} = O \times D, |I_{fact}| = 4\)。
- **四个语义坐标**：
  - **PCC（正巩固坐标）**：保留全局最高效的成功轨迹（按效率 \(\ell_i\) 最小化），作为稳定的正参考；
  - **PAC（正自适应坐标）**：保留失败后首个成功轨迹（按时间序），捕捉“失败-成功”的恢复模式；
  - **NCC（负巩固坐标）**：保留效用超过负初始化阈值 \(Q_{init}^-\) 的失败经验中效用最高者，作为可复用的诊断性负面证据；
  - **NAC（负自适应坐标）**：保留最近一次失败轨迹，追踪当前错误状态。
- **更新机制**：新经验通过**在线保留、晋升或替换**更新坐标内容；每个坐标至多存储一个代表记忆及其效用 \(Q\)。被替换的代表以当前效用做 warm start，后续奖励 \(r_t\) 继续按标准 Q 更新：
  \[
  Q_{g,t+1}^{o,d} = Q_{g,t}^{o,d} + \alpha \cdot \mathbb{1}[m_{g,t}^{o,d} \in S_t](r_t - Q_{g,t}^{o,d})
  \]
- **检索**：按加权余弦相似度与效用分数排序，取 Top-\(k_{ret}\)。

### 2.3 理论保障

- **定理 3（反馈集中）**：降阶后每个效用坐标的平均反馈为 \(\bar{n}_{fact} = (N_t/4)\,\bar{n}_{full}\)，效用估计方差从 \(O(\sigma^2 N_t/(kT))\) 降至 \(O(4\sigma^2/(kT))\)——固定预算集中到少数坐标上。
- **命题 1（稳态错误坐标占用）**：在通用坐标转移模型下（干净→错误概率 \(\le \gamma\)，错误→干净概率 \(\ge \lambda\)），稳态错误占比至多 \(\gamma/(\gamma + \lambda)\)，预期错误坐标数至多 \(d\gamma/(\gamma+\lambda)\)，当 \(d\gamma/(\gamma+\lambda) < N_t\rho_{full}\) 时低于全池暴露。

## 6. 主要结论与发现

- **主实验**：RoMeRL 在 LAB-OS、LAB-DB 和 ALFWorld 上全面优于所有基线，整体平均 SR 达 0.862，比最强基线 MemRL（0.830）高 3.2 个百分点。
- **反馈利用**：Cold-Q 比率从 MemRL 的约 28% 上升到 44.9%，而 RoMeRL 从 28% 降至 9.0%（降 80.0%）；反馈密度从 4.96 提升到 29.93（约 6.0×）。
- **效率**：平均记忆池规模降低 84.4%（45K→7K），LLM 调用降低 21.1%（570K→450K）。
- **MRT 鲁棒性**：在噪声注入测试中，RoMeRL 将正向噪声更新限制在 2.4 次（MemRL 3.7、MemRL+UCB 7.2），最终噪声占比仅 0.15%（MemRL 1.02%、MemRL+UCB 1.20%），且成功率最高（82.0%）。UCB 强化探索确实加重了奖励污染。
- **跨模型迁移**：冻结记忆状态在 4 种“模型-任务”组合中均提升验证分数并降低平均步骤数，说明降阶记忆携带跨骨干可迁移的程序性信息。
- **消融结论**：NCC 同时提升末期 SR 与 CSR（可复用负面诊断信息）；PAC 主要提升末期 SR（保留恢复模式），占用率虽低（5-8%）但价值显著。
- **Q 值质量**：RoMeRL 的 Q 值与记忆来源的 Pearson 相关性从 0.493 提升到 0.673，未更新于初始 Q=0.5 的记忆占比从 47.8% 降至 5.0%，且高 Q 区间仍保留约 19.9% 的失败来源记忆，说明 Q 并非成功/失败标签的简单代理。

## 7. 优点

4. **经验验证全面**：成功演示了“探索加剧奖励污染”这一反直觉现象，并验证了降阶状态在此压力下的鲁棒性。
5. **效率与效果兼得**：记忆压缩没有以性能为代价，反而提升性能并降低推理成本，实用价值高。
6. **跨模型泛化**：冻结记忆可直接迁移到不同 LLM 骨干，展示出良好的可复用性。

## 8. 不足与局限

1. **因果信用分配未完全解决**：RoMeRL 仍依赖结果级（bundle-level）奖励，未引入干预式或反事实归因，观测归因偏差 \(a_i\) 依然存在——降阶状态减少了“暴露面”而非消除了归因误差。
2. **理论参数不可直接估计**：Proposition 1 中的 \(\gamma\) 和 \(\lambda\) 需要成对反事实 rollout 或等价归因才能获得坐标级因果标签，实际部署中难以精确获取。
3. **实验覆盖有限**：
   - 未包含 LifelongAgentBench 的 KG 任务；
   - 主要对比基于单一骨干模型（DS-V4-flash），未做骨干敏感性分析；
   - 未见多次运行的统计波动（标准差/置信区间），难以判断差异显著性；
   - 消融不完整，未系统考查 PCC 和 NAC 的贡献及坐标间交互。
4. **开放场景未验证**：论文实验限于固定任务集和有限预算，没有评估真实环境下开放式、长时程、不断有新任务涌现的自进化场景。
5. **基准偏“技能复用”型**：ALFWorld 和 LAB 的任务类型相对固定，记忆价值主要体现在“同任务或高度相似任务复用”上；对需要创造性推理或情境剧烈变化的任务，固定 4 维坐标的表达力可能不足。
6. **工程依赖**：坐标内容的“更新/替换”规则部分依赖人工预设（如效率最小化、时间序、效用阈值），这些归纳偏置在更复杂任务中可能需要重新设计。
