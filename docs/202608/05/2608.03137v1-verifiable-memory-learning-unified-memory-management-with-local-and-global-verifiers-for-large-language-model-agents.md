## 摘要
大语言模型（LLM）智能体必须在长时间交互中保留可复用信息、控制有界活动上下文，并恢复早期证据。现有方法通常分别优化长期记忆（LTM）和短期记忆（STM），而统一策略往往主要依靠轨迹级反馈进行训练，这为单个记忆决策提供的信用信号较弱。我们提出可验证记忆（VerMem）框架，将长期记忆、活动上下文和情节历史表示为不同状态，并通过一个记忆操作策略控制它们。七个原子操作使策略能够添加、修订或软删除长期记忆条目；将长期记忆检索到活动上下文；过滤或总结活动上下文；以及恢复选定的情节片段。VerMem通过监督微调初始化，并使用三阶段强化学习课程进行训练。局部验证器对可执行的记忆转换进行评分，全局验证器在任务完成后评估证据连贯性和终端记忆一致性。这些得分通过分层信用分配与程序化计算的任务、证据召回、效率和约束信号相结合。验证器仅在训练期间使用。在五个基准和两个LLM骨干网络上，VerMem在绝大多数报告指标上取得了最佳结果，并持续优于强记忆基线。在三个交互式基准上受控的在线token预算下，它在所比较的方法中也实现了最强的效率-性能前沿。代码可在https://github.com/Sun-SYSU-24/VerMem获取。

## Abstract
Large language model (LLM) agents must retain reusable information, control a bounded active context, and recover earlier evidence during long-horizon interaction. Existing methods commonly optimize long-term memory (LTM) and short-term memory (STM) separately, while unified policies are often trained primarily with trajectory-level feedback, which provides weak credit for individual memory decisions. We present Verifiable Memory (VerMem), a framework that represents LTM, active context, and episodic history as distinct states and controls them with one memory operation policy. Seven atomic operations let the policy add, revise, or soft-delete LTM entries; retrieve LTM into the active context; filter or summarize the active context; and restore selected episodic fragments. VerMem is initialized by supervised fine-tuning and trained with a three-stage reinforcement-learning curriculum. The local verifier scores executable memory transitions, and a global verifier assesses evidence coherence and terminal-memory consistency after task completion. These scores are combined with programmatically computed task, evidence-recall, efficiency, and constraint signals through hierarchical credit assignment. The verifiers are used only during training. Across five benchmarks and two LLM backbones, VerMem achieves the best result on the vast majority of reported metrics and consistently outperforms strong memory baselines. Under controlled online-token budgets on three interactive benchmarks, it also achieves the strongest efficiency--performance frontier among the compared methods. Code is available at https://github.com/Sun-SYSU-24/VerMem.

## 一、核心问题与研究动机

- **背景**：LLM 智能体在长时间、多步骤交互中，不仅依赖单步生成能力，还需要在决策间保留和利用任务相关信息。智能体记忆通常分为两类：
  - **长期记忆（LTM）**：跨回合/阶段/任务持久保存用户或任务相关知识；
  - **短期记忆（STM）**：当前输入上下文中的信息，支撑即时推理与行动。
- **核心问题**：现有方法存在三个主要缺陷：
  1. **异构记忆协同困难**：LTM 与 STM 操作在不同状态与时间尺度上工作，统一策略难以在共享决策过程中协调二者且保持功能边界；
  2. **历史上下文恢复缺失**：早期观察、工具输出或中间结论在子目标切换后可能重新变得相关，而仅靠检索、过滤和压缩无法指定应恢复"哪段情节历史"；
  3. **多粒度信用分配薄弱**：单个记忆操作的效用往往是延迟的（如正确的写入只有在后续检索时才体现价值），轨迹级反馈无法区分具体哪些原子转换是有用或有害的。
- **现有方法的局限**：多数系统单独优化 LTM 或 STM；即使 AgeMem 提出了统一策略，其 STM 动作也仅聚焦检索、过滤、总结，缺乏情节级恢复能力；且大多仅依赖轨迹级/答案级反馈。

## 二、方法论

### 2.1 核心思想：VerMem 框架

- 将**长期记忆 M_t**、**活动上下文 C_t** 与**同任务情节历史 H_t** 保持为三个不同状态，由**单一记忆操作策略**统一控制。
- 策略输入为有界序列化状态：$x_t = g(s_t)$，其中 $s_t = (q, M_t, C_t, H_t)$，受 8,192 token 策略状态限制约束。
- 完整记忆命令为 $u_t = (v_t, \xi_t)$，其中 $v_t$ 为操作类型（可空），$\xi_t$ 为结构化参数；过渡函数为 $\tilde{s}_t = T_m(s_t, u_t)$；任务/环境交互过渡为 $s_{t+1} = T_e(\tilde{s}_t, b_t, z_{t+1})$。

### 2.2 七个原子记忆工具

| 类别 | 操作 | 功能 |
|------|------|------|
| LTM | **Add** | 向 M_t 添加持久条目 |
| LTM | **Update** | 在 M_t 创建修订版本（保留旧版本） |
| LTM | **Delete** | 软删除 M_t 中的条目（保留历史记录） |
| STM | **Retrieve** | 将 M_t 内容检索至 C_t |
| STM | **Filter** | 过滤 C_t 中的低价值内容 |
| STM | **SelectEpisode** | 从情节历史 H_t 恢复相关片段至 C_t |
| STM | **Summarize** | 总结压缩 C_t |

另含**空操作 ∅**（不改变记忆状态，计入决策地平线但不计为工具调用）。SelectEpisode 与 Retrieve 的关键区别在于信息源：前者恢复同任务历史中的观察/工具输出/中间结论，后者检索持久知识库。

### 2.3 训练流程

- **SFT 预热**：32,000 条监督数据（8 类决策各 4,000 条，含边界模板与冻结 DeepSeek-V3.2 教师生成候选，经七重确定性过滤），目标为操作选择与结构化参数生成。
- **三阶段强化学习课程**：$\theta_{SFT} \to \theta_A \to \theta_B \to \theta_C$
  - Phase A：训练 $V_{LTM} \cup \{\emptyset\}$（1,000 次更新，8,000 训练集）；
  - Phase B：训练 $V_{STM} \cup \{\emptyset\}$（1,000 次更新，8,000 训练集，含干扰物场景）；
  - Phase C：完整 $V \cup \{\emptyset\}$ 协同训练（1,500 次更新，12,000 训练集）。
- **状态化轨迹收集**：每次更新采样 8 个任务、每任务 8 条候选轨迹（K=8），同一候选组共享初始状态，仅策略采样不同，用于 GRPO 风格归一化。

### 2.4 局部-全局验证器引导的分层信用分配

- **局部验证器**（冻结 DeepSeek-V3.2）：对每个可执行记忆转换评四维分数——任务相关性、证据接地性、局部进展、信息保真度（各 0–4 分），按操作类型归一化得 $A^local_{t,k}$；被拒绝命令设零。
- **全局验证器**：任务完成后评估**证据连贯性**与**终端记忆一致性**（仅此两维），与程序化计算的任务正确性、支持事实召回、效率信号组成为综合全局分支 $r^global_k$，在候选组内归一化得 $A^global_k$。
- **分层信用合成**：$A^{hier}_{t,k} = \lambda_{local} A^{local}_{t,k} + \lambda_{global} A^{global}_k - \lambda_{constraint} c_{t,k}$（λ 均为 1），约束成本 $c_{t,k}$ 处理结构/安全/预算等硬违规。
- **全局奖励构成**：$r^{global}_k = \frac{1}{4}(r^{task}_k + r^{evid}_k + r^{state}_k + r^{eff}_k)$，其中 $r^{evid}_k = \frac{1}{2}(r^{sup}_k + v^{coh}_k)$，$r^{state}_k = v^{state}_k$，效率项 $r^{eff}_k = \mathbb{I}[r^{task}_k \geq \delta](1 - C^{online}_k)$（δ=0.5，防止低成本失败获得效率奖励）。
- **优化目标**：PPO 裁剪目标 + GRPO 候选组归一化 + KL 正则（β=0.1），损失仅施加于记忆命令 token。

## 七、方法亮点

- **统一但分状态的设计**：一个策略协调 LTM 维护与 STM 控制，同时保持三种状态的功能边界，并用 SelectEpisode 显式支持情节级历史恢复——填补了既有工作（如 AgeMem）缺少的操作维度。
- **多粒度信用分配**：局部（操作级）与全局（轨迹级）验证器信号分别归一化后分层组合，使成功轨迹中的较差操作不必获得全额正信用，失败轨迹中的有用操作可保留局部正贡献；操作类型级归一化避免工具间评分尺度差异。
- **验证器仅训练使用**：推理时无额外验证开销，保障部署效率。
- **严格的状态与约束管理**：软删除、版本保留、预算检查、硬约束与语义评分通道分离；区分"可选策略行为"（语义评分低）与"硬违规"（拒绝+惩罚）。
- **实验设计严谨**：跨基准迁移、多种子报告、预算固定协议、Qwen-Max 独立评估、多种消融

**实验设计严谨**：跨基准迁移、多种子报告、预算固定协议、Qwen-Max 独立评估、多种消融组合相互印证，使得结论具有较强的可信度与可复现性。

## 八、局限性与潜在缺陷

1. **离线训练成本与依赖**：SFT 数据生成及局部/全局验证器均依赖冻结的 DeepSeek-V3.2 教师模型，训练管线包含前置数据合成步骤与多次策略更新，论文未报告 GPU 型号、数量及墙钟时间，难以量化整体训练开销，也限制了在资源受限场景下的可复制性。
2. **评估器依赖性问题**：HotpotQA 的 $J_{judge}$ 与 MQ 指标依赖固定的专有 Qwen-Max 快照，论文承认该快照不可独立复现；若专有模型版本更新，指标数值可能漂移，长期对比基线方法时存在公平性隐患。
3. **上下文窗口上限约束**：策略状态受 8,192 token 上限限制，序列化 $(q, M_t, C_t, H_t)$ 时必须截断或压缩；在更长交互或更大记忆库场景下，信息丢失可能导致策略决策质量下降，论文未深入分析状态序列化截断对性能的边际影响。
4. **单任务隔离假设**：记忆状态按任务隔离、每任务从空状态开始，未处理跨任务记忆迁移或长期持续性智能体（同一 agent 连续处理多个任务）场景；尽管实验结果支持"跨任务策略迁移"，但"跨任务内容记忆"的累积与复用尚未验证。
5. **验证器设计依赖人工维度定义**：局部验证器的四维评分（相关性、接地性、进展、保真度）与全局验证器的两维评分（证据连贯性、终端一致性）由人工设定并需逐操作调用冻结模型评估，维度选择的合理性缺乏消融；验证器打分质量的上限直接影响信用分配的精度。
6. **效率信号的基本假设**：效率奖励仅当任务正确完成时发放，且使用固定阈值 $\delta=0.5$ 与预定义预算 S*、B*；若任务难度分布变化，固定阈值可能使效率奖励失真。
7. **PDDL 基准上的非最优表现**：VerMem 在两个骨干下均未在 PDDL 上取得第一（落后于 noVerify 0.35 分），提示验证器信用在某些规划密集型任务上可能引入轻微噪声，论文未对此给出机理层面的解释。
8. **外部基线覆盖范围有限**：未与更新的长时记忆方法（如基于 RAG 的认知架构、记忆图升级版本）或更大规模骨干上的记忆策略对比，结论的泛化边界有待更广验证。

## 九、总体评价与展望

整体而言，VerMem 的核心贡献在于**将长期记忆、短期记忆与情节历史统一到一个可微调的原子操作策略之下**，并通过局部—全局分层验证器解决了记忆操作延迟信用分配的难点。其在五基准、双骨干上的跨任务迁移表现不仅验证了方法的有效性，也为"记忆操作策略本身可被学习、可跨任务复用"这一论点提供了有力证据。相比已有的单模块记忆优化或统一策略（如 AgeMem），VerMem 在动作空间完整性（加入 SelectEpisode 情节恢复）与信用分配细粒度上均有实质推进，且推理时零额外验证开销的设计具备实际部署价值。

未来工作可从以下方向延伸：

- 放宽单任务隔离假设，研究跨任务连续交互下的记忆内容迁移与生命周期管理；
- 引入自适应状态序列化或分级记忆压缩，突破 8,192 token 策略窗口对长期记忆规模的限制；
- 降低对冻结教师模型的依赖，探索验证器自训练或在线反馈替代方案，以削减离线成本；
- 将验证器维度选择纳入自动化搜索或端到端学习，减少人工设计偏差；
- 在更大参数规模骨干（如 14B/32B）与更复杂交互环境（如多智能体协作、具身长程任务）上验证方法上限。
