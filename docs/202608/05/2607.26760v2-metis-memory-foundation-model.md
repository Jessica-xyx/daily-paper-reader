## 摘要
近期AI智能体的进展越来越多地将原生能力内化到其底层基础模型中，催生了多模态基础模型和大型推理模型。然而，智能体记忆仍主要通过外部模块实现，原生记忆能力在很大程度上尚未被探索。在本文中，我们通过引入记忆基础模型，向这一方向迈出了第一步，使基础模型具备原生记忆能力。我们从两个角度形式化原生记忆：骨干网络内持续且动态演化的记忆状态，以及通过模型计算自主存储和利用信息的原生记忆程序。我们表明，原生记忆在架构、端到端优化和效率方面具有优势。基于这一表述，我们提出了Metis，这是记忆基础模型的第一个原型。Metis引入了一种新架构，为基础模型配备了原生记忆状态，使得历史信息能够被压缩到模型中，并通过记忆注意力进行访问。我们构建了大规模的记忆专用训练数据，并引入了多个优化目标，通过中期训练来习得这些原生记忆程序。Metis的在线记忆维护是无梯度的，记忆更新仅需一次前向传播。在推理时，所有学习到的模型权重保持冻结，而原生记忆状态通过标准前向计算自主转换。通过大量实验，我们展示了Metis展现出原生记忆能力，并进一步详细分析了其优势、局限性和行为。为促进未来对记忆基础模型的研究，我们发布了我们的项目和模型检查点。

## Abstract
Recent advances in AI agents have increasingly internalized native capabilities into their underlying foundation models, giving rise to multimodal foundation models and large reasoning models. However, agent memory is still primarily implemented through external modules, leaving the native memory capability largely unexplored. In this paper, we take a first step toward this direction by introducing memory foundation models, which empower foundation models with native memory capabilities. We formalize native memory from two perspectives: a persistent and dynamically evolving memory state within the backbone, and native memory procedures that autonomously store and utilize information through model computation. We show that native memory offers advantages in architecture, end-to-end optimization, and efficiency. Based on this formulation, we propose Metis, the first prototype of memory foundation models. Metis introduces a new architecture that equips a foundation model with a native memory state, allowing historical information to be compressed into the model and accessed through memory attention. We construct large-scale memory-specific training data and introduce multiple optimization objectives to acquire these native memory procedures through mid-training. The online memory maintenance of Metis is gradient-free, and the memory update requires only a forward pass. At inference time, all learned model weights remain frozen, while the native memory states are autonomously transformed through standard forward computation. Through extensive experiments, we show that Metis exhibits native memory capabilities and further provide a detailed analysis of its strengths, limitations, and behaviors. To facilitate future research on memory foundation models, we release our project and model checkpoints.

## 一、论文的核心问题与整体含义

- **研究背景**：近年来，AI 智能体能力逐步被“内化”到基础模型本身（如多模态基础模型、大型推理模型），但智能体的记忆仍普遍由外部模块（如 RAG、向量库、记忆银行）实现，基础模型不具备“原生记忆”能力。外部记忆存在三大固有局限：
  1. **解耦性**：记忆模块与骨干模型分离，目标独立，记忆难以为推理提供最优信息；
  2. **无法端到端优化**：离散记忆操作阻碍梯度传播，领域后训练困难；
  3. **在线开销高**：记忆准备、检索、拼接和重预填充增加推理延迟。
- **核心含义**：论文提出**记忆基础模型（Memory Foundation Models）**，将记忆能力从外部模块“内化”到骨干模型的计算过程中，使模型具备跨多轮交互的持久记忆状态和自主记忆操作。这是智能体记忆研究的一个重要范式转变，类似从大型语言模型到大型推理模型（将思维链内化进推理）的演化。
- **具体定义**：从两个维度刻画原生记忆：
  - **原生记忆状态**：记忆状态是骨干模型动态参数的一部分，可跨推理步骤持续演化；
  - **原生记忆程序**：记住、遗忘、更新等操作在模型前向计算中自主完成，无需外部规则或离散流程。
- **整体贡献**：提出首个记忆基础模型原型 **Metis**，设计新架构、构建大规模记忆训练数据、通过中期训练（mid-training）习得原生记忆能力，并开放源码与模型权重。

## 二、方法论：核心思想、关键技术细节

- **整体框架**：Metis 采用因果语言模型为基座，在 Transformer 层中嵌入 **Metis Block**，每个 Metis Block 由：
  - **Local Memory Block**：维护动态记忆状态，包括稠密记忆网络 M ∈ R^(d_k×d_v) 和查询-键归一化向量 S ∈ R^(d_k)，随步骤更新；
  - **Hyper Memory Block**：由静态（训练后冻结）参数构成，包括：
    - 可学习重要性向量 w_agg，用于自适应聚合当前层激活；
    - 记忆键/值投影矩阵 W_K、W_V，将选中的隐藏状态映射为记忆键和值；
    - 记忆查询投影矩阵 W_Q，用于记忆读取时的相似度重塑造。
- **原生记忆存储过程**：
  1. 对输入隐藏状态做层归一化，用可学习重要性向量计算 token 重要性分布；
  2. 采用 **top-ρ 累计概率**选择关键位置（straight-through estimator 保持可导），得到紧凑表示；
  3. 通过投影得到记忆键和记忆值；
  4. 用折扣因子 λ 更新 M 和 S（论文实际采用 **Gated Delta Network (GDU)** 代替线性更新，以避免全局衰减带来的干扰）。
- **原生记忆利用过程**：定义**记忆注意力**：
  \[
  \tilde{A}_t^{(l)} = \text{diag}(\tilde{Q}_t^{(l)} S_t^{(l)})^{-1} \tilde{Q}_t^{(l)} M_t^{(l)}
  \]
  该分支与原始自注意力并行，通过权重 γ 融合：
  \[
  A_t^{(l)} = \gamma \cdot \text{Softmax}(\cdots) V_t^{(l)} + (1-\gamma) \cdot \text{Norm}(\tilde{A}_t^{(l)})
  \]
- **理论解释**：从“虚拟记忆前缀”视角推导，记忆注意力等价于对虚拟前缀 token 的注意力；引入可学习记忆查询投影 W_Q 可重塑跨步骤相似性，抑制无关记忆的噪声干扰。
- **误差分析**：给出了固定大小矩阵压缩历史导致的三个误差项（注意力误差、全局归一化结构误差等），从理论上说明记忆查询与键投影的可学习性有助于压制噪声。
- **效率分析**：原始注意力、记忆读取、记忆存储在并行层面可重叠执行，且历史信息以固定大小状态存储，不随交互轮数线性增长，避免了外部检索/拼接入上下文的额外开销。
- **数据构建**：
  - **主数据**：27 个公共基准，覆盖 remember/update/forget/reflect 四种操作，结合显式/隐式/干扰三种风格，合成 357,137 个样本（约 4.06 亿 token）；
  - **辅助数据**：针对多实体绑定、选择性遗忘、记忆后对话、记忆无关对话等复杂场景，合成 609,443 个样本；
  - 数据构建流程包括种子抽取、静态合成、质量验证（一致性、正交性、捷径检查）。
- **优化目标**：
  1. **记忆重建目标**：让模型在记忆中保留源内容并重建，对应无损压缩上限；
  2. **记忆操作目标**：显式/隐式与干扰样本共同监督 remember/update/forget/reflect 等运算；
  3. **正则化目标**：针对多实体干扰和记忆污染，提升鲁棒性；
  - 所有目标共享逐 token 负对数似然；训练时冻结骨干，只优化记忆相关参数；采用任务权重线性退火采样器控制各数据子集比例。

## 六、主要结论与发现

- **Metis 具备原生记忆能力**：在无上下文、无外部

- **记忆操作与问答上的表现**：在 MemOps (Gold/Full) 与 Metis Test Set 上，Metis 的无上下文记忆操作准确率显著超过无上下文基线（原始骨干几乎无法回答），并接近、部分超越 Qwen3.5 全上下文模型；在 LoCoMo (Gold) 与 NextMem 上，Metis 无需任何检索或上下文注入即可取得与“完整上下文”相当甚至更好的结果，说明原生记忆状态确实承担了传统 RAG 的职责。
- **规模效应**：模型从 4B 到 27B 总体性能持续提升，说明原生记忆能力与骨干参数量正相关；更大骨干能更有效地组织、压缩和利用记忆。
- **与检索增强对比**：Metis 在长会话、多跳时间推理等场景普遍优于 Dense RAG；由于无需在线检索和拼接，其每轮推理延迟与存储开销也明显更低，记忆状态大小固定，不随会话长度增长。
- **OOD 结论**：在排除训练源、未参与合成的基准（ATM-Bench、MemDaily）上，Metis 表现出一定泛化能力但并非稳定全面领先，说明其记忆能力仍与训练数据分布密切相关，是当前主要的短板之一。
- **容量与遗忘**：记忆容量随维度与骨干规模增大而提升，但在长轨迹与多实体干扰下存在明确上限；选择性遗忘能力依赖辅助数据，若缺乏足够“遗忘-隔离”训练，旧记忆会污染新记忆。
- **消融结论**：Gated Delta Network、自适应聚合、可学习记忆查询投影与归一化向量均对记忆有效性和稳定性有正贡献；去除多实体训练数据后干扰场景性能下降，验证了数据设计对鲁棒性的关键作用。
- **效率与工程**：Memory-as-Adapter 结构使记忆状态附加在骨干之上，可在多用户批量推理时共享骨干、分割记忆参数，显著降低单会话存储成本；实测延迟与上下文 / 历史长度近似解耦，具备支持长期交互的工程可行性。
- **跨骨干迁移**：Metis 的记忆机制可迁移至 Llama、Gemma 等其他骨干，证明其不是 Qwen 特有的过拟合产物；但迁移后需等规模训练才能达到相近保真度。
- **总体判断**：Metis 首次验证了“记忆基础模型”这一范式的可行性：将离散外部记忆转化为连续原生记忆状态，通过中期训练让模型自主记忆、遗忘与更新，同时在精度与效率上均有竞争力。但它仍是原型系统，受限于容量、合成数据分布和评测不确定性，距离生产级通用记忆仍需进一步迭代。
