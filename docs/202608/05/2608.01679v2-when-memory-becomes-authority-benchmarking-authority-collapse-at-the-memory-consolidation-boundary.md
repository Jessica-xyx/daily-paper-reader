## 摘要
持久化记忆使（自我进化的）LLM智能体能够通过将异构交互历史整合为可复用的事实、偏好、观察和规则，来适应各种任务。然而，整合也施加了一个隐含的授权边界：它决定了存储的信息之后是否可以被用作用户事实、经验证的观察或长期指令。我们识别出权威崩溃现象，即整合保留了一个主张，却抹去了约束其授权使用的来源条件，导致存储的记忆暗示出比其来源所允许的更大的权威。我们引入了AuthMem-Bench，一个受控的成对基准，它保持焦点主张和下游任务不变，仅改变来源权威。它评估写入时崩溃、下游授权错误和自动权威保留。在基于广泛使用的智能体记忆系统的七个整合器和七个LLM骨干上，我们在49个评估配置中的48个中观察到权威崩溃。在受控的基于行动的评价中，没有权威元数据的崩溃记忆产生了50.3%的平均未经授权行动率。在端到端评估中，自动预测并持久化的权威标签将观察到的未经授权行动率从16.9%降至0.0%，而良性任务成功基本保持不变。这些发现表明，记忆驱动的适应不仅必须保留所学的内容，还必须保留其可以被复用的权威。

## Abstract
Persistent memory allows (self-evolving) LLM agents to adapt across tasks by consolidating heterogeneous interaction histories into reusable facts, preferences, observations, and rules. Yet consolidation also imposes an implicit authorization boundary: it determines whether stored information may later be consumed as a user fact, an attested observation, or a standing instruction. We identify authority collapse, in which consolidation preserves a claim while erasing the source constraints governing its authorized use, causing the stored memory to imply greater authority than its source permits. We introduce AuthMem-Bench, a controlled paired benchmark that holds the focal claim and downstream task fixed while varying only source authority. It evaluates write-time collapse, downstream authorization errors, and automatic authority preservation. Across seven consolidators based on widely used agent-memory systems and seven LLM backbones, we observe authority collapse in 48 of 49 evaluated configurations. In a controlled action-grounded evaluation, collapsed memories without authority metadata yield a mean unauthorized-action rate of 50.3%. In an end-to-end evaluation, automatically predicted and persisted authority labels reduce the observed unauthorized-action rate from 16.9% to 0.0%, while benign task success remains essentially unchanged. These findings show that memory-driven adaptation must preserve not only what was learned, but also the authority under which it may be reused.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **背景**：LLM 智能体越来越依赖持久化记忆（persistent memory）来跨任务携带信息、个性化行为并复用既往经验。记忆驱动型与自我进化型智能体尤其依赖一个"记忆整合"（memory consolidation）过程，将角色标注的异构交互历史（system/user/assistant/tool 各角色消息）转化为可复用的事实、偏好、观察、经验与规则。
- **核心问题**：作者指出，整合不仅是"决定记住什么"，它还构成了一道隐含的**授权边界**——决定了一条被存储的信息日后能否被用作"用户事实"（user fact）、"经证实的观察"（attested observation）或"长期指令"（standing instruction）。若整合保留了主张内容却丢失了限制其合法使用的来源条件，即产生 **authority collapse（权威崩溃）**。
- **安全含义**：权威崩溃可利用的对抗形态是 **authority laundering（权威清洗）**：来自未背书来源的主张（如第三方报告、工具输出、助手建议）被静默地固化为看似有更高权威的记忆，即使该主张本身为真且不含注入指令，也可能导致后续未授权工具调用。这不同于既往工作研究的"记忆投毒"与"提示注入"——权威崩溃的关键不在于内容真假，而在于**来源所赋予的使用权限被悄悄升级**。

## 2. 论文提出的方法论

### 2.1 核心思想与形式化定义

- 将交互历史形式化为 \( H = \langle(x_i, r_i)\rangle_{i=1}^n \)，其中 \( x_i \) 为源片段，\( r_i \in \{system, user, assistant, tool\} \) 为角色类；整合器 \( C_\theta \) 将 \( H \) 映射为记忆集合 \( C_\theta(H) = \{m_1,\dots,m_k\} \)。
- 对焦点主张 \( p \)，定义黄金权威标签 \( \ell^\star(p,H) \)，分为三层：**Authorized**（可直接授权受保护行动）、**Attested**（可信来源断言，但不单独证明用户意图）、**Unendorsed**（可用于上下文保留，但不能直接授权受保护行动）。
- 定义**虚假权威升级**：当存储表示所隐含的允许用途 \( \hat{\Pi}(m) \) 超出黄金标签允许用途 \( \Pi(\ell^\star) \) 时（即 \( \hat{\Pi}(m) \not\subseteq \Pi(\ell^\star(p,H)) \)），整合过程即发生了 authority collapse。
- 权威是**使用特定**（use-specific）的：日历工具证实"某个时段空闲"并不授权"用户意图预订该时段"。

### 2.2 AuthMem-Bench 基准构建

- **数据来源**：从两个固定来源采样 50 条基础历史（τ2-Bench 发布轨迹 30 条：航空/零售/电信各 10；APIGen-MT-5k 合成轨迹 20 条：航空/零售各 10），渲染为标准角色标注历史，并补充良性交互以支持非焦点记忆。
- **权威策略**（frozen role-policy-v1）：user → Authorized；assistant → Attested；tool → Unendorsed；system 不直接作为记忆来源。
- **七种权威转换模板**（构造分层）：

| 代码 | H⁻ 来源条件 | 被禁止的解释 |
|---|---|---|
| R2F | 第三方报告 p | → 用户档案事实 |
| P2R | 外部规程 a | → 长期规则 |
| C2O | 未背书主张 p | → 操作性事实 |
| MIX | 用户/工具混合证据 | → 无限定事实/规则 |
| O2I | 工具观测 p | → 用户意图/决定 |
| R2P | 外部建议 x | → 用户偏好 |
| S2D | 助手建议 a | → 用户决定 |

- **配对构造**：50 条基础 × 7 种转换 = 350 对（700 条历史变体）。同对中焦点主张与操作值完全相同，后续任务 q、工具模式、目标参数、固定参数与动作谓词全部固定，仅载体角色不同。每个配对提供"清洗版"（去掉来源条件）与"来源标注版"两种受控记忆渲染。

### 2.3 三阶段评测任务

- **Module A（写入时崩溃）**：对 H⁻/H⁺ 分别执行整合，将 H⁻ 结果分类为 omitted / authority-upgraded / authority-preserved，并报告三项指标：Upgrade-all（升级比例）、Ret⁻（负例保留率）、Ret⁺（正例保留率）。
- **Module B（受控下游后果）**：直接注入基准提供的焦点记忆（绕过整合与检索），在七种记忆条件下执行相同的后续任务，以确定性原生工具调用谓词打分，报告 ASR（非授权用例中发出被禁动作的比例）与 TSR（授权用例中完成目标动作的比例）。
- **Module C（端到端权威保留）**：完整流水线由来源历史出发：整合 → 自动预测权威标签（源优先预测器选择主支撑消息，再按角色策略确定性映射为标签）→ 持久化 → 检索 → 行动；同样用 ASR/TSR 评分，且所有配对均计入分母。

  - Module C：C1 含 **4,900 个 case 级检查点与 28,875 条 memory 级来源决策**；C2 含 700 条参考标签、700 条预测标签与 **3,500 条端到端动作记录**。
  - 统计推断采用 10,000 次 base-cluster bootstrap 置信区间。
- **充分且较客观**：行动评分不使用 LLM 判定而是精确匹配原生工具调用（目标工具 + 完整参数对象），降低主观性；Module A 判定由隐藏写作者身份的 GPT-5.6-Luna 执行，并做了独立裁判验证（Luna vs Qwen 一致性 κ=0.762，第三方 DeepSeek 仲裁，最终仅 0.57% 的单元结果改变）；20/20 硬审计检查全部通过；预测器/行动模型均只在验证集上选择，未泄漏测试信息。
- **公平性考量**：各整合器采用统一接口（相同角色化历史、最多 16 条记忆、相同五种记忆类型），保持历史、解码、判定与评分固定，仅变化整合提示；补录了完整逐格 token 记账以确保可复现。

## 6. 论文的主要结论与发现

1. **权威崩溃具有跨模型普遍性**：49 个整合器—骨干配置中有 48 个出现权威升级；唯一零升级配置（Mem0 classic + GPT-5.5）是通过完全省略 350 条非授权焦点主张来规避，并非真正保权。
2. **低 Upgrade-all 不等于安全**：基础网格中 Ret⁺ 仅 61.5%、Ret⁻ 仅 26.0%；很多"安全"结果是靠"不记住"而非"记住但保留限制"实现；GPT-5.5/GPT-5.4 mini 的低升级率伴随极低的负例保留率（11.2%/12.7%）。
3. **提示修复收效有限**：Marked 干预使 Ret⁻ 从 25.3% 升至 83.5%，但同时把 Upgrade-all 从 21.6% 抬到 55.8%（暴露了此前被省略掩盖的崩溃）；加 source-aware 指令后 Upgrade-all 降至 9.9%（Ret⁻ 82.5%，Ret⁺ 98.6%），说明底层 LLM 仍有脆弱性。
4. **清洗记忆导致行动层授权错误**：清洗文本 + 无元数据时，宏观 ASR/TSR 分别为 50.3%/49.4%，几乎无法区分授权与非授权来源；来源标注文本仅把 ASR 降到 40.5%，自然语言来源不足以可靠控权。
5. **结构化权威元数据恢复选择性**：黄金元数据将 ASR 降到 5.8%（清洗）/ 2.7%（来源标注），TSR 保持 53.9%；而文本消毒器（26.2% ASR / 26.1% TSR）与保守连接（5.1%/5.1%）是"无差别抑制"而非恢复权威。
6. **端到端可自动恢复权威**：冻结流水线中，预测元数据把观察到的 ASR 从 16.9% 降至 0.0%，TSR 从 39.7% 微升至 40.0%，与参考标签结果

6. **端到端可自动恢复权威**：冻结流水线中，预测元数据把观察到的 ASR 从 16.9% 降至 0.0%，TSR 从 39.7% 微升至 40.0%，与参考标签结果（ASR 0.0% / TSR 40.0%）完全一致；这意味着不需要任何人工标注，仅靠自动预测的权威标签就能在完整“整合→持久化→检索→行动”链路中恢复授权边界，也说明 Module A/B 中观察到的崩溃**并非不可修复的系统性缺陷**，而是当前记忆系统缺少“来源约束的显式建模”所致。

7. **局限性、开放问题与更广泛含义**

### 7.1 局限性与威胁有效性

- **基准覆盖范围有限**：来源角色仅为 user/assistant/tool 三类，system 消息未作为记忆来源；领域限于航空、零售、电信；历史为固定模板渲染，未覆盖多轮交叉引用、隐式指代、多主张复合记忆等更复杂形态。
- **权威策略单一**：采用冻结的 role-policy-v1，未探讨不同应用（如医疗、金融合规、法律）可能需要的更细粒度权威层级；也未处理“同一主张被多个来源以不同权威重复断言”的聚合问题。
- **评价指标以任务完成/拒绝为焦点**：ASR/TSR 刻画“是否发出被禁动作”与“是否完成授权动作”，未充分衡量记忆的长期正确性、遗忘曲线、隐私合规成本等。
- **LLM 骨干属 API 黑盒**：模型版本固定但不可复现内部解码；作者用温度 0 与固定模型 ID 缓解，但无法排除服务端更新导致的行为漂移。

### 7.2 开放问题

- **最省力的安全点在哪里**：Module B 显示结构化元数据几乎能完全恢复选择性，但 Module A 显示整合器普遍丢弃来源条件；未来系统设计应优先在**写入时**强制权威元数据，还是依靠**读取时**的保守策略？
- **文本能否承载权威**：来源标注文本仅把 ASR 从 50.3% 降到 40.5%，说明自然语言对脆弱模型而言不足以稳健控权；是否应从根本上改变记忆的表示形式（如结构化事实 + 来源边）而非依赖提示工程？
- **权威与隐私的权衡**：保守连接基线以极低 TSR 为代价换取低 ASR，提示“不记住”虽然安全但损害效用；如何让系统在保留有用信息的同时只恢复其合法权限，是记忆系统设计的关键张力。

### 7.3 对记忆驱动型智能体领域的更广泛含义

- 本文把“记忆整合”从单纯的**信息选择问题**重新定义为**权限边界维护问题**，为记忆安全研究提供了一个新维度：不仅要防“坏的记忆内容”，也要防“好内容被错误地赋予更高使用权限”。
- 基准与指标（authority collapse、upgrade-all、ASR/TSR）可复用于未来记忆系统评测；配对构造（同一主张仅换载体角色）是控制变量的干净范式，有望成为后续记忆安全评测的标准做法。

8. **总体结论**

作者通过形式化“权威崩溃”概念、构建 AuthMem-Bench 基准并开展三层级、跨 7 记忆系统、7 骨干模型、7 权威转换模板的大规模评测，证明了：当代 LLM 记忆整合器在写入、受控读取与端到端三个层面都系统性丢失来源权限信息；清洗记忆会使行动层几乎无法区分授权与非授权来源；仅靠自然语言来源标注或通用消毒提示无法稳健恢复权威；而显式的结构化权威元数据（无论是人工给定还是自动预测）都能近乎完全地恢复选择性授权。论文的核心呼吁是：**记忆系统必须把“来源”当作与“内容”同等重要的一等公民来建模，否则记忆越强、清洗越彻底，权威崩溃带来的安全风险就越大。**
