## 摘要
大语言模型（LLM）智能体必须保留并利用跨步骤信息，才能在长时程任务中保持行为连贯。现有方法提升了记忆的可访问性，但若信息构建、组织、优先级排序或呈现方式不佳，与行动相关的信息仍可能无法有效指导当前决策。我们将这种访问后的失败称为“记忆-行动鸿沟”。我们提出MemArbiter，一种功能感知的记忆仲裁框架，用于解决该鸿沟中由记忆管理引发的问题。MemArbiter将交互历史分解为原子条目，组织成五个功能性记忆库，并结合库级需求、条目级关联性、焦点-环境表征以及时间呈现门控来动态控制记忆显著性。我们在ALFWorld上，在统一的单步记忆预算下，将MemArbiter与平坦检索和平坦新颖性基线进行比较。在500和750令牌预算下，使用开放权重行动生成模型的MemArbiter分别达到了82.8%和92.5%的成功率，分别超出最强基线20.9和25.4个百分点。它还改善了失败后的恢复能力，减少了失败动作重复和状态-动作循环。这些结果表明，功能感知的记忆仲裁能够使可访问的信息更有效地引导行动。

## Abstract
Large language model (LLM) agents must retain and use cross-step information to act coherently in long-horizon tasks. Existing methods improve memory accessibility, yet action-relevant information may still fail to guide the current decision because it is poorly formed, organized, prioritized, or presented. We call this post-access failure the Memory-Action Gap. We propose MemArbiter, a function-aware memory arbitration framework that addresses the memory-management-induced component of this gap. MemArbiter decomposes interaction histories into atomic items, organizes them into five functional Memory Banks, and combines bank-level demand, item-level relevance, focal-ambient representations, and a temporal presentation gate to dynamically control memory salience. We evaluate MemArbiter on ALFWorld against Flat Retrieval and Flat Recency under unified per-step memory budgets. With an open-weight action-generation model, MemArbiter achieves success rates of 82.8% and 92.5% under 500- and 750-token budgets, outperforming the strongest baseline by 20.9 and 25.4 percentage points, respectively. It also improves post-failure recovery and reduces failed-action repetition and state-action recurrence. These results show that function-aware memory arbitration enables accessible information to guide actions more effectively.

## 2. 论文提出的方法论

### 2.1 核心思想

MemArbiter是一个**决策时工作记忆仲裁框架**，核心理念是：不同决策功能的记忆应以不同方式被组织、更新、优先排序和呈现。框架将交互历史分解为原子记忆条目，按功能存入五个记忆库，并通过动态信号和时间门控机制控制每条记忆在当前决策提示中的呈现状态（焦点/环境/隐藏）。

### 2.2 关键技术细节

**（1）五个功能记忆银行**

| 记忆库 | 决策功能 | 时间特征 |
|--------|----------|----------|
| Goal（目标） | 引导行动朝向期望结果 | 跨步骤持久 |
| Task State（任务状态） | 描述当前位置、物品、对象状态等决策条件 | 频繁更新 |
| Constraint（约束） | 限制无效行动和结果 | 相关步骤内稳定 |
| Episodic（情景） | 记录先前尝试与结果 | 持续累积 |
| Reference（参考） | 提供可复用的环境知识（位置、URL等） | 需要时激活 |

**（2）原子记忆条目与候选写入（Candidate Writer W）**

- 每一步接收完整决策上下文 `ct`（目标、子目标、当前观察、前一步动作与结果、任务进度、相关实体、未解决的信息需求）。
- 将观察和行动结果分解为原子候选写入，每个候选分配**唯一的主要功能角色**。
- 同一观察可能产生多个银行候选；更新前进行有效性检查、去重和冲突消解。
- 更新策略因银行而异：Task State覆盖旧快照，Constraint合并重复项，Episodic按时间追加，Reference合并事实并更新冲突信息。

**（3）双频带记忆表示（Dual-Band Representation）**

- 每条记忆 `mi` 有两种表示：**焦点形式（focal）**——保留完整内容，直接支持行动；**环境形式（ambient）**——使用确定性模板生成简洁提示，只保留关键实体/关系。
- 银行和频带是两个正交维度：前者决定决策功能，后者决定呈现形式；记忆可在两频带间切换而无需重新提取或分类。

**（4）决策相关性信号**

- **库级需求 `d_b,t`**：评估当前步骤对某个功能记忆角色的整体需求。Goal看子目标完成状态；Task State看状态快照的新近度；Constraint看是否有约束适用于当前子目标或上一步结果；Episodic综合上一步异常结果和过往事件与当前子目标的相关性；Reference关注未解决的信息需求。
- **条目级相关性 `η_i,t`**：评估具体记忆条目对当前决策的贡献。各银行根据自身功能特性计算（如Goal看与当前子目标的对齐度，Episodic看子目标相似性和错误恢复效用，Reference看与未解决需求的信息兼容性）。

**（5）时间呈现门控（Temporal Presentation Gate）**

- 状态更新公式：`z_i,t = G_b(i)( z_i,t-1, d_b(i),t, η_i,t, h_i,t-1 )`，其中 `z` 取值为 F（焦点）、A（环境）、H（隐藏）三种状态。
- **状态转移规则**：强支持当前决策的记忆被分配/保留在焦点；仍有价值但非紧急的记忆以环境形式呈现；当前相关性不足的记忆被隐藏；焦点记忆若相关性持续下降则被降级。
- **角色特异性保护**：Goal和Constraint在完成、取代或失效前受保护，不受普通时间衰减影响；Task State始终对应最新快照；Episodic和Reference动态调整。
- **设计动机**：若每步独立决定呈现形式，瞬时波动可能导致有价值信息过早移出显著位置或频繁切换频带。

**（6）提示组装（Prompt Assembly）**

- 按银行分组，焦点条目以完整形式优先呈现，环境条目使用简化表示，同一频带内按条目相关性排序，隐藏条目被排除。
- 最终生成结构化记忆提示 `Pt`，与当前观察 `ot` 共同输入动作生成模型：`at ~ πθ(I, g, ot, Pt)`。

## 6. 论文的主要结论与发现

- **核心结论**：功能感知的记忆仲裁能有效弥合记忆-行动鸿沟，使已可访问的信息更好地引导长时程任务中的决策。
- **主实验结果**：
  - 500 token预算下，MemArbiter成功率82.84%，比最强基线Flat Retrieval高20.90个百分点。
  - 750 token预算下，成功率92.54%，比Flat Retrieval高25.38个百分点。
  - 增加预算对扁平基线提升有限，说明额外容量的价值在于结构化组织而非单纯积累。
- **任务类型差异**：改进覆盖所有任务类型；在Pick Two任务上效果最显著（基线为0%，MemArbiter达58.82%/70.59%），这类任务需要协调多个中间状态。
- **步数效率**：MemArbiter在相同步数限制下完成任务更多，说明高成功率不只是靠更多行动换取的。
- **跨模型泛化**：GPT-5.4上MemArbiter的SR@50达83.58%，仍超越基线10-13个百分点。
- **消融结果**：
  - 去掉功能银行：SR@50下降15.68个百分点（差距随交互变长而扩大）。
  - 去掉动态信号：SR@50下降17.17个百分点（最大降幅）。
  - 去掉时间门控：SR@15上升2.98但SR@50下降8.96（门控对长序列更关键）。
- **失败恢复**：一步恢复率最高，失败动作重复率最低；Episodic记忆在失败后提示中占比明显上升（500预算时+3.3个百分点），而w/o Temporal Gate变体几乎无变化（+0.2），提示时间门控与失败敏感性呈现之间存在关联。

- **单次运行无方差**：每组任务仅运行一次，虽然temperature=0有助复现，但无法评估随机性对结果的影响，也无统计显著性检验。

- **诊断证据是关联性的**：论文自身承认，Episodic份额增加与恢复率提高之间是相关关系，未通过受控干预证明因果性。

### 方法限制
- **显式角色设计**：五个记忆银行和相关信号是人工预设的，需要领域知识，无法自动适应新场景的决策功能需求。
- **依赖LLM做解析和候选提取**：Candidate Writer和状态解析使用Qwen3.6，其提取质量可能成为性能上限瓶颈；换用更强/更弱的解析模型可能改变结果。
- **额外计算开销**：相比扁平基线，MemArbiter每步需额外调用LLM进行状态解析、候选写入和相关性评估，推理成本和延迟更高，论文主要报告效果提升，未充分讨论该开销对实际部署的影响。
- **预算上限有限**：最大评测预算为750 token，未探索更大预算下的表现是否持续提升或饱和。

### 偏差风险
- **任务复杂性偏差**：Pick Two任务上基线全部失败，而MemArbiter表现良好，说明该方法在处理多状态协调任务上有优势，但这是否能泛化到其他复杂类型任务（如需要长链推理或多目标权衡的任务）不明确。
- **实现复杂度偏差**：MemArbiter的内部组件比基线复杂，额外LLM调用本身可能提供隐式的“思考时间”优势，不完全等同于纯记忆管理效果。
