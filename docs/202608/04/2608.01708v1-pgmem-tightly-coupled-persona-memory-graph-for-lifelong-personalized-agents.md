## 摘要
长期个性化对话智能体必须随着用户人格的演变而追踪其偏好。现有的记忆系统能很好地组织过去的事件，但将人格存储为与事件脱节的平面档案，而这些事件正是人格的佐证。这种松耦合导致了记忆-人格有效性差距和人格感知检索差距。我们提出PGMem，一种异质人格-记忆图，通过类型化的出处边和证据边连接事件节点与人格节点，使每个人格信号可追溯到支持或修正它的事件。在检索时，PGMem从查询相关的种子节点扩展，并根据证据有效性对信号进行排序。在三个使用小语言模型骨干的基准测试中，PGMem持续优于基于摘要、人格感知、图结构和智能体记忆的基线，并且随着上下文增长而提升性能。PGMem的源代码可在https://github.com/wonjunchoi23/pgmem/获取。

## Abstract
Long-term personalized dialogue agents must track user preferences as their personas evolve. Existing memory systems organize past events well, but store personas as flat profiles detached from the events that justify them. This loose coupling leads to the memory-persona validity gap and the persona-aware retrieval gap. We propose PGMem, a heterogeneous persona-memory graph that connects event and persona nodes through typed provenance and evidence edges, keeping each persona signal traceable to the events that support or revise it. At retrieval time, PGMem expands from query-relevant seeds and ranks signals by evidential validity. Across three benchmarks with small language model backbones, PGMem consistently outperforms summary-based, persona-aware, graph-structured, and agentic memory baselines, and improves performance as the context grows. The source code of PGMem is available at https://github.com/wonjunchoi23/pgmem/

## 2. 论文提出的方法论：PGMem

### 2.1 核心思想
PGMem 构建一个**异构人格–记忆图**，将事件级节点与人格级节点通过两类有向边连接：
- **出处边（SOURCE）**：记录高层节点由哪些低层节点归纳而来；
- **证据边（EVIDENCE）**：标记节点间“支持 / 矛盾 / 转移”等证据关系。

### 2.2 节点设计与边类型
- **事件级节点**：
  - `Context`：单轮原始对话；
  - `Episode`：连续对话片段的摘要。
- **人格级节点**：
  - `State`：短期的、时点相关的用户状态（如当前偏好、约束、目标）；
  - `Trait`：从长期对话中抽象出的稳定人格假设。
- **证据边类型**：
  - `SUPPORT (⊕)`：一致/互相强化；
  - `CONTRADICT (⊖)`：冲突/挑战；
  - `SHIFT_TO (⇝)`：更新/替代，新信号取代旧信号；
  - `IRRELEVANT (∅)`：无关关系，不参与检索，但避免重复判断。
- 每个节点还带有关键词集合、领域标签等元数据，供检索使用。

### 2.3 构建过程（增量式）
- 每个对话轮生成 `Context`；若用户话语含人格信号则提取 `State`；
- 在 chunk 边界汇总出 `Episode`；
- 每 `B` 个 chunk，从积累的状态/事件中提取 `Trait`；
- 新节点与已有候选节点两两做关系分类，并周期性补充“远程关系”判断（离线更新），形成多跳证据路径。

### 2.4 检索过程（三阶段）
1. **种子检索（Seed Retrieval）**：
   - 对四类节点分别计算组合分数  
     \[
     \phi(q,v)=w_{sem}\cdot \text{sem}(q,v)+w_{ov}\cdot \text{ov}(q,v)
     \]
     其中 `sem` 是嵌入余弦相似度，`ov` 是词级别的词汇重叠度，并按 `SCOPE` 调整权重；
   - 每类各取 top-k 作为种子，并额外维护一个“活跃人格集（APS）”，保证高优先级 `State` 被保留。
2. **证据引导的图扩展（Evidence-Guided Expansion）**：
   - 将 `Context` 种子替换为经由 `SOURCE` 边相连的 `Episode/State/Trait` 节点；
   - 沿 `SUPPORT` 和正向 `SHIFT_TO` 边以“正号”继续传播；沿 `CONTRADICT` 和反向 `SHIFT_TO` 以“负号”传播并终止路径；
   - 符号满足 \(s^+ \circ s^+ = s^+,\ s^+ \circ s^- = s^-\)，最多扩展 `H=10` 跳。
3. **有效性感知的最终组装（Validity-Aware Final Assembly）**：
   - 删除在扩展中被新信号取代的旧 `SHIFT_TO` 来源；
   - 对任意节点 \(v\)，统计从其可达的“支持路径数量 |S(v)|”和“矛盾路径数量 |C(v)|”，计算有效性分数：
     \[
     \text{val}(v)=\frac{|S(v)|+\alpha}{|S(v)|+|C(v)|+2\alpha}
     \]
   - 最终按  
     \[
     \psi(q,v)=\lambda\,\text{val}(v)+(1-\lambda)\,\phi(q,v)
     \]
     排序并取预算内的证据，按类型/状态序列化后送入生成 prompt。

## 3. 实验设计

### 3.1 数据集 / Benchmark
- **ImplexConv（opposed 子集）**：300 个会话实例、1259 条 QA，测试隐式人格推理，即查询与所需人格信号在语义上相距较远。
- **PrefEval（多人设交织设置）**：100 个会话、5050 条 QA，将多个独立人格会话拼接，测试能否在查询时正确选择该会话对应的人格知识。
- **PersonaMem**：动态用户画像基准，使用 32k 和 128k 两种历史长度设置，报告四选一问答准确率。

### 3.2 对比基线
- `Full History`（无外部记忆的完整历史输入）
- `MemoryBank`（摘要式长期记忆）
- `LD-Agent`（人格感知个性化智能体）
- `THEANINE`（时间图结构记忆）
- `A-MEM`（智能体式笔记记忆）
- 附录中另有 `SeCom`、`H2Memory` 作为补充强化基线的对比。
- 所有方法均在相同骨干（`Qwen3-1.7B`、`Gemma-3-1B`，以及 4B 扩展实验）和相同 embedding（`all-MiniLM-L6-v2`）下运行。

### 3.3 评估指标
- ImplexConv 与 PrefEval：采用 LLM-as-a-judge（`gpt-4o-mini`，温度 0）的四维二分清单打分，合计 0–4 分；
- PersonaMem：四选一精确匹配准确率。

## 6. 论文的主要结论与发现

- PGMem 在所有三个基准、两个 SLM 骨干下均超过摘要式、人格感知、图结构和智能体记忆基线；在 ImplexConv 上比最强基线最高提升 29%，在 PrefEval 上最高提升约 59%。
- PGMem 在**上下文增长时优势扩大**：ImplexConv 上随着对话轮数增加、PrefEval 上随着交织人格会话增多，PGMem 的 margin 保持稳定甚至扩大；在 PersonaMem-128k 上，PGMem 是唯一在 Qwen3-1.7B 下仍能提升的模型，其他基线均退化。
- 消融实验表明：
  - **人格级节点**是最关键组件，移除后各 benchmark 下降最大；
  - **证据边（尤其 `CONTRADICT` 和 `SHIFT_TO`）** 在人设冲突与演化的长上下文场景中贡献显著；
  - **图扩展**在长历史下比短历史下更重要。
- 效率上，PGMem 构建图的 token 总消耗低于 A-MEM 和 THEANINE，QA 阶段 token 与调用次数也保持较低水平，适合资源受限的 SLM 场景。

## 7. 优点

- **方法创新的系统性**：将“记忆”与“人格”纳入同一个证据图，显式建模支持/矛盾/转移关系，首次将终身个性化定义为“证据化人格管理”，而非简单档案累积。
- **检索机制设计精巧**：带符号的多跳扩展和有效性分数，能把“表面不相关但人格关键”的事件召回，同时抑制过时人格信号。
- **对 SLM 友好**：在小骨干下表现显著，说明记忆结构而非模型容量承载了个性化能力。
- **实验全面**：涵盖多基准、多骨干、消融、敏感性、效率、人工校验、案例研究，代码开源，可复现性强。
- **隐私与可维护性**：人格存储为独立可读节点，用户可删除单个信号，低有效性/被取代节点可自动裁剪，便于隐私与生命周期管理。

## 8. 不足与局限

- **证据关系标注可靠性有限**：论文自身的人类验证显示，`CONTRADICT` 标注准确率仅 36%、`SHIFT_TO` 为 52%，明显低于 `SUPPORT`（80%）和 `IRRELEVANT`（84%）。尽管作者论证其对整体性能影响有界，但不可靠的关系标签仍是重要的噪声源。
- **数据局限**：所有实验基于合成基准，缺乏真实的、有自然人格演化的长期对话数据；真实场景中的隐私与稀疏性可能改变行为。
- **超长期生命周期缺失**：只验证了有限长度的上下文；数月/数年的对话会积累大量节点和边，论文尚未实现剪枝、合并、衰减等生命周期策略。
- **时间建模较弱**：仅使用相对顺序编码时序，未建模真实的绝对时间/间隔衰减，难以处理时间敏感的偏好变化。
- **大骨干下优势减弱**：在 4B 骨干的 PersonaMem 上 PGMem 不如 A-MEM，说明其对骨干能力的依赖方式还需要进一步适配。
- **生成侧失败**：案例分析显示，即使检索到正确人格信号，生成阶段也可能只做表面提及、未在实质建议中体现（near-miss 模式），说明检索正确并不保证响应正确。
- **消融不完整**：主要消融只在单骨干上报告，缺少跨骨干的消融一致性验证。
