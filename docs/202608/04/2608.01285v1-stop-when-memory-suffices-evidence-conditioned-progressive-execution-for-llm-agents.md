## 摘要
LLM向持久性和适应性智能的持续发展，越来越需要能够在交互中保留和重用信息的长期记忆机制。现有记忆系统要么压缩和结构化历史以实现高效访问，要么对更广泛的轨迹进行深度研究。前者降低了在线成本，但可能遗漏时间、因果或跨步骤依赖关系；后者以显著的延迟和推理成本提高了证据覆盖率。这引出了一个关键问题：记忆系统能否在保持低在线延迟的同时实现强答案质量？我们引入了Router-Mem，一种用于长时程智能体记忆的证据条件驱动渐进式执行框架。Router-Mem首先应用共享的低成本检索前缀来获取证据。然后，一个轻量级的充分性路由器预测上下文是否支持提前终止，从而在推理时实现单令牌决策。它通过证据级监督和基于理由的条件表示蒸馏进行训练。当证据不足时，Router-Mem重用检索命中来扩展记忆块，并执行更深入的分析和聚合。在AMA-Bench和BEAM上的实验表明，与完整记忆执行相比，Router-Mem获得了55.17%和38.77%的得分，同时平均推理时间分别减少了27.3%和25.5%。

## Abstract
The continued development of LLMs toward persistent and adaptive intelligence increasingly requires long-term memory mechanisms that preserve and reuse information across interactions. Existing memory systems either compress and structure histories for efficient access or perform deep research over broader trajectories. The former lowers online cost but may omit temporal, causal, or cross-step dependencies, while the latter improves evidence coverage at substantial latency and inference cost. This raises a key question: can a memory system achieve strong answer quality while maintaining low online latency? We introduce Router-Mem, an evidence-conditioned progressive execution framework for long-horizon agent memory. Router-Mem first applies a shared low-cost retrieval prefix to obtain evidence. A lightweight sufficiency router then predicts whether the context supports early termination, which enable a single-token decision at inference time. It is trained with evidence-level supervision and rationale-conditioned representation distillation. When evidence is insufficient, Router-Mem reuses retrieval hits to expand memory blocks and perform deeper analysis and aggregation. Experiments on AMA-Bench and BEAM show that Router-Mem achieves 55.17\% and 38.77\% score while reducing average inference time by 27.3\% and 25.5\% compared with full memory execution.

- **核心研究问题**：能否让记忆系统根据查询和轻量检索已获得的证据，自主推断所需的处理深度——证据已充分时及早终止，证据不足时再进行深度分析，从而同时实现高答案质量与低在线延迟？

### 2. 方法论：Router-Mem 渐进式执行框架

#### 核心思想

Router-Mem将记忆访问组织为**证据条件驱动的渐进式执行**过程：所有查询先执行共享的低成本检索前缀；随后轻量路由器根据查询与检索到的证据预测是否可提前终止；不能终止时，系统复用检索命中作为定位信号，扩展记忆块并执行深度分析与聚合。

#### 关键流程（算法流程文字描述）

1. **共享检索前缀**：给定查询 \( q \) 与有序记忆 \( M \)，共享检索器 \( R_f \) 返回初始证据上下文 \( C_f \) 及命中信息 \( H_f \)。
2. **证据充分性路由**：轻量路由器 \( s_\theta(q, C_f) \) 计算提前终止得分 \( s = \text{pyes}/(\text{pyes} + \text{pno}) \)。若 \( s \ge \tau \)，则基于检索上下文直接生成答案（早退）；否则进入续作阶段。
3. **检索引导的续作**：将检索命中映射到对应记忆块，选择锚点块及其时间邻域，由多个记忆智能体并行分析各块，聚合结果后生成最终答案。
4. **快慢路径耦合**：两条路径共享同一检索前缀，续作阶段从已有检索结果出发继续展开，不重启搜索。

#### 训练方法

- **证据充分性数据构建**：
  - 正样本：支持证据完整 + 干扰步骤；
  - 负样本：移除部分/全部关键证据 + 语义相关的硬负样本；
  - 用多个答案模型验证负样本确实不可回答，教师模型生成解释性理由。
- **路由器训练**：
  - 分组令牌分类损失（grouped-token loss）：基于“yes”/“no”令牌组的概率进行二分类；
  - 理由条件表示蒸馏（rationale-conditioned representation distillation）：冻结教师模型读取理由文本，学生模型仅见 \( (q, C_f) \)，在中间层对齐表示；
  - 最终目标：\( L = L_{cls} + \lambda_{\text{rep}} s_0 L_{\text{rep}} \)。
- **共享检索器训练**：基于多正样本对比损失，检索答案支撑证据。

### 6. 主要结论与发现

- Router-Mem在AMA-Bench上达到55.17%得分，在BEAM上达到38.77%得分，相比Full Completion（完整记忆执行），平均推理时间分别减少**27.3%**和**25.5%**。
- 在不同阈值下形成平滑的质量–成本帕累托前沿，\( \tau = 0.5 \) 是性价比最优工作点之一：AMA-Bench上仅比全量执行低1.32分，但 \( T_{\text{mem}} \) 从11.34s降至8.25s。
- 路由器训练有效校准快速/慢速路径决策边界：AMA上纠偏过度保守的“慢路径偏好”，BEAM上纠正过度自信的“快路径偏好”。
- 联合训练（路由器 + 检索器）使 \( \tau \) 成为有效的质量–延迟控制旋钮。
