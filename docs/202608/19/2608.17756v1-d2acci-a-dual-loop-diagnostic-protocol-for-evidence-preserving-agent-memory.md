## 摘要
记忆是LLM智能体的关键能力。持久记忆将该能力扩展至跨会话场景——实现回忆、修订与个性化。然而，其多阶段流水线（摄取、检索、过滤、生成）使得故障难以定位：端到端评估仅能表明发生了错误，却无法指出由哪个阶段导致。现有评估通常报告总体性能，而缺乏配对统计比较、切片级非回归检查或阶段级诊断追踪。我们提出D$^2$ACCI（诊断驱动、基于产物、闭环控制迭代），一种双循环协议，其外部诊断门根据配对证据、受保护切片监控和追踪级可定位性，对记忆干预进行提升、特征标记或拒绝。我们进一步引入DCR，一种分级可观测性度量，用于衡量故障是否仍可定位，以及D$^2$ACCI-Eval，一种用于门重放的可复用产物。我们在MemStack中实例化该协议，并在三个公开基准上评估，在LoCoMo上达到93.59%，在LongMemEval上达到90.93%，在PersonaMem-V2上达到57.20%。五项配对消融实验表明，补充抽取、会话记忆检索和遗忘防护带来统计显著的增益（+1.9至+3.7个百分点，所有p≤.003）。相比之下，BM25/RRF被保留为受监控的特性标志——这一区别在仅聚合评估中不可见。诊断审计显示，相较于仅结果重新标记，丰富追踪显著提升了根本原因一致性。诊断产物的DCR@3达到98–100%，而仅结果日志为0%。这些结果证实，稳健的记忆系统迭代需要可追踪、统计基础扎实且具有回归意识的证据——这正是D$^2$ACCI所填补的空白。

## Abstract
Memory is a key capability of LLM agents. Persistent memory extends this across sessions---enabling recall, revision, and personalization. Yet its multi-stage pipeline (ingestion, retrieval, filtering, generation) makes failures difficult to localize: end-to-end evaluation reveals that an error occurred, but not which stage caused it. Existing evaluations often report aggregate performance without paired statistical comparisons, slice-level non-regression checks, or stage-level diagnostic traces. We propose D$^2$ACCI (Diagnostic-Driven Artifact-based Closed-loop Controlled Iteration), a dual-loop protocol whose outer diagnostic gate promotes, feature-flags, or rejects memory interventions based on paired evidence, protected-slice monitoring, and trace-level localizability. We further introduce DCR, a graded observability metric that measures whether failures remain localizable, and D$^2$ACCI-Eval, a reusable artifact for gate replay. We instantiate the protocol in MemStack and evaluate on three public benchmarks, achieving 93.59% on LoCoMo, 90.93% on LongMemEval, and 57.20% on PersonaMem-V2. Five paired ablations show that supplement extraction, session-memory retrieval, and Forget Guard yield statistically significant gains (+1.9 to +3.7pp, all p $\le$ .003). In contrast, BM25/RRF is retained as a monitored feature flag---a distinction invisible to aggregate-only evaluation. A diagnostic audit shows enriched traces substantially improve root-cause agreement over result-only relabeling. Diagnostic artifacts reach 98--100% DCR@3 versus 0% for results-only logs. These results establish that robust memory-system iteration demands traceable, statistically grounded, and regression-aware evidence---exactly the gap D$^2$ACCI fills.

## 1. 核心问题与整体含义（研究动机与背景）

- **研究背景**：LLM 智能体的持久记忆（persistent memory）是跨会话实现回忆、修订和个性化的关键能力。然而，持久记忆系统通常由多阶段流水线构成（摄取 ingestion、检索 retrieval、过滤 filtering、生成 generation），任一环节出错都可能导致最终答案错误。
- **核心问题**：
  - 端到端评估只能发现“错误发生了”，却无法定位“错误由哪个阶段导致”；
  - 现有评测大多只报告聚合准确率，缺乏配对统计比较、切片级非回归检查、阶段级诊断追踪；
  - 记忆系统迭代是一个“部署问题”而非单纯“基准问题”：某个干预可能在整体指标上提升，却暗中损害特定任务切片（如时序推理、偏好保真度），或不可复现、不可归因。
- **整体含义**：作者主张应将智能体记忆视为“可演化的运行时系统”，其迭代需要可追踪、统计扎实、回归感知的证据。现有聚合指标驱动的开发方式不足以支撑可靠的记忆系统演化，亟需一种系统化的诊断与决策协议。

## 2. 提出的方法论：D²ACCI 双循环诊断协议

- **总体框架**：D²ACCI（Diagnostic-Driven Artifact-based Closed-loop Controlled Iteration，诊断驱动、基于产物、闭环控制迭代）将记忆系统迭代分为两个循环：
  - **内循环（运行时）**：执行记忆增强智能体的完整流水线（摄取、存储、检索、过滤、上下文组装、生成），并在每个阶段边界发射类型化诊断追踪（trace）。
  - **外循环（诊断演化）**：基于配对产物（paired artifacts）进行统计检验、保护切片检查、DCR 覆盖评估、根因审计，最终给出“接受（Accept）/ 特性标志（Feature-Flag）/ 拒绝（Reject）”的决策，并更新内循环的特性标志。
- **关键概念**：
  - **诊断状态**：每个样本记录 `di = (eraw_i, estore_i, rtop-k_i, ffilter_i, cctx_i, ggen_i, ji)`，即原始证据、存储记忆、检索结果、过滤决策、组装上下文、生成答案和最终判定。
  - **配对比较**：将候选配置 θ′ 与基线 θ 在相同样本上配对，划分为改进（I）、退化（R）、双错（Bw）、双对（Bc）四类。
  - **根因标签**：对每个实质退化或持续错误，标记最早可操作的失败阶段：摄取遗漏、检索遗漏、上下文组装错误、约束错误、生成错误、组件危害、未解决歧义。
- **决策契约（Algorithm 2）**：外部门控按以下顺序执行检查：
  1. 报告不完整 → 特性标记；
  2. 显著危害（Δ<0 且 p≤α 且置信区间上界<0）→ 拒绝；
  3. DCR 低于阈值（τ < ρ_min）→ 特性标记（保证可观测性）；
  4. 统计不显著或置信区间跨零 → 特性标记（证据不足）；
  5. 存在保护切片回归（Δπ < −ε）→ 接受但需监控；
  6. 否则 → 接受。
- **DCR 度量**：诊断覆盖率（Diagnostic Coverage Rate, DCR）衡量失败样本中至少 τ 个阶段可由追踪定位的比例。DCR 具有阶段单调性、与准确率正交、门控可靠性三项设计性质。
- **D²ACCI-Eval 产物**：可重用的评估工具，支持配对统计、切片检查、不一致样本导出、确定性门重放，并保留正/零结果供后续迭代复用。
- **MemStack 实例化**：多粒度记忆内核（L0 原子事实、L1 主题汇聚、L2 用户画像、会话记忆），各阶段均可通过特性标志独立开关（补充抽取、会话检索、BM25/RRF、遗忘防护等），确保每个消融对应明确失败模式。

## 6. 主要结论与发现

- D²ACCI 能够区分“统计有效的改进”与“无效/不可观测的变化”，避免仅凭聚合指标做出错误决策。
- 在 MemStack 上，补充抽取（+2.71pp，p=.0009）、会话记忆检索（+3.67pp，p=.0026）、遗忘防护（+1.92pp，p=.0030）均带来统计显著提升；
- BM25/RRF 在两个基准上均为零结果，被保留为“受监控特性标志”，而简单的指标驱动策略会对同一组件给出“提升/降级”的矛盾结论。
- 诊断追踪显著提升根因定位一致性：富追踪下 GPT-4o 重标 κ=0.571/0.619，仅结果下仅 0.258/0.272；
- DCR@3 在诊断产物上达到 98–100%，而仅结果日志为 0%——证明标量结果无法提供阶段级可定位证据。
- PersonaMem-V2 失败分析显示 57.1% 的错误源于生成/选项评分，29.8% 源于约束处理，仅 13.0% 源于检索，约 87% 位于记忆可寻址范围之外；这一诊断可避免在错误方向上的工程投入。
- 门重放可自动复现人类迭代决策（LoCoMo t0–t5 全部匹配，包括 t3 拒绝），证明协议可支撑自动化记忆系统演化。

## 7. 优点

- **方法论创新**：将“配对统计 + 切片监控 + 追踪覆盖”绑定为正式决策契约，比单纯 A/B 测试或聚合指标更严谨。
- **双循环架构分离**：内循环运行、外循环诊断，结构清晰，易于落地；特性标志实现低成本配对消融。
- **可观测性度量 DCR**：作为准确率之外的正交指标，能识别“高准确但难调试”的系统，具有阶段单调性等优良性质。
- **产物可复用性**：D²ACCI-Eval 支持门重放、历史证据归档、零结果保留，保证迭代可复现。
- **实验客观性**：保留负结果，不夸大外部对比，明确区分参考点与受控配对证据；审计验证了追踪的实际价值。
- **实践洞察**：通过失败边界分析区分“记忆可修复”与“生成瓶颈”，避免盲目优化记忆组件。

## 8. 不足与局限

- **硬件资源未披露**：没有给出 GPU/训练时长等算力信息，限制了复现成本估计和公平比较。
- **外部对比非严格受控**：与 MemBrain 等参考系统的数字来自公开资料，模型、提示、检索预算等未完全对齐，只能作参考。
- **审计规模有限**：60 例根因标签审计样本量较小，可能降低统计功效；人类标注未显示最终仲裁结果。
- **跨基准复制不完整**：某些消融只在单一基准上验证（如 No Session 仅 LongMemEval），跨基准泛化性未充分展示。
- **零结果解释谨慎**：BM25/RRF 的零结果仅表示“无充分证据支持提升”，不能证明其绝对无效；但作者已声明这一解读。
- **DCR 定义依赖人工设定可操作性谓词**，其阈值（ρ_min=0.90）需预先指定，不同系统可能需要调整。
- **自动化的边界**：虽然门重放可复现决策，但根因标签仍然依赖规则或模型，最终修复措施仍需要人工判断。
