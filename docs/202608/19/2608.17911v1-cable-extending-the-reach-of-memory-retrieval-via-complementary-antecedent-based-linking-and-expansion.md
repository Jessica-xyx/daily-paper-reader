## 摘要
随着LLM智能体在结构化工作流和会话中运行，保留长期历史并不能确保后续上下文能够通过有界的记忆接口恢复相关证据。我们研究了长期会话记忆中的这种证据可达性问题，其中检索仍然严重依赖语义相似性。这在主题回忆中效果良好，但常常遗漏早期经验、计划或动机，这些内容与它们帮助解释的后续事件在语义上相距甚远。现有的记忆图提供了跨记忆结构，但主要由语义重叠驱动的连接可能会重复宿主检索器已经恢复的内容。我们认为，连接构建应优先考虑一组稀疏的、与检索器互补的关联。我们提出了CABLE（Complementary Antecedent-Based Linking and Expansion，基于前因的互补连接与扩展），这是一种插件式增强方法，构建旨在扩展宿主检索器直接语义覆盖范围的连接。对于每条新记忆，CABLE生成面向前因的查询，检索先前记忆，减去直接语义邻域中的候选，并在将接受的互补关联添加到稀疏有向图之前验证其余部分。在检索时，CABLE沿这些连接扩展宿主系统检索到的种子，以揭示隐式支持证据。我们使用A-MEM在LoCoMo和MA-LongMemEval上评估CABLE，并进一步将其集成到LoCoMo上的SimpleMem和Mem0g中，使用Qwen3.5-27B、DeepSeek-chat和GPT-4o-mini。CABLE在每一个评估的系统级设置中均获得更高的平均LLM评判分数，在有用证据分布在不同记忆或会话中的类别中提升最大，包括开放域、多会话和偏好导向的问题。这些结果支持优先考虑稀疏的、与推理相关的关联，这些关联补充而非重复宿主检索器。

## Abstract
As LLM agents operate across structured workflows and sessions, preserving long-term history does not ensure that later contexts can recover relevant evidence through a bounded memory interface. We study this evidence-reachability problem in long-term conversational memory, where retrieval still relies heavily on semantic similarity. This works well for topical recall, but it often misses earlier experiences, plans, or motivations that are semantically distant from the later events they help explain. Existing memory graphs provide cross-memory structure, yet links driven mainly by semantic overlap can duplicate what the host retriever already recovers. We argue that link construction should instead prioritize a sparse set of retriever-complementary associations. We present CABLE (Complementary Antecedent-Based Linking and Expansion), a plug-in augmentation that constructs links designed to extend the host retriever's direct semantic reach. For each new memory, CABLE generates antecedent-oriented queries, retrieves prior memories, subtracts candidates in the direct semantic neighborhood, and verifies the remainder before adding the accepted complementary associations into a sparse directed graph. At retrieval time, CABLE expands the host system's retrieved seeds along these links to surface implicit supporting evidence. We evaluate CABLE with A-MEM on LoCoMo and MA-LongMemEval, and further integrate it into SimpleMem and Mem0g on LoCoMo, using Qwen3.5-27B, DeepSeek-chat, and GPT-4o-mini. CABLE yields higher mean LLM-judge scores in every evaluated system-level setting, with the largest gains in categories where useful evidence is distributed across memories or sessions, including open-domain, multi-session, and preference-oriented questions. These results support prioritizing sparse, reasoning-relevant associations that complement rather than duplicate the host retriever.

## 1. 核心问题与整体含义

- **研究背景**：LLM 智能体越来越多地以执行图（execution graph）的形式跨组件、跨会话运行，长期历史无法始终保持在单一提示词内，需要通过有界的记忆接口从外部存储中恢复相关证据。
- **核心问题（证据可达性问题）**：仅仅“存储了历史”并不等于“后续查询能检索到相关证据”。在长程会话记忆中，检索高度依赖语义相似度（embedding 相似性），这能应对主题型回忆，但常常错过在语义上与后续事件相距较远、却能解释该事件的早期经验、计划、动机或背景信息。
- **现有方法的不足**：已有记忆图系统（如 A-MEM、Mem0 图变体、HippoRAG 等）提供了跨记忆结构，但链接主要由语义重叠或实体重叠驱动，往往只是重复宿主检索器已经能直接命中的记忆。在固定上下文预算下，冗余邻居会挤占更有用证据的位置，无法真正扩展系统的“有效触达范围”。
- **论文主张**：记忆图中的链接应遵循**检索器互补性（retriever complementarity）**原则——关联的价值在于暴露宿主检索器直接语义邻域之外的证据，而非构建一个面面俱到的世界模型。基于此提出了 CABLE，作为现有记忆系统的插件式增强，扩展其对语义疏远但推理相关证据的恢复能力。

## 2. 方法论

- **核心思想**：为每条新记忆构建指向旧记忆的“前因链接”（antecedent links），并以“减重”（overlap subtraction）保证这些链接不重复宿主检索器已能命中的内容；检索时沿链接扩展种子记忆，从而找出语义上距离较远但对当前问题具有解释力的证据。
- **构建阶段（Construction-time）**：
  1. **前因导向查询生成**：规则过滤器去除问候等低信息量记忆；LLM 将记忆分类为 `event`、`opinion`、`plan`、`state_change` 等操作类型，按类型生成最多 3 条前因查询（如事件的前导事件、动机、过往经历等）。
  2. **双路检索（Dual Retrieval）**：直接检索——用新记忆 mi 的嵌入在历史记忆 M<i 中检索 top-Kb 得到 Bi（直接语义邻域）；前因检索——用每条前因查询分别检索 top-Kh，合并为 Hi。
  3. **重叠相减（Overlap Subtraction）**：取 Ci = Hi \ Bi，剔除直接检索已能命中的候选，仅保留“检索器互补”候选；若 Ci 为空，则不为该记忆添加任何边。
  4. **验证与建图（Verification & Graph Update）**：LLM 验证每个候选 mj 是否构成有用前因（如远因、背景、动机、角色弧线、多跳证据），拒绝仅基于主题共现或实体重叠的弱关联；接受后添加稀疏有向边 mj → mi。
- **检索阶段（Retrieval-stage expansion）**：
  - 种子选择：仅保留宿主检索结果 R0 中与查询余弦相似度 ≥ τ 的种子 S。
  - 候选收集与打分：取每个种子的单跳图邻域（含入边和出边），排除已在 R0 中的记忆；候选得分为其所有相连种子与它的余弦相似度之和：score(c) = Σ_{s∈S, c∈N(s)} sim(φ(c), φ(s))。
  - 新颖性过滤（Novelty Filtering）：按得分贪心选取候选，仅当候选与当前结果集中所有条目的最大相似度 < θ 时接受，避免近重复。
  - 在 A-MEM 和 Mem0g 中，CABLE 在固定检索条目预算下替换低排名基线条目（如最多替换 5 条），不增加上下文长度；SimpleMem 则仅在反思步骤判定基线检索不充分时激活 CABLE。
- **成本特性**：构图阶段每条新记忆至多考虑 Nq×Kh 个候选、每条记忆有界的 LLM 调用（一次类型分类、一次查询生成、每候选一次验证），构建成本按记忆数摊销；边总数 O(|M|) 线性增长；检索时无需额外 LLM 调用，仅做邻居枚举、嵌入相似度打分和过滤。

## 3. 实验设计

- **评测基准**：
  - **LoCoMo**：排除对抗性拆分，报告四个可回答类别——Single-hop（841）、Multi-hop（282）、Temporal Reasoning（321）、Open-domain Knowledge（96），共 1540 题。
  - **MA-LongMemEval**：使用 MemoryAgentBench 重组的 5 个长对话上下文、300 个问题；报告六种非弃权类型——多会话（multi-session）、时间推理（temporal-reasoning）、知识更新（knowledge-update）、单会话用户（single-session-user）、单会话助手（single-session-assistant）、单会话偏好（single-session-preference）。
- **宿主记忆系统**（对比基线）：
  - **A-MEM**：自带动态链接的 agentic 记忆系统，检验 CABLE 在已有关联能力之上是否仍有效。
  - **SimpleMem**：多视图混合检索 + 反思式充分性检查的自适应检索系统，检验 CABLE 在更强基线下的通用性。
  - **Mem0g**：图增强记忆系统（显式实体关系图），检验 CABLE 与现有图系统的互补性。
- **骨干模型**：Qwen3.5-27B、DeepSeek-V3.2-chat（记作 DeepSeek-chat）、GPT-4o-mini；主流程（记忆提取、CABLE 构图、检索推理、答案生成）和 LLM 评判均使用同一骨干模型。
- **评估指标**：平均 LLM-judge 分数（百分比），评判模型对生成的答案相对参考答案进行语义正确性打分，保留原始分数不做二值化；基线与 +CABLE 使用相同的评判提示和评判模型。
- **集成协议**：A-MEM 和 Mem0g 使用受控的固定条目预算（A-MEM 45 条、CABLE 最多替换 5 条；Mem0g 共 20 条、替换最多 5 条）；SimpleMem 保留其自适应反思协议，仅在基线检索不充分时激活 CABLE。
- **实现超参**：Nq=3、Kb=Kh=15、扩展预算 5、τ=0.3、θ=0.9；嵌入模型 A-MEM 用 all-MiniLM-L6-v2，SimpleMem 和 Mem0g 用 Qwen3-Embedding-0.6B。

## 6. 主要结论与发现

- **总体效果**：CABLE 在所有 7 个系统级设置中均提升平均 LLM-judge 分数（A-MEM 上 +1.00 至 +6.00 pp；SimpleMem +0.58 与 +1.62 pp；Mem0g +2.20 pp）。
- **增益分布规律**：单跳类增益最小（直接语义检索已够用）；开放域类增益最大（LoCoMo 上 Qwen3.5-27B +6.24 pp，DeepSeek-chat +9.37 pp）；多会话和单会话偏好类增益显著（MA-LongMemEval 上 Qwen3.5-27B 分别 +12.00 和 +23.33 pp，GPT-4o-mini 对应 +2.66 和 +3.33 pp）。这与“证据分布在不同记忆/会话中时 CABLE 最有用”的假说一致。
- **例外情况**：MA-LongMemEval 上的时间推理类型在两种模型下均有小幅度下降（-1.33、-2.67 pp），作者解释关联扩展对依赖精确时间分辨的任务帮助有限。
- **消融结论**：重叠减法移除后 LoCoMo -0.91 pp、MA-LongMemEval -0.67 pp；验证步骤移除后造成 MA-LongMemEval 上最大退化（-2.66 pp），说明长历史中噪声候选更多、验证尤为重要；类型条件前因查询优于通用查询分解（LoCoMo 上 +0.46 pp）。
- **定性案例**：一个“为什么 Melanie 在陶艺中使用颜色和图案”的问题中，基线检索到主题相近的陶艺爱好记忆（无动机信息），而 CABLE 通过已存储的前因链接恢复了包含“吸引眼球、让人微笑”动机的远距离记忆，从“无法回答”变为可回答。
- **核心立场**：稀疏的、推理相关的、与宿主检索器互补的关联优于密集的、语义重叠驱动的图结构。

## 7. 优点

- **问题定位精准且规避了虚荣指标**：聚焦长期记忆系统中真实的“证据可达性”失败模式，而非单纯提高语义检索精度；用具体的 failure case（主题近但信息不足）说明语义相似 ≠ 信息相关。
- **原则清晰、实现轻量、即插即用**：将“检索器互补性”形式化为“先检后减再验”的构图流程，不修改宿主系统的记忆写入和答案生成，替换而非追加的预算控制使比较公平且不增加检索成本。
- **检索阶段零 LLM 调用**：构图时一次性支付推理成本，查询时仅做图遍历和相似度计算，时间开销可控。
- **实验设计较严谨**：多个系统、多个模型、两个基准、固定预算/受控协议、行内对比、消融实验和定性案例相互印证，结论可信度较高。
- **承认失败案例**：没有回避时间推理类别的退化，反而在文中明确说明，增强了工作的客观性与诚实度。

## 8. 不足与局限

- **实验覆盖仍受限**：仅覆盖长程会话记忆问答这一认知任务，未涵盖工具使用、多智能体协调、任务级执行图等更复杂的智能体工作流；结论是否能泛化到这些场景尚不明确。
- **算力与成本信息缺失**：未报告 GPU/训练时长、LLM API 调用总量或实际运行时间，无法评估 CABLE 在生产部署中的工程成本。
- **图缺少维护机制**：链接为 append-only，没有遗忘、衰减或更正机制；被后续记忆更正/取代的旧链接仍可能持续将过时证据送入上下文，长期运行时图会持续增大。
- **时间推理类别的下降未深入解决**：论文只给出“精确时间分辨任务不适用”的解释，没有提出适配时间推理的改进方案。
- **简单基线对比存在小规模类别误差风险**：部分类别（如 single-session preference、n=30）样本量过小，±23 pp 量级的变化虽符合总体模式，但置信区间会较宽。
- **同骨干模型同时承担构图验证与最终评判**，可能引入验证风格与评判偏好一致性的系统性偏差；不同系统使用不同嵌入模型也使得跨系统横向比较不严格。
