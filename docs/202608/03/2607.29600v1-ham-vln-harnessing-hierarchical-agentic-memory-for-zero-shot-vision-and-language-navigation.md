## 摘要
视觉-语言导航（VLN）使机器人能够在未见过的环境中遵循指令。最近出现了一种免训练范式：机器人查询多模态大语言模型以理解其观察并规划下一步动作。然而，基于图像流或密集地图的长时程导航不可避免地会引入不断增长的记忆与推理瓶颈。我们提出HAM-VLN，这是一种决策耦合的、由智能体自生成的记忆，使机器人具备持久且基于深度的世界图。在与选择下一步动作相同的模型调用中，HAM-VLN还会记录语义与反思信息——包括房间类型、物体、导航进度和失败备注。最近的路径点以逐字形式保留在受限窗口内，而更早的历史则仅通过与相关性、近因性和显著性评分相结合的检索，加上一跳拓扑扩展重新进入上下文。该设计在每次路径点决策之外不需要额外的大语言模型调用。与以往方法相比，HAM-VLN不仅提升了多项导航指标，还将上下文长度减少了超过65%。具体而言，HAM-VLN在VLN-CE R2R上实现了61.0%的成功率（SR），在VLN-CE RxR上实现了52.7%的SR，在HM3D-v2 ObjectNav上实现了79.7%的SR，无需任何训练。

## Abstract
Vision-and-language navigation (VLN) enables robots to follow instructions in previously unseen environments. Recently, a training-free paradigm has emerged: the robot queries a multimodal LLM to understand its observations and plan the next action. However, long-horizon navigation based on either image streams or dense map inevitably introduces a growing memory and reasoning bottleneck. We present HAM-VLN, a decision-coupled, agent-authored memory that equips the robot with a persistent, depth-grounded world graph. In the same model call used to select the next action, HAM-VLN also records semantic and reflective information---including room type, objects, navigation progress, and failure notes. Recent waypoints remain verbatim within a bounded window, while older history re-enters the context only through retrieval scored by relevance, recency, and salience, together with one-hop topological expansion. This design requires no additional LLM calls beyond the per-waypoint decision. Compared to previous methods, HAM-VLN not only improves various navigation metrics but also reduces the context length by more than 65%. Specifically, HAM-VLN achieves 61.0% Success Rate (SR) on VLN-CE R2R, 52.7% SR on VLN-CE RxR, and 79.7% SR on HM3D-v2 ObjectNav without any training.

# 《HAM-VLN：利用分层代理记忆实现零样本视觉-语言导航》论文总结

## 一、核心问题与研究动机

- **任务背景**：视觉-语言导航（VLN）要求机器人仅凭自然语言指令，在未见过的连续环境中导航至目标位置或物体。近年出现的“零样本”范式依赖多模态大语言模型（MLLM）直接理解观测并规划动作，无需训练。
- **瓶颈问题**：长时程导航中，如何向 LLM 提供“去过哪里、指令执行到哪一步、哪些分支失败过”等历史信息，同时避免上下文无限膨胀？已有两种经典表示均存在缺陷：
  - **密集语义地图**：存储量随环境面积增长，且建图过程与导航决策分离，难以直接将语言指令匹配到度量单元；
  - **原始视觉历史**：将过去全景图直接追加到上下文，重要地标被细节淹没，上下文随轨迹逐步增长，无法标记已失败分支。
- **核心思想**：将“记忆管理”纳入导航决策循环——让 MLLM 在选动作的同时自主写记忆，构建持久化、基于深度的世界图，并按需检索相关历史，从而在不增加额外 LLM 调用的前提下压缩上下文。

## 二、方法论：HAM-VLN

### 1. 双过程架构（Dual-Process Architecture）

- **System 2（慢思考）**：在每一个路径点调用大 MLLM（Gemini-3.1-Pro），读取指令、当前观测、记忆上下文，输出高层决策：前进方向、回溯到某个已访问路径点，或停止。
- **System 1（快反应）**：轻量级接地模型（Qwen3.6-35B）将系统2的目标意图转化为像素级边界框，再经深度反投影、里程计坐标变换和快速行进规划（fast-marching）生成低层可执行动作。
- **策略分解**：
  - \(A_t = \pi_{\text{robot}}\left(\phi_1(\phi_2(T, O_t, M_t), D_t, P_t, K_{\text{cam}})\right)\)
  - 其中 \(T\) 为指令，\(O_t\) 为当前观测，\(M_t\) 为检索到的记忆，\(D_t\) 为深度，\(P_t\) 为里程计位姿，\(K_{\text{cam}}\) 为相机内参。

### 2. 分层代理记忆（Hierarchical Agentic Memory）

- **记忆组成**：
  - **工作记忆（Working Memory）**：保存最近 \(K\) 个路径点的原始帧；
  - **情景区记忆（Episodic Memory）**：记录访问轨迹与时间元数据；
  - **语义记忆（Semantic Memory）**：维护地点-物体图的内容与拓扑；
  - **反思记忆（Reflection Memory）**：将失败证据附着在对应地点，检索时逐字返回。
- **记忆公式**：
  - \(M_t = W_t \oplus L_t \oplus R(G_t, q_t)\)
  - \(W_t\)：最近 K 个路径点帧；\(L_t\)：指令进度记录；\(G_t\)：长期世界图；\(R\)：子目标条件检索算子。
- **世界图表示**：
  - \(G_t = (V^P_t, V^O_t, E^{PP}_t, E^{PO}_t)\)
  - 地点节点聚合约简语义、访问统计、失败证据；物体节点关联深度定位的开放词表描述；边表示导航连通性与语义包含关系。
- **决策耦合写入**：
  - 模型输出结构化决策记录 \(J_t = (a_t, w_t, r_t)\)，其中 \(w_t\) 包含场所、物体、进度，\(r_t\) 为理由；
  - 同时更新进度 \(L_{t+1}\) 和图 \(G_{t+1}\)，**不产生额外 LLM 调用**；
  - 物体检测与分割用 Grounding DINO 和 SAM 完成，深度投影与图关联为自动操作。

### 3. 子目标条件检索

- 打分函数：
  - \(s_t(p) = \alpha \cdot \text{rel}(q_t, p) + \beta \cdot \text{rec}_t(p) + \gamma \cdot \text{sal}(p)\)
  - rel：查询-地点余弦相似度（用本地 bge-large-en-v1.5 编码）
  - rec：时间新近度 \(\rho^{\,t-\tau(p)}\)，\(\rho=0.85\)
  - sal：地标显著性与物体丰富度
  - 权重 \(\alpha=1.0, \beta=0.3, \gamma=0.3\)
- 拓扑感知读出：
  - 种子预算 \(K_s=3\)，最终地点预算 \(K_p=5\)；
  - 取最高分地点做一跳扩展，并包含当前地点邻域，序列化成紧凑子图进入上下文。

### 4. 失败记忆与回溯

- 回溯时，将被放弃的轨迹后缀映射到地点节点，并把决策理由作为失败证据写入；
- 证据是“建议性”而非“禁止性”，不改变打分，不屏蔽地点；
- 仅在相关地点被检索到时重新进入上下文，使模型能在新子目标下重新解释旧失败。

## 六、主要结论与发现

- **零样本性能显著提升**：
  - R2R-CE：NE 由 5.87→3.92m，SR 61.0%，OSR 78.7%，SPL 48.1%；
  - RxR-CE：NE 由 8.80→6.27m，SR 52.7%，nDTW 54.3%；
  - HM3D-v2 ObjectNav：SR 79.7%，SPL 43.2%，超过此前最佳零样本方法，并超过表内部分监督方法。
- **上下文高效**：相比 full raw history，每 episode API token 减少 67.2%；相比 K=3 raw history 也减少 34.8%，同时指标更高。
- **记忆组件各有贡献**：
  - 去掉世界图损失最大（SR 降 9.3 点）；
  - 去掉反思记忆使 SPL 降 11.2 点，说明失败证据主要提升路径效率；
  - 三者全去掉时 SR 降至 50.7%（-10.3），SPL 降至 31.5%（-16.6）。
- **回溯示例证明反思记忆的有效性**：错误停止后写下失败说明并回溯，后续在走廊成功识别眼力图并正确停止。

## 七、优点与创新点

1. **免训练且通用**：同一配置在三个不同 benchmark 上均取得 SOTA 级零样本结果，不需任务特定调参。
2. **记忆写入零额外成本**：把记忆维护并入同一 LLM 调用，避免额外调用带来的延迟和费用。
3. **深度的世界图紧凑且可检索**：图的大小随发现的地点/物体增长而非随面积/轨迹增长，兼具几何、拓扑与语义信息。
4. **分层记忆设计合理**：工作/情景区/语义/反思四视图对应不同时间尺度和功能，检索打分（相关性+新近性+显著性）有明确公式与可控权重。
5. **失败记忆可复用**：回溯不仅恢复位姿，还更新记忆状态，使失败经验在后续决策中“有条件地”重新参与，具备创新闭环。
6. **实验指标全面**：除成功率外还报告 NE、SPL、nDTW、token 成本，消融较充分。

## 八、不足与局限

1. **评测范围有限**：仅在 100-episode 子集上测试（论文给出与全集的偏差论证，但非完整全量评估），跨环境的泛化强度仍有待证明。
2. **资源信息不透明**：未报告 GPU 型号/数量、推理耗时、内存峰值、单步延迟等工程指标，读者难以估算真实部署成本。
3. **模型依赖固定**：只用了单一 System2（Gemini-3.1-Pro）和 System1（Qwen3.6-35B），未展示对不同 MLLM 的鲁棒性。
4. **检索约束较多**：地点预算 Kp=5、种子 Ks=3、权重 α/β/γ 均为手工设定，未做敏感性分析，是否存在过拟合到特定 benchmark 的风险未知。
5. **SPL 仍有提升空间**：虽然 SR 很高，但 SPL 在 R2R 上只有 48.1、RxR 上 35.7，说明路径效率仍不如部分监督方法，零样本探索策略尚不最优。
6. **失败证据的“建议性”设计**：只提供提示，不去除无效区域，可能在某些场景下导致重复试错，对复杂长指令的收益需更深入验证。
7. **无真实世界实验**：全部在仿真环境（Habitat）中评估，真实机器人上的深度噪声、里程计漂移、导航失败恢复等未验证。
