## 摘要
大语言模型（LLM）智能体越来越频繁地处理长时间交互历史，有效的推理需要识别并利用分布在过往观察和行动中的任务相关证据。然而，在先前计算得到的表示中编码的有用信息，在后续生成过程中往往未被充分利用。我们提出\textbf{TransMem}，一个轻量级推理时参数化记忆模块，将冻结的LLM主干网络产生的稀疏历史隐藏状态转化为可复用的记忆表示。TransMem使用轻量级门控网络动态地对当前隐藏状态施加潜在干预，而无需重复编码先前上下文。为了学习可迁移的记忆利用方式而非任务特定知识，我们引入了基于证据条件的自蒸馏。一个记忆增强的学生网络处理完整上下文，并与共享同一冻结主干网络的、仅基于证据的教师网络的预测分布相匹配。在LoCoMo、HotpotQA和MemoryAgentBench上的实验表明，TransMem在不同模型架构和规模下均带来了持续改进。TransMem在LoCoMo上取得了11.58–29.25 $F_1$的提升，在HotpotQA上取得了10.20–13.03 $F_1$的提升，同时将MemoryAgentBench的平均准确率从29.54%提高到40.00%。这些结果确立了稀疏历史隐藏状态作为长上下文LLM智能体有效且高效的记忆基质。我们的代码可在https://github.com/Haodong-Lei-Ray/TransMem获取。

## Abstract
Large language model (LLM) agents increasingly operate over long interaction histories, where effective reasoning requires identifying and exploiting task-relevant evidence distributed across past observations and actions. However, useful information encoded in previously computed representations is often underutilized during subsequent generation. We propose \textbf{TransMem}, a lightweight inference-time parametric memory module that transforms sparse historical hidden states from a frozen LLM backbone into reusable memory representations. TransMem uses a lightweight gating network to dynamically apply the latent intervention to the current hidden states, without repeatedly encoding the preceding context. To learn transferable memory utilization rather than task-specific knowledge, we introduce evidence-conditioned self-distillation. A memory-augmented student processes the full context and matches the predictive distribution of an evidence-only teacher that shares the same frozen backbone. Experiments on LoCoMo, HotpotQA, and MemoryAgentBench demonstrate consistent improvements across different model architectures and scales. TransMem yields gains of 11.58--29.25 $F_1$ on LoCoMo and 10.20--13.03 $F_1$ on HotpotQA, while improving the average MemoryAgentBench accuracy from 29.54\% to 40.00\%. These results establish sparse historical hidden states as an effective and efficient memory substrate for long-context LLM agents. Our code is available at https://github.com/Haodong-Lei-Ray/TransMem.

# TransMem 论文总结

## 1. 核心问题与整体含义（研究动机和背景）

- 长上下文交互是 LLM 智能体的核心挑战。现有模型虽然能处理长输入，但**关键证据往往被“淹没”在上下文中**，模型在生成时难以有效利用先前已计算出的隐藏状态中所蕴含的信息。
- 作者观察到因果 Transformer 的两个特性：
  1. 隐藏状态天然聚合了其之前 token 的信息，因此**靠近片段末尾的隐藏状态可作为该片段的压缩表示**；
  2. 这些表示具有**位置敏感性**，不同位置的隐藏状态以不同保真度保留上下文的不同部分，导致“中间丢失”或“近因偏差”问题。
- 由此引出核心问题：**如何在不重复编码历史、不扩大上下文窗口的前提下，让模型更好地“回忆”并利用长上下文中已有的任务相关证据？**
- TransMem 提出一种轻量级推理时参数化记忆模块，将稀疏的历史隐藏状态转化为可复用的记忆表示，从而实现**记忆能力与推理能力的解耦**。

## 2. 方法论

### 核心思想
- **不构造外部文本记忆，也不学习特定知识**，而是学习“如何从已有的隐藏状态中提取有用信息”这一通用记忆利用能力。
- 在冻结的 LLM 骨干上插入轻量记忆模块，仅在生成阶段对当前隐藏状态施加修正。

### 技术细节
1. **记忆特征提取**：
   - 在 prefill 阶段得到长上下文 C 的隐藏状态序列 `h^K_1:L`。
   - 将上下文划分为 B 段（每段长度 n = L/B），取每段最后一个隐藏状态作为稀疏记忆特征：`H_M = [h^K_n, h^K_2n, ..., h^K_L]`。
   - 对于超长上下文（超过骨干窗口），分块（chunk）提取后拼接各块的记忆特征。

2. **记忆转换与门控干预**：
   - 将 `H_M` 和当前生成前缀的隐藏状态 `H_A` 送入一个轻量 Transformer 块 `f^K_m`，得到记忆特征 `h_m`。
   - 通过可学习投影 `W^K_Δ` 得到记忆偏移：`Δh = W^K_Δ h_m`。
   - 门控网络 `f^K_g` 对偏移进行自适应缩放：`g = α·σ(W_g h_m / τ)`（默认 α=2，τ 为温度参数）。
   - 最终修正：`ĥ^K_t = h^K_t + g ⊙ Δh`，仅在生成阶段（t ≥ L+1）应用，随后传入下一层 Transformer。

3. **模型插入方式**：
   - 仅插入最后 4 层（实验发现较优），进一步降低开销；不修改任何骨干参数。

### 训练方法：证据条件自蒸馏（ECSD）
- 教师路径：仅输入“证据 E + 问题 Q”，运行冻结骨干，生成答案分布 `p_T(·|A_<i, E, Q)`。
- 学生路径：输入完整上下文 C，运行冻结骨干 + TransMem，得到分布 `p_S(·|A_<i, C)`。
- 目标函数为前向 KL 散度：  
  `L_SD = (1/|A|) Σ_{i=1}^{|A|} KL(p_T(·|A_<i, E, Q) || p_S(·|A_<i, C))`
- 该设计迫使 TransMem 从完整上下文中“恢复”仅依据证据才能做出的预测，从而学会抑制噪声、突出关键信息。

## 6. 主要结论与发现

- TransMem 在 **LoCoMo** 上带来 **11.58–29.25 F1** 提升；在 **HotpotQA** 上带来 **10.20–13.03 F1** 提升；在 **MemoryAgentBench** 上平均准确率从 29.54% 提升至 **40.00%**。
- **稀疏历史隐藏状态可作为一种高效、可扩展的记忆基质**，无需重编码历史即可增强长上下文推理。
- **证据条件自蒸馏显著优于 SFT、GRPO、OPD**，说明 token 级、特权的证据教师监督对学习记忆利用能力至关重要。
- 插入**最后四层**效果最佳；更早层插入收益有限，表明深层表示更利于记忆形成。
- 门控网络学习到一种**跨域稳定的层间调度**：浅层（相对）放大记忆更新，深层抑制，且该模式在 HotpotQA 与 LoCoMo 上一致，说明学到的不是数据集特化的开关，而是普适的修正策略。
- 计算开销与上下文长度无关，延迟不随上下文增长，具有良好的可扩展性。

## 7. 优点

- **轻量且高效**：只插入 4 层，只在生成阶段干预，额外计算量独立于上下文长度；相比 δ-Mem 等具有明显效率优势。
- **方法新颖**：直接利用“已计算但被忽视”的隐藏状态作为记忆源，无需外部存储、无需扩窗、无需重编码。
- **训练策略精妙**：通过证据条件自蒸馏，教师只看到证据，学生看到完整上下文，迫使模型学会“去噪聚焦”，并且只在 HotpotQA 训练即可跨域泛化。
- **实验设计全面**：覆盖多数据集、多骨干、多对比方法，并有大量消融验证各组件贡献；附录进一步探讨了门控统计、层间行为、模型移植等细节。
- **分析深入**：对门控行为的跨域稳定性分析、训练目标对比等，为理解方法提供了扎实的实证基础。

## 8. 不足与局限

- **记忆表示过于稀疏**：仅取每段最后一个隐藏状态作为记忆特征，可能遗漏段内重要信息；实验对段数 B 不敏感，但未与更复杂的表示抽取方式对比。
- **依赖骨干质量**：在较弱的骨干（如 Llama3.1-8B）上虽然提升大，但绝对分数仍较低；方法收益可能受限于冻结骨干的表示能力。
- **训练数据单一**：仅在 HotpotQA 上训练，虽实现跨域泛化，但可能未充分发挥潜力；若加入更多元的长上下文数据可能进一步提升。
- **对比基线公平性存疑**：部分外部记忆方法（如 BM25 RAG、MemoryBank）在多数指标上负收益，可能未针对长上下文问答调优；且未报告多次运行的方差/显著性检验，固定种子 42 可能带来偶然性。
- **超长上下文支持有限**：分块策略各块独立提取记忆，块间交互有限，可能影响跨块推理；未与分段全局注意力等方法对比。
- **效率对比不全面**：仅对比 δ-Mem 和 MLP Memory，未与外部记忆方法（如 RAG）的端到端延迟和成本对比；也未报告 TransMem 本身的参数量。
- **应用场景局限**：目前主要面向离线长上下文问答/记忆评测，未在在线流式交互或实时更新记忆场景中验证。
