## 摘要
大语言模型（LLM）智能体越来越多地被用作高风险领域（如财务咨询）中的个性化助手，但目前尚不清楚它们能否在长时间跨度内维护和更新个体化用户模型。现有的个性化记忆基准主要测试事实保留，或依赖于约束较弱的模型生成轨迹，导致事件驱动的偏好适应研究不足。我们提出了FinPerMA，一种基于事件的基准，用于评估针对固定纵向投资者轨迹的个性化记忆。其生成流程结合了确定性的、理论驱动的影响规则、受控的LLM叙述和自动化质量筛选；一个“冲击后”检查点用于隔离智能体是否已将重大事件整合到其持久用户模型中。在来自276个角色的2,994个问题上，七个前沿LLM及多达七种记忆配置远未饱和：没有任何全上下文配置的整体准确率超过约0.47，或多项选择问题的准确率超过约39%。归因分析表明，基于摘要的记忆通常保留事实细节，却丢失了个性化所需的偏好信号；因此，简单的检索可能优于专门构建的记忆系统，且这种差距在冲击后扩大。

## Abstract
Large language model (LLM) agents are increasingly used as personalized assistants in high-stakes domains such as financial advising, yet it remains unclear whether they can maintain and update an individualized user model over long horizons. Existing personalized-memory benchmarks primarily test factual retention or rely on weakly constrained model-generated trajectories, leaving event-driven preference adaptation underexplored. We introduce FinPerMA, an event-grounded benchmark that evaluates personalized memory against frozen longitudinal investor trajectories. Its generation pipeline combines deterministic, theory-informed impact rules, controlled LLM narration, and automated quality screening; a Post-Shock checkpoint isolates whether an agent has integrated a material event into its persistent user model. On 2,994 questions from 276 personas, seven frontier LLMs and up to seven memory configurations remain far from saturated: no full-context configuration exceeds approximately 0.47 overall accuracy or approximately 39% on multiple-choice questions. Attribution analysis shows that summary-based memory often preserves factual details while losing the preference signals needed for personalization; simple retrieval can therefore outperform purpose-built memory systems, with the gap widening after shocks.

- **背景**：大语言模型（LLM）智能体正被用于金融咨询等高风险、长时交互场景，需要建立并持续更新个性化的用户模型（如投资者的风险偏好），而不仅是孤立地回答问题。
- **核心问题**：现有系统能否在长期交互中真正维护和更新用户模型，而非只做表面匹配？现有个性化记忆基准（如 PersonaMem、LoCoMo、LongMemEval）主要聚焦事实记忆或长上下文回忆，缺少对“事件驱动的偏好适应”的受控评测。
- **两个关键空白**：
  - **G1（有限的事件条件状态变化）**：现有基准难以控制重大事件如何改变用户的潜在偏好，无法区分“回忆过去”与“基于更新后状态推理”。
  - **G2（标签可审计性不足）**：弱约束的 LLM 生成轨迹会使生成器偏差与评估目标纠缠；FinPerMA 通过确定性规则约束状态变化、冻结对话和标签来降低该风险。
- **选择金融作为测试床的原因**：真实宏观事件（2020 疫情崩盘、2022 加息、2023 硅谷银行倒闭）提供时间锚点；行为金融学提供可操作的理论机制（前景理论、经验效应、参考依赖等）；金融决策中“过期/不一致的用户模型”会产生严重后果。
- **本文目标**：构建一个理论驱动、事件锚定、可审计的个性化记忆基准，衡量 LLM 智能体在事件冲击后是否能整合并更新用户模型。

## 2. 方法论

### 2.1 整体架构（五阶段生成流程）

FinPerMA 的语料库形式为 C = {(P_i, T_i, D_i, Q_i)}，其中每个角色有：

- P_i：角色描述（人口统计、财务画像、心理特征）；
- T_i：5–8 个事件的纵向时间线；
- D_i：围绕时间线合成的多会话对话；
- Q_i：3 个评估维度 × 4 个时间检查点的问题集。

核心对象是事件反应 R_{i,k} = ImpactModel(P_i, E_{i,k}, M_{i,<k})，其中 M_{i,<k} 是事件前的记忆库。

### 2.2 角色合成

- 基于深圳证券交易所和中国资产管理协会的公开零售投资者调查校准人口统计与财务画像边际分布。
- 心理特征包括：大五人格、10 项风险容忍度评分、5 项金融素养测验。
- 按 Pompian (2012) 的规则映射将角色分为四类行为投资者类型（BIT）：被动保守者（PP）、友好跟风者（FF）、独立个人主义者（II）、主动积累者（AA）；通过拒绝采样确保每类占比 ≥ 20%。

### 2.3 事件时间线构建

- 共 97 个带日期的事件：17 个宏观事件、64 个行业事件、16 个人生活事件。
- 每个事件记录类型、日期、受影响的资产/领域、地区、摘要、典型反应、1–5 严重度评分。
- 行业事件通过基于兴趣标签、知识领域、信息消费风格和事件显著性的种子相关过滤器选择，而非简单的二值暴露。
- 每个角色采样 5–8 个事件，要求类别多样化且事件间隔至少 4 周。

### 2.4 三层 Impact Model（核心生成框架）

**Layer 1：规则驱动的 ImpactConstraint（确定性）**

包含五个子模块（M1–M5）：

- **M1（BIT 分类）**：按 Pompian (2012) 分类，门控风险方向和禁止偏差集合；
- **M2（事件冲击系数）**：查表映射 (BIT, 事件类型) → 方向和系数，基础幅度为 base_mag(E) = c[E.type] × (E.severity / 5)；
- **M3（大五人格乘数）**：基于神经质和内外向缩放幅度，公式为 m_trait(P) = 1 + 0.30(P.N − 0.5) − 0.15(P.E − 0.5)，其余三个特质因文献方向不一致而省略；
- **M4（经验历史聚合）**：基于 Malmendier & Nagel 的经验收益信念，公式为 μ̂(P)_t = Σ w_i r_i，权重 w_i = a_i^λ / Σ a_j^λ，a_i = max(1, t − y_i + 1)，λ = 1.3，通过 clip(1 − 0.2μ̂, 0.6, 1.4) 调节冲击幅度；
- **M5（符号化记忆参考锚点）**：基于记忆参考依赖，激活条件为 s(m, x) = min(1, 0.8·J(T_m, T_x) + 0.2·I[e_m = e_x]) ≥ 0.3，记忆强度 h_m = exp(−0.1·years_m)·(1 + rehearsal_m)，参考值为加权平均。

聚合输出为 ImpactConstraint 数据类（方向、幅度范围、可能偏差、禁止偏差、经验 μ̂、记忆锚点），对固定输入完全确定性。

**Layer 2：受约束的 LLM 叙述器（随机）**

- 将 ImpactConstraint 作为硬约束写入提示，要求模型输出 JSON 格式的 EventReaction，包含：preference_deltas（字段、增量、新值）、inner_monologue（必须引用至少一个记忆锚点）、biases_triggered、confidence。
- 结构化 JSON 便于 Layer 3 直接审计。

**Layer 3：自动验证与重试**

- 硬检查：风险方向一致性、风险增量边界（20% 容差）、禁止偏差排除、冲击后演化类型一致性；
- 软诊断：经验信念和记忆引用条件不拒绝但保留；
- 失败则重试最多 3 次，最终回退模板（confidence=0.2, layer3_fallback=True）。

### 2.5 对话合成

- 面向任务的用户模拟器接收 (P_i, E_i,k, R_i,k) 作为私有状态，生成投资者–顾问对话，偏好通过交易、提问、担忧等隐式表达。
- 质量控制：确定性去重、隐式性检查、财务合理性过滤，再经多 LLM 质量投票，只有通过的会话进入冻结语料库。

### 2.6 评价任务设计

- **三个维度**：
  - 记忆保真度（MF，Memory Fidelity）：对既定属性和过去行为的事实回忆；
  - 偏好推理（PR，Preference Reasoning）：从行为痕迹推断隐式偏好；
  - 情境适应（CA，Context Adaptation）：在全新决策情境中应用（可能已更新的）偏好。
- **四个检查点**：
  - 零记忆（Zero-memory/control）：无历史，测参数知识下限；
  - 时间线内（In-timeline）：持续记忆维持；
  - 分心后（Post-distraction）：无关会话后的记忆保持；
  - **冲击后（Post-Shock，novel）**：重大事件后立即提问，测试是否将事件整合到持久用户模型中——这是本文的主要协议贡献。
- **问题与干扰项设计**：共 2,494 道六选一选择题（83.3%）+ 500 道开放题（16.7%）；选项位置均匀洗牌（固定种子）；干扰项在结构和长度上与正确选项匹配（中位长度差 5 字符，52.9% 落在 5 字符内）。

## 3. 实验设计

### 3.1 数据集 / 基准

- **FinPerMA v8gold 冻结语料**：276 个评估角色、2,994 个问题（2,494 MCQ + 500 开放题），每个角色贡献 3–19 个问题（中位数 11）。
- 覆盖 3 个维度 × 4 个检查点的完整网格；数据由 2020–2026 年 97 个真实宏观、行业和个人事件锚定。

### 3.2 对比模型与方法

- **七个 LLM 骨干**：Qwen3.8、Qwen3.7-Max、DeepSeek-V4-Pro、GLM-5.2、GPT-5.6-sol、Gemini-3.1-pro、Claude-Opus-4-8（代表中国市场金融咨询常用系统）。
- **记忆配置（固定 Qwen3.7-Max 骨干）七种**：
  - no_memory（下限，仅查询）；
  - full_context（上限，所有先轮逐字输入）；
  - naive_rag（BM25 检索）；
  - bge_rag（BGE-M3 密集检索）；
  - mem0（可扩展抽取/检索系统）；
  - memos / MemOS（记忆操作系统）；
  - memobase（结构化/画像系统）。
- **评估协议**：MCQ 确定性选项匹配打分；开放题由三家供应商的裁判多数投票判定。

## 5. 实验数量与充分性

- **实验规模**：7 个骨干 × 2 个参考点（no_memory/full_context）= 14 组主要对比；加上 Qwen3.7-Max 上的 7 种记忆配置对比，共约 21 组系统性比较；外加归因分析（按检查点、能力、失败模式、典型/反典型角色切片）。
- **充分性评价**：

  - **不足与公平性风险**：

    5. 实验未做多次重复运行，无法报告方差。

## 6. 主要结论与发现

- **发现 1：存在显著且依赖模型的记忆差距**。full_context 相比 no_memory 准确率提升 1.5–2.4 倍（从 0.18–0.27 → 0.41–0.47），但整体准确率最高仅约 0.47、MCQ 最高约 39%，**基准远未饱和**。较强的参数知识无法替代角色特定证据。
- **发现 2：简单检索优于专门记忆系统**。在 Qwen3.7-Max 上，BM25/BGE-M3 检索恢复全上下文差距的约 88%，而三个结构化内存系统（Memobase、Mem0、MemOS）只恢复 54–79%。差距集中在开放题上：检索保留可逐字引用的证据，摘要/画像内存会丢弃。成本排序与准确率排序不同，检索在约 1/10 token 预算下即可接近上限。
- **发现 3：冲击后差距扩大**。full_context 与 mem0 的准确率差距在 In-timeline 为 8.0 分，到 Post-Shock 扩大到 13.0 分；表明结构化记忆在“事件应更新用户状态”时失效最严重，Post-Shock 是独立的记忆更新测试。
- **发现 4：摘要记忆保留事实但丢失偏好信号**。memOS 的事实回忆与 full_context 持平（27.7 vs 27.1），但在偏好追踪（31.9 vs 52.9）和偏差识别（32.6 vs 54.0）上大幅落后。
- **发现 5：没有模型在所有能力上领先**。领先能力在 Qwen3.8（偏好追踪、情境适应）、Claude（事实回忆、因果推理）、Gemini（跨域迁移）之间轮换；模型总体强度不转化为普遍更强的个性化记忆。
- **发现 6：典型失败模式**。主要错误类型是“零记忆默认”（zero-memory default）、“单信号过度推断”（single-signal over-inference）和“时间错位”（temporal misalignment），三者合计约占错误的 66%。
- **发现 7：反典型角色表现系统性下降**。所有模型在“非典型”角色上比“典型”角色低 4.5–11.2 分，说明模型会回退到类型刻板印象，而非利用个体证据覆盖冲突的先验。

## 7. 优点

- **理论驱动且可审计**：Impact Model 将行为金融学原理（前景理论、经验效应、记忆参考依赖等）转译为确定性的、可检查的规则，生成轨迹可复现、可审计。
- **事件锚定与真实时间线**：使用 2020–2026 年 97 个真实事件作为外部锚点，避免任意合成事件带来的偏差。
- **Post-Shock 检查点设计**：直接测试“重大事件是否被整合到持久用户模型”这一此前未被隔离的能力，是方法论上的主要贡献。
- **冻结语料库保证公平**：所有系统面对完全相同的轨迹和标签，不同模型间的比较不受重新生成标签的影响。
- **受控生成流水线**：确定性规则 + 受控 LLM 叙述 + 自动验证重试的三层结构，在自然语言灵活性与规则可审计性之间取得平衡。
- **多维评估与归因分析**：3 维 × 4 检查点的网格设计，加上按能力、失败模式、典型性的归因切片，比单一总分更深入。

## 8. 不足与局限

- **合成数据的外部效度受限**：角色和偏好变化由规则引导而非真实投资者产生，基准准确率不能直接外推到真实用户行为。
- **应用范围较窄**：仅覆盖个人金融领域，时间线仅 5–8 个事件（中位 11 个问题），远短于真实跨月/跨年交互。
- **实验设计不完善**：记忆系统对比为单种子、token 预算不匹配；缺少重复运行和方差报告；部分模型查询因内容安全网关被丢弃。
- **评估依赖 LLM 裁判**：开放题正确性由跨厂商裁判多数投票决定，存在裁判偏差风险。
- **机制简化**：M5 使用符号 Jaccard 相似度而非嵌入相似度，M4 的权重随经验年龄递增但未做严格结构估计，属于“可解释启发式”而非真实认知模型。
- **未验证跨场景迁移**：论文建议未来通过人类评审和纵向用户交互来测试生成轨迹和结论是否适用于受控环境之外。
