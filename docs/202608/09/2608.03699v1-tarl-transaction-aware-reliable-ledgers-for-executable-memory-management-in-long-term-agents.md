## 摘要
持久化内存帮助长期智能体保留知识，但单次更新错误可能反复扭曲未来的检索与推理。现有大多数系统将内存更新简化为二元写入/保持决策，无法区分新信息应被添加、忽略、用于修正过时信念、作为不可靠信息拒绝，还是推迟验证。这些选择可能共享相同的二元标签，却产生根本不同的内存状态。我们提出TARL，一种内存状态更新框架，将每条语句映射为五种可执行操作之一。TARL识别受影响的内存，解析其时间范围，比较来源可靠性，并更新接受、待定和拒绝账本。通过比较替代更新操作所产生的内存状态来训练模型，鼓励模型选择能导向正确结果的操作。我们还引入了TARL-Mem，一个具有细粒度动作标签和下一状态目标的基准。在领域内、跨来源、时间、反事实和顺序评估中，TARL提升了动作预测和状态恢复，减少了内存污染，保留了冲突证据，并限制了累积损坏。完整的模型实现已在补充材料中提供。

## Abstract
Persistent memory helps long-term agents retain knowledge, yet a single update error can repeatedly distort future retrieval and reasoning. Most existing systems reduce memory updating to a binary Write/Hold decision, which cannot distinguish whether new information should be added, ignored, used to revise an outdated belief, rejected as unreliable, or deferred for verification. These choices may share the same binary label while producing fundamentally different memory states. We introduce TARL, a memory state update framework that maps each statement to one of five executable actions. TARL identifies the affected memory, resolves its temporal scope, compares source reliability, and updates accepted, pending, and rejected ledgers. It is further trained by comparing the memory states produced by alternative update operations, encouraging the model to select the operation that leads to the correct result. We also introduce TARL-Mem, a benchmark with fine-grained action labels and next-state targets. Across in-domain, cross-source, temporal, counterfactual, and sequential evaluations, TARL improves action prediction and state recovery, reduces memory pollution, preserves conflicting evidence, and limits cumulative corruption. The complete model implementation is provided in the supplementary material.

## 1. 核心问题与整体含义

- **研究背景**：持久化记忆是长期智能体跨会话保留知识、支持反思与检索增强的基石；但持久性同时会放大更新错误——一次错误写入可能在后续会话中被反复检索并持续扭曲推理与决策。
- **现有缺陷**：多数系统把记忆更新简化为二元 `Write/Hold`。论文用形式化分析指出，该二元判断“信息不足”：新信息可能应**追加、忽略、修订旧信念、因不可靠而拒绝、或推迟验证**，这些语义可共享同一二元标签，却产生截然不同的内存状态。
- **核心主张**：可靠智能体不仅要决定“是否记住”，更要决定“如何改变当前记忆状态”。TARL 将每条候选语句映射到五类可执行操作，并在三个账本上执行确定性的状态转移。

## 2. 方法论

### 2.1 三账本事务语义

- 持久记忆状态定义为 `M_t = (A_t, P_t, H_t)`：
  - **A（Accepted）**：当前活跃、可直接用于下游访问的证据；
  - **P（Pending）**：尚未证实、等待进一步验证的信息；
  - **H（History/Rejected）**：非活跃记录的审计账本，区分 `superseded`（被修订取代）与 `rejected`（被拒绝）两类条目。

### 2.2 五个可执行操作

| 操作 | 候选去向 | 被触发的 Accepted 条目 |
|---|---|---|
| `append` | 加入 Accepted | 保留 |
| `noop` | 不保留 | 保留 |
| `revise` | 加入 Accepted | 归档为 superseded |
| `reject_conflict` | 加入 History/Rejected | 保留 |
| `defer_verify` | 加入 Pending | 保留 |

- `append` 与 `revise` 都“写入”，但只有 `revise` 会退役旧证据；
- `revise` 与 `reject_conflict` 都处理冲突，却保留相反的一方为活跃记忆；
- `noop` 与 `defer_verify` 都不写 Accepted，但只有后者保留候选以备后续裁决。

### 2.3 预测流程

1. **候选与记忆编码**：文本主干（frozen Llama-3.1-8B-Instruct）将候选语句与各目标槽编码到共享空间；
2. **目标定位**：用 softmax 交互打分 `α_t,i` 计算候选与存储槽的兼容性，得到目标索引 `ξ_t` 和加权目标证据 `q_t`；
3. **可靠性比较**：由联合头输出 `r_new` 与 `r_old`，取符号化余量 `ρ_t = r_new − r_old`，正值倾向提交/修订、负值保留旧证据、小幅度倾向延迟验证；
4. **操作条件价值评估**：为每个动作 a，结合嵌入、执行码 `ϕ(a)`、可靠性信度等，输出五路策略 `p_θ(a|s_t, M_t)`；
5. **确定性账本执行**：`M_{t+1} = Exec(M_t, e_t, a_t, ξ_t)`，完全按表 1 的规则修改三账本，神经网络只负责决策、不参与状态变异。

### 2.4 反事实执行监督

- 关键思想：仅比对“动作标签”无法反映不同错误的后果——错误的 `noop` 只是漏更新，错误的 `revise` 可能删除有效证据并污染后续回合；
- 训练时对每一个候选动作都执行一遍 `Mt → Exec(Mt, e_t, a, ξ)`，计算其状态与 gold 状态的逐账本一致性 `Q_t(a)`，再以温度 τ 的 softmax 化为软目标，用交叉熵对齐策略；
- 推理时只选取最高分动作执行一次，无假设分支、无 gold 状态依赖。

## 6. 主要结论与发现

1. **二元监督信息不足**：`Write/Hold` 无法确定唯一下一状态，即使补充目标槽也不可精确恢复；五路动作标签才是可执行恢复的必要条件；
2. **TARL 全面领先**：在域内主对比中，5-way Macro F1 达 0.8286（最佳基线 MemAgent 0.7871），Next-state Acc 0.6621（最佳基线 0.6354），污染率 0.2524、ECE 0.0369 均为最优；
3. **跨源泛化有效

3. **跨源泛化有效**：在 HaluMem-hard、LoCoMo、LongMemEval 三个互不重叠的 source-family holdout 上，TARL 的五路动作 F1 与下一状态准确率均保持领先，且性能衰减幅度显著小于多数基线，说明其对不同来源、不同改写风格的记忆更新具备稳健的迁移能力，而非域内过拟合；
4. **组件消融的主次贡献**：顺序移除反事实模拟、交叉交互、时间规范化、可靠性比较、目标槽选择、账本头后，模型性能均出现不同程度下降；其中移除反事实执行监督的降幅最大，验证了“用后果监督动作”这一设计对压制记忆污染和错误修订的核心作用；
5. **长事务流稳定性**：在 14 条独立 200 步顺序回放轨迹上，TARL 的相对状态恢复分（SRS）稳定上升，Turn-Δ-F1 保持正值，说明其在多轮累积更新中能持续修正既有错误，而多数基线（如 MemoryBank、HippoRAG）的污染率随步数线性恶化；
6. **下游推理增益**：将更新后的可信记忆作为上下文送入读取阶段后，TARL 在 QA 正确率与证据引用正确率上优于二元 Write/Hold 基线和提示式 DeepSeek-R1 基线，表明“可执行操作+明确账本”比“记住/不记住”更有利于减少检索噪声与错误信息传播；
7. **二元监督不可恢复性的形式化验证**：论文不仅通过实验，还以信息论视角证明：在缺乏动作语义标注时，即使下一状态完全已知，也无法唯一反推出所需更新行为；这一结论为记忆更新任务提出“必须直接监督动作语义”的最低必要条件。

## 7. 局限性与未来工作

- **动作粒度仍有边界**：五类操作覆盖了常见事务语义，但尚未涵盖合并多条候选、跨实体重写、主动召回旧证据等更复杂更新；作者也承认 Pending 账本的裁决策略目前基于简单阈值，缺少显式“验证触发”建模；
- **骨干模型强耦合**：文本编码与可靠性打分均依赖冻结的 Llama-3.1-8B，虽然提高了可复现性，但模型的先验偏差会直接渗入候选和槽位的表示，尚不清楚更换骨干后操作语义是否仍能稳定保持；
- **数据规模与来源有限**：TARL-Mem 由三个公开 QA/记忆基准转换而来，实例总量约 5,422 条，领域仍以对话和叙事型记忆为主，对真实系统中检索日志、数据库变更、多模态记忆的覆盖不足；
- **评估偏重自动指标**：尽管包含下游 QA 效用测试，但缺少与人工评估的对比；记忆污染率等指标对“什么是污染”的判定与人工直觉是否完全一致尚无验证；
- **未来方向**：作者提出可将五路操作扩展为隐式动作空间、引入 Pending 的主动验证策略（如同步外部工具、询问用户）、对账本状态做可微分近似以端到端优化长期回报，并探索在更大记忆规模与更长会话生命周期中的表现。

## 8. 综合评价

TARL 的核心贡献在于将“记忆更新”从二分类问题重构为“带审计的执行流”，通过三账本状态与可执行操作将神经网络的决策空间与确定性状态转移解耦，并设计反事实执行监督来对齐“动作后果”而非“动作标签”。该工作在任务定义、方法设计、实验控制上都较为扎实，尤其是统一骨干、统一执行器、防泄漏划分和多随机种子重复等设置显著提升了结论的可信度；其对二元监督信息不足的形式化分析也为后续研究提供了清晰的理论依据。主要不足在于动作空间和数据域的广度有限，且部分结论未做显著性检验，但总体而言，这项工作为长期智能体的持久化记忆更新提供了新的范式参考。
