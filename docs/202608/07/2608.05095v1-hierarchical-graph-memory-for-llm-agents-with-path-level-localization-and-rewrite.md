## 摘要
面向长期推理的智能体需要一种能够随着新事实和外部反馈不断到来而高效且有效更新的记忆系统。近年来，图记忆被采用以提供用于多跳检索和推理的结构化组织。然而，现有方法将所有记忆存储在平面图中，累积的历史记忆可能引入不相关的上下文，并增加检索过程中证据选择的成本。此外，它们通常独立地更新记忆单元，需要重复的单元级重写来覆盖相关的变更。为解决这些问题，我们提出了HiGram，一种具有路径级定位与重写的演进式层级图记忆框架。具体而言，我们首先提出一种层级图记忆，将记忆组织为包含上层节点和MemoryUnit的由粗到细的架构，从而减少检索过程中的不相关信息量。我们进一步提出基于MicroGraph的路径级定位，利用查询和更新条件化的MicroGraph在重写前识别支持子图和证据路径。最后，我们提出一种协调重写方法，联合修订单元内记忆与单元间依赖关系，使得在定位的证据路径中更新有效的依赖结构。在面向长期对话问答和冲突感知记忆评估的基准实验上，我们的方法在答案质量和令牌效率方面较基线有显著提升。此外，在动态、静态和条件冲突下，我们的方法提高了答案准确性和查询有效证据选择的能力。

## Abstract
Agents for long term reasoning require a memory that can be efficiently and effectively updated over time, as new facts and external feedback continue to arrive. Recently, graph memory has been adopted to offer structural organization for multi-hop retrieval and reasoning. However, existing methods store all memories in a flat graph, and accumulated historical memories can introduce irrelevant contexts and increase the cost of evidence selection during retrieval. Moreover, they typically update memory units independently, requiring repeated unit-wise rewrite to cover related changes. To address these issues, we propose HiGram, an evolving hierarchical graph memory framework with path-level localization and rewriting. Specifically, we first propose a hierarchical graph memory, which organizes the memory into coarse-to-fine architecture composed of upper-level nodes and MemoryUnits, thereby reducing the amount of irrelevant information during retrieval. We further propose MicroGraph-based path-level localization, which leverages query and update conditioned MicroGraphs to identify support subgraph and evidence path before rewrite. Finally, we propose a coordinated rewriting method that jointly revises intra-unit memory and inter-unit dependencies, enable valid dependency structures updating in the localized evidence path. Experiments on benchmarks for long-term conversational question answering and conflict-aware memory evaluation demonstrate that our method demonstrate substantial improvements over baselines in answer quality and token efficiency. Besides, our method improves answer accuracy and query-valid evidence selection under dynamic, static, and conditional conflicts.

### 一、核心问题与整体含义（研究动机与背景）

- **研究背景**：长期推理智能体需要能随新事实、修正信息和外部反馈持续演进的记忆系统。现有记忆增强系统虽能存储对话历史、检索相关经验，但面对持续增长的记忆，存在两个关键难题：
  - **检索噪声**：累积的历史记忆在平面图结构中检索时，会引入大量无关上下文，增加证据选择的成本；
  - **更新低效**：答案通常由相互关联的证据路径支撑，而非孤立事实。现有方法独立更新单个记忆单元，一次更新可能影响多个下游依赖，需要反复逐单元重写才能覆盖所有相关变更，导致token消耗高、更新效率低。
- **核心洞察**：现有方法在记忆组织的粒度与推理所用证据结构的粒度之间存在**错配**——检索在持续扩张的全局图上进行，而答案只依赖少量局部化证据；更新虽只针对单个记忆单元，但其影响会沿证据路径传播。因此，记忆系统应先**定位查询相关的子图**，再基于更新**识别受影响的证据路径**，并在受限区域内联合修订记忆状态与依赖关系。
- **整体含义**：论文提出HiGram，通过层级图记忆架构、路径级定位和协调重写，实现高效、一致且可维护的长期智能体记忆，在降低检索噪声的同时提升更新效率。

### 二、方法论：核心思想、关键技术细节与算法流程

#### 2.1 总体框架

HiGram包含三个核心阶段（对应图1）：
1. **层级图记忆组织**——构建粗粒度到细粒度的记忆架构；
2. **MicroGraph路径级定位**——在重写前定位受查询和更新影响的证据路径；
3. **协调重写**——在定位区域内联合更新记忆单元状态与依赖关系。

#### 2.2 层级记忆组织

- 将t时刻的记忆表示为层级图 $G_t = (V_t, E_t)$。
- **节点集**：$V_t = V_t^{sub} \cup V_t^{cat} \cup V_t^{ctx} \cup M_t$，其中 $V_t^{sub}$（主语节点）、$V_t^{cat}$（宾语类别节点）、$V_t^{ctx}$（上下文节点）为上层抽象节点，$M_t$ 为存储事实细节的MemoryUnit集合。
- **边集**：$E_t = E_t^{sub} \cup E_t^{obj} \cup E_t^{ctx} \cup E_t^{dep}$，分别连接MemoryUnit与其主语、宾语类别和上下文信息，以及MemoryUnit之间的显式依赖边。
- **MemoryUnit状态**：包括 active（当前有效）、superseded（被取代）、outdated（过时）、pending（待定）。非active单元保留在图中用于维护修订历史，但被排除在定位步骤之外。
- **设计价值**：上层节点提供粗粒度访问入口，MemoryUnit存储细粒度事实与依赖结构，避免对整个历史事实图进行盲目搜索。

#### 2.3 MicroGraph路径级定位

- **MicroGraph定义**：由主语节点和宾语类别节点对确定的局部子图 $B_{t,j} = (v_{t,j}^{sub}, v_{t,j}^{cat})$。选择这两个属性是因为它们在时间更新中保持稳定，且能在详细证据路径选择前提供高效访问。
- **锚点提取**：从查询 $q_t$ 和更新文本 $u_t$ 构造临时MemoryUnit $M_t^{temp}$，提取主语节点和宾语类别节点作为锚点 $A_t = anch(M_t^{temp})$。
- **候选MicroGraph筛选**：选取与锚点有交集（主语或宾语类别匹配）的候选MicroGraph，按相关性打分 $R(B, A_t)$，取Top-$K_g$个构成局部记忆区域 $\hat{B}_t$，其关联的MemoryUnit、上下文节点和依赖边共同构成**支持子图** $G_{S,t}$。
- **路径级定位**：在 $G_{S,t}$ 中枚举最多 $K_p$ 条连通候选路径 $P_t^{cand}$，按与临时MemoryUnit的一致性打分 $\phi_H(P, M_t^{temp})$（考虑属性匹配、依赖一致性、时间有效性和上下文兼容性），选出受影响证据路径 $\hat{P}_t = \arg\max \phi_H(P, M_t^{temp})$。

#### 2.4 协调重写

- **匹配**：将临时MemoryUnit $M_t^{temp}$ 与 $\hat{P}_t$ 中的MemoryUnit匹配，识别受影响的单元。
- **单元内重写（Intra-unit Rewrite）**：保留既有记录，更新受影响MemoryUnit的内部状态和有效时间信息。新记忆提交为active MemoryUnit；已有记忆则根据时间与上下文一致性修订状态。
- **单元间重写（Inter-unit Rewrite）**：识别 $\hat{P}_t$ 中直接依赖受影响单元的 $D_t(m_i)$，检查更新后其依赖证据是否仍然有效。验证通过的依赖保留，否则对应MemoryUnit标记为outdated并从当前证据视图排除。更新后的MemoryUnit不自动继承原单元的下游依赖，防止无证据支撑的派生结论。
- **整体更新式**：$G_{t+1} = Update(G_t, Rewrite_{inter}(Rewrite_{intra}(\hat{P}_t, M_t^{temp}), M_t^{temp}))$，重写区域之外的MemoryUnit和关系保持不变。

### 三、实验设计

- **实现细节**：LoCoMo使用GPT-5.4和GPT-4o生成答案；MemConflict使用GPT-5.0 mini；GPT-5.4 mini作为评判模型。路径深度$h=3$，$K_g=12$，$K_p=24$。

### 六、主要结论与发现

1. **答案质量与token效率的双重提升**：HiGram在LoCoMo上使用GPT-5.4和GPT-4o均取得平均F1、BLEU和LLM-J的最优结果，同时token消耗仅为全上下文的7.2%（GPT-5.4下）和ReadAgent的15.8%（GPT-4o下），实现了质量与成本的良好平衡。
2. **冲突场景下的显著优势**：在MemConflict上，HiGram的总体AA（67.84 vs 最佳基线55.39）、Macro-AA（81.06 vs 67.10）以及SEH@3（77.31 vs 58.79）均大幅领先所有基线。静态冲突和条件冲突的AA优势尤为明显。
3. **时间性问题处理最佳**：在Temporal问题上HiGram表现最强，且在Adversarial问题上（GPT-5.4下）排名第一，验证了时间有效性范围与局部证据路径的作用。
4. **结构与定位机制互补**：消融实验表明，MicroGraph组织和基于定位的支持子图分别从粗粒度索引和细粒度依赖保持两个层面贡献性能；去除任一组件都会导致LLM-J下降和token消耗上升。
5. **协调重写优于单一策略**：Append-only在两类冲突上表现平庸，Relation-level更新虽提升静态冲突但削弱动态冲突，而HiGram的协调重写同时取得两类的最佳结果，不存在此消彼长的权衡。
