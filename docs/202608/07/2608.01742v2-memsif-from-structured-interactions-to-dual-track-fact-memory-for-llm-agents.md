## 摘要
长期记忆对于在长时间跨度的交互中运行的LLM智能体至关重要。然而，现有记忆系统的一些持续局限性可以追溯到长期交互设置中两种反复出现的错位模式：时间-结构错位（TSM）和延迟效用显现（DUM）。当时间邻近性不能可靠地与主题或事件级相关性对齐时，会出现TSM；而当写入时的显著性不能可靠地预测未来的查询效用时，会出现DUM。为了缓解这些错位模式，我们提出了MemSIF（具有结构化交互和事实的记忆），一种结构化交互到事实的记忆框架。结构化交互记忆将原始交互组织为主题片段（Topical Segments），保留局部主题连贯性，以及事件轨迹（Event Trajectories），维持跨时间的事件连续性。双轨事实记忆使用两个互补的轨道：CoreFact记忆在写入时整合稳定的、模式引导的信息，而ActiveFact记忆按需形成事实，并提升那些由多个历史来源和重复查询需求支持的事实以供重用。在LoCoMo和LongMemEval-S上跨越五个主干LLM的实验表明，MemSIF在所有设置中实现了最高的总准确率（Total ACC），在LoCoMo上比最强基线高出2.29%-8.79%，在LongMemEval-S上高出2.87%-6.15%。这些结果支持将结构化交互记忆与双轨事实记忆相结合以缓解TSM和DUM的有效性。代码可在https://github.com/luoyufeihaha/MemSIF获取。

## Abstract
Long-term memory is critical for LLM agents operating over long-horizon interactions. However, several persistent limitations of existing memory systems can be traced to two recurring misalignment patterns in long-term interaction settings: Temporal-Structural Misalignment (TSM) and Delayed Utility Manifestation (DUM). TSM arises when temporal proximity does not reliably align with topical or event-level relatedness, whereas DUM arises when write-time salience does not reliably predict future query utility. To mitigate these misalignment patterns, we propose MemSIF (Memory with Structured Interactions and Facts), a structured interaction-to-fact memory framework. Structured Interaction Memory organizes raw interactions into Topical Segments that preserve local topical coherence and Event Trajectories that maintain cross-time event continuity. Dual-Track Fact Memory uses two complementary tracks: CoreFact memory consolidates stable, schema-guided information at write time, whereas ActiveFact memory forms facts on demand and promotes those supported by multiple historical sources and recurring query demand for reuse. Experiments on LoCoMo and LongMemEval-S across five backbone LLMs show that MemSIF achieves the highest Total ACC in all settings, outperforming the strongest baseline by 2.29%-8.79% on LoCoMo and 2.87%-6.15% on LongMemEval-S. These results support the effectiveness of combining Structured Interaction Memory with Dual-Track Fact Memory to mitigate TSM and DUM. Code is available at https://github.com/luoyufeihaha/MemSIF.

### 研究动机与背景

- 大语言模型（LLM）智能体已从单轮响应系统发展为支持长时间跨任务（long-horizon tasks）的复杂系统，如研究助手、虚拟代理等。
- 随着交互历史的累积，将其整体塞入上下文窗口既代价高昂，也可能损害性能（"lost in the middle"等问题）。
- 构建**可检索、可更新的外部记忆**是扩展智能体能力的关键路径。

### 论文识别的两大核心问题

论文指出现有长期记忆系统存在两类**反复出现的系统性错位模式**：

1. **时间-结构错位（TSM, Temporal–Structural Misalignment）**
   - 时间上的邻近性并不能可靠地反映主题或事件层面的相关性。
   - 同一时间内相邻的对话轮次可能讨论无关主题，而相隔遥远的轮次可能属于同一演进事件。
   - 预定义的时间边界可能将无关主题归入同一记忆单元，或使相关证据散落在多个单元中。

2. **延迟效用显现（DUM, Delayed Utility Manifestation）**
   - 写入时的显著性（salience）无法可靠预测未来的查询效用。
   - 写入时看似不重要的信息，可能在未来对回答关键问题至关重要。
   - 写入时激进过滤会丢弃后来关键的信息，保守保留又会产生大量冗余。
   - 实验诊断显示：43.71% 的含关键证据的问题中，至少有一条关键证据在写入时是低显著性的。

### 整体含义

- 论文认为，现有方法通常将交互组织与事实构建分开优化，但这两类问题相互交织，需要**联合设计**。
- 同时，现有系统缺乏结构化组织时，查询时无法有效检索分散证据；且查询时的方法虽能暂时恢复低显著性信息，但未将其持久化，未来仍需重复检索。

## 2. 论文提出的方法论

### 核心思想

- 提出 **MemSIF（Memory with Structured Interactions and Facts）**，一种**结构化交互到事实（interaction-to-fact）**的记忆框架。
- 通过两个互补的模块分别缓解 TSM 和 DUM：
  - **结构化交互记忆**（Structured Interaction Memory）
  - **双轨事实记忆**（Dual-Track Fact Memory）

### 结构化交互记忆（缓解 TSM）

- 将原始交互历史 `H = (u1, u2, ..., uT)` 组织为两种互补表示：
  - **主题片段（Topical Segments）**：时间上连续、主题连贯的交互单元，保留局部主题边界。
  - **事件轨迹（Event Trajectories）**：将属于同一演进事件或任务的非连续主题片段关联起来，维持跨时间事件连续性。
- 核心匹配函数：

  ```
  φ(A, B) = α · s_sem(A, B) + (1 − α) · J(K_A, K_B)
  ```

  - `s_sem`：归一化余弦相似度（语义相似度）
  - `J`：关键实体集合的 Jaccard 重叠度
  - `α`（默认 0.8）平衡语义与实体重叠两种信号

- **主题片段构建**采用双阈值策略：
  - `φ ≥ τ_merge`（0.60）→ 自动并入当前片段
  - `φ ≤ τ_split`（0.325）→ 开启新片段
  - 介于两者之间的模糊边界 → 调用 LLM 判断，仅将不确定决策交给 LLM，兼顾效率与连贯性。

- **事件轨迹聚合**：按时间顺序处理主题片段，检索 top-K 候选轨迹，用 LLM 判断事件身份、任务连续性和状态一致性，匹配则追加，否则新建轨迹。

### Schema 引导的 CoreFact 整合（DUM 之写入时轨道）

- CoreFact 记忆整合**写入时就能识别长期价值**的、稳定的、由 schema 引导的信息。
- CoreFact schema（可配置）在目标设定中包含四类事实：身份（Identity）、事件（Event）、偏好（Preference）、关系（Relation）。
- 流程：从主题片段提取符合 schema 的候选事实 → 事件轨迹提供跨时间证据补充/调和 → 通过 LLM 执行四种操作之一：
  - **Add**（新增）
  - **Update**（整合兼容的新证据）
  - **Merge**（合并重复条目）
  - **Supersede**（标记过期事实但保留历史查询）
- 每个 CoreFact 条目为 `⟨subject, type, stmt, meta⟩` 形式。

### 查询驱动的 ActiveFact 形成（DUM 之查询时轨道）

- ActiveFact 记忆针对写入时价值不确定、后续查询才显现价值的信息，包含四个阶段：

1. **查询局部提取与候选累积**
   - 当事实级证据不足以回答查询 `q_t` 时，从结构化交互记忆中检索相关主题片段和事件轨迹，提取查询局部证据（不直接写入 ActiveFact）。
   - 答案 `a_t` 生成后，证据条目才进入候选累积流程。
   - 候选按主题聚类：`C_k = (s_k, X_k, Q_k, R_k)`，其中包含标准化主题、去重事实陈述、去重触发查询、不同历史交互单元标识符。
   - 查询局部证据在每次回答后清除，而**候选聚类跨查询保留**，使历史支持与查询需求随时间累积。

2. **候选提升（Promotion）**
   - 两个信号用于评估候选：

     ```
     Score_src(C_k) = (1 − 1/|R_k|) · Coh(X_k)
     Score_qry(C_k) = (1 − 1/|Q_k|) · Coh(Q_k)
     ```

   - 提升决策：

     ```
     P(C_k) = 1[Score_src ≥ θ_s ∧ Score_qry ≥ θ_q]
     ```

   - 仅当候选**既有多个历史来源支持、又有重复查询需求**才被提升为持久 ActiveFact 条目。

3. **持久维护**
   - 提升后的 ActiveFact 条目 `⟨subject, stmt, meta⟩` 存入 ActiveFact 记忆，后续可被直接重用，无需重复回溯原始交互。

### 记忆检索与答案生成

- 对每个查询，从 CoreFact 和 ActiveFact 中联合检索事实条目，通过 LLM 充分性检查器判断是否足以回答。
- 若充分，则用检索到的事实构建答案上下文；若不充分，则回溯结构化交互记忆获取查询局部证据，再组合生成答案。
- 答案生成后，查询局部证据进入 ActiveFact 管线。

   - 统计可靠性：配对 bootstrap（10,000 次重采样，6 组设置）。
   - 评估者验证：440 个样本的人类标注研究。

### 充分性与客观性

- **优点**：
  - 覆盖 5 个不同规模/家族的主干模型，验证了泛化性。
  - 消融实验系统全面，每项组件都对整体性能有贡献且各有侧重。
  - 诊断子集从数据出发独立构建（不依赖方法输出），能直接检验两个核心问题。
  - 统计显著性通过 bootstrap 检验，置信区间均排除零。
  - 超参数敏感性分析显示性能不易受调参影响。
- **注意点**：
  - 论文本身提到某些类别下（如 DeepSeek-v4-pro 的 M-hop 和 Temp）MemSIF 并非最优，说明增益并非在所有类别中一致。
  - 附录中的诊断（如 TSM 的 ASV/SNTD、DUM 的 LSHUR）依赖 GPT-4o 打分，虽经过人工验证，仍存在主观性风险。
  - 所有方法使用统一的嵌入模型（Qwen3-Embedding-8B）以保障公平，这种做法合理但可能对各基线的最优性能有一定影响（因其官方实现可能使用其他嵌入器）。

## 6. 论文的主要结论与发现

1. **MemSIF 全面超越基线**：
   - LoCoMo：比最强基线高 2.29%（DeepSeek-v4-pro）至 8.79%（Qwen3-4B）。
   - LongMemEval-S：比最强基线高 2.87%（DeepSeek-v4-pro）至 6.15%（Qwen3-4B）。
   - 在全部六个数据集-主干设定中，95% 置信区间均排除零，统计上显著。

2. **组件各有侧重，互补配合才能解决 TSM 和 DUM**：
   - 移除事件轨迹 → LoCoMo Temp 类别下降最大（10.36%），说明其跨时间连线作用。
   - 移除主题片段 → M-hop 下降显著，说明其保障多段证据组装。
   - 移除 CoreFact → LongMemEval-S 总准确率下降 12.77%，说明在 100K+ token 上下文中持久可重用事实的重要性。
   - 移除 ActiveFact → M-hop 下降最大（13.23% 和 12.38%），说明其恢复"效用延迟显现"信息的关键作用。
   - 在 NCE 子集上，移除结构化交互组件导致最大下降；在 LSHU 子集上，移除 ActiveFact 导致的下降最大。

3. **效率与准确性可以兼得**：
   - Full MemSIF 比仅查询局部提取更高效且更准确（持久 ActiveFact 缩短了回溯时间）。
   - Qwen3-32B 下，MemSIF 比 GAM 少用 40.6% tokens（2.41K vs. 4.06K），准确率还高出 5.78%。
   - 与 SimpleMem 相近的 token 预算下，准确率高 8.38%、运行时间减少 42.8%。

4. **经验验证了 TSM 和 DUM 的存在与影响**：
   - TSM 诊断：ASV 分析表明相邻片段存在显著语义波动（LoCoMo 高波动桶中 23% 为真实话题切换），SNTD@k 显示语义邻居可跨越大范围时间距离（LoCoMo 远距离邻居中仍有 70% 属于同一事件线程）。
   - DUM 诊断：LSHUR 达到 41.55%（成对级别）/ 43.71%（查询级别）；基于显著性的压缩使细节恢复率从 82.19% 降至 43.84%–50.68%，答案准确性下降 16%–25%。

5. **总体判定**：结构化交互记忆与双轨事实记忆的结合能有效缓解两类错位，使记忆系统从简单的检索效率优化走向"交互经验随时间演化为可重用知识"的建模。

## 7. 优点

### 方法设计亮点

- **问题驱动、诊断先行**：先通过大规模数据诊断（ASV、SNTD、LSHUR、CDL、QAD）验证两类错位模式的存在和影响，再据此设计架构，因果关系清晰。
- **联合设计而非分而治之**：将交互组织与事实构建放在统一框架内耦合设计，交互组织为事实构建提供跨时间证据连续性，事实构建反过来依赖结构化交互作为可回溯来源。
- **双轨互补设计巧妙**：
  - CoreFact 负责写入时可识别的稳定事实（写时整合），ActiveFact 负责查询时才显现价值的信息（查询时形成），覆盖了信息价值的两种时态。
  - 提升条件（多来源支持 AND 重复查询需求）较为严格，降低噪声提升风险。
- **效率意识**：双阈值策略将 LLM 调用限制在模糊边界，ActiveFact 持久化避免了重复回溯，实现了准确率与成本的良好平衡。
- **保留历史而非删除**：Supersede 操作保留过期事实供历史查询使用，更贴近实际部署需求。

## 8. 局限性

### 依赖 LLM 判断环节较多

- 主题片段模糊边界的判定、事件轨迹的身份判别、CoreFact 的四类操作、ActiveFact 的提升决策均依赖 LLM 调用。虽然双阈值策略已大幅压缩模糊边界的 LLM 调用量，但整体管线中 LLM 仍是核心依赖，成本与延迟在超大规模部署中仍需斟酌。
- 若 LLM 在事件身份判别（尤其是边界模糊、主题穿插的对话）上出现误判，错误会沿管线向下游传播，影响事实记忆的整合质量。

### 对评估器与嵌入模型的依赖

- 准确率由 GPT-4o 判定，虽经人工验证（93% 一致），但判定标准本身（"正确"的语义边界）仍存在主观性，尤其是对多跳推理答案的判定。
- 统一使用 Qwen3-Embedding-8B 作为嵌入模型保障了公平比较，但可能未达到部分基线在各自官方嵌入器下的最优表现，MemSIF 的增益在不同嵌入器下是否稳健尚未验证。

### 诊断实验的规模局限

- TSM 诊断中 ASV/SNTD 分析虽有一定规模，但部分实证（如 LLM 对 600 对片段是否属于同一事件的判断）样本量偏小，结论外推需谨慎。
- 两大数据集（LoCoMo 与 LongMemEval-S）的会话场景以双人对话为主，对于多智能体协作、工具调用日志、多人会议等更复杂的交互形态尚未覆盖。

### 参数与阈值的经验性

- τ_merge、τ_split、θ_s、θ_q、α 等参数虽做了敏感性分析，但取值仍然是在特定数据集上人工/网格设定的，不同领域（如医疗、法律）可能需要重新校准。
- 阈值之间的灰色地带依赖 LLM 兜底，"效率与准确性兼得"的结论建立在这些超参相对合理的前提之上。

### 单次实验规模有限

- 论文未报告重复多随机种子的实验平均结果（仅 bootstrap 重采样），也未披露每项配置的推理方差（除置信区间外），对方法稳定性的刻画仍可加强。

## 9. 启示与未来方向

### 对记忆系统设计的启示

1. **"时间邻近 ≠ 主题相关"是记忆组织的首要约束**：任何长期记忆系统，若仅按时间窗口或会话边界组织记忆，必然遭遇 TSM 问题；需要显式的主题/事件层建模，而非默认时间顺序即语义顺序。
2. **写入时价值判定不可靠，但也不应放弃**：DUM 诊断表明 43.71% 的查询关键证据在写入时是低显著性的，但论文并未走向"什么都要存"的极端；而是设计了**两级机制**——写入时保稳定事实，查询时保延迟价值信息——这一"分层定时"思想值得借鉴。
3. **持久化的价值在于避免重复回溯**：查询时组合方法能恢复低显著性信息，但不能将其沉淀；MemSIF 的 ActiveFact 将"查询中反复显现价值"的证据固化，本质上是在线与离线学习界限的打通。

### 潜在研究方向

- **更细粒度的时间感知**：引入时间衰减、事件演化状态机（如事件开始/进行/结束），使记忆在时间维度上更加动态。
- **多模态交互记忆**：将文本交互扩展到语音、图像、代码执行日志等模态，TSM 与 DUM 在多模态下可能有新的表现形式。
- **学习式阈值与决策**：用可微分的匹配与提升函数替代硬阈值，或通过强化学习端到端优化记忆写入与检索策略。
- **评估基准的扩展**：当前两大基准仍以问答准确率为主，未来可加入记忆一致性（同一事实多次回答是否矛盾）、记忆遗忘曲线（随距离增加的性能衰减）、记忆编辑的可解释性等维度。
- **隐私与遗忘机制**：Supersede 已部分涉及"如何说再见"，但被删除或被覆盖的事实如何在多用户、多权限场景下安全管理，是部署级问题。

## 10. 总体评价

MemSIF 是一篇**问题驱动、诊断扎实、设计精巧、验证全面**的长期记忆系统论文。它的核心贡献不在单个模块的革新，而在于**揭示了长期记忆系统中长期被忽视的两类系统性错位模式（TSM 与 DUM），并用结构性架构设计同时回应了二者**。

- 其方法深度：结构化交互记忆将连续文本切分为主题片段并跨时间连接为事件轨迹，为后续事实整合提供了"时间上有序、事件上连贯"的组织骨架；
- 其方法广度：CoreFact 与 ActiveFact 双轨事实记忆，既照顾了写入时就可知的稳定价值，也捕获了查询时才显现的延迟价值，覆盖了信息价值评估的完整生命周期；
- 其方法可信度：从大规模数据诊断、到组件级消融、到成本对比、到统计显著性检验，实验链条完整且严谨。

如果说"记忆力"是智能体的长期竞争力的核心，那么 MemSIF 提供了一条从"记忆存储"走向"记忆组织与知识沉淀"的清晰路径。其"结构化交互 + 双轨事实"的框架，不仅为后续长期记忆研究提供了可直接复用的设计范式，也重新定义了记忆系统应当优化的目标——**不只检索效率，而是**交互经验随时间演化为可复用知识**的完整能力**。
