## 摘要
记忆增强的VLM代理依赖于持久化的空间知识行事，然而随着环境变化，这些知识会悄然变得过时。我们探究当代理必须调和自信的记忆主张与矛盾的观察时会发生什么，以及当前模型能否在冲突演变为安全相关错误之前发现它。利用动态FrozenLake测试平台，我们将一项陈旧性检测任务与一项下游导航任务相结合，覆盖三个闭源模型和三个开放权重VLM，同时使用文本和图像输入（进行了1,800次检测运行，以及由四个LLM导航器在共享的50个随机种子规模下进行的12,000次文本模式导航实验）。我们得到三项发现。第一，文本可解性并不等同于视觉基础：能够从文本中可靠标记陈旧条目的模型，在相同网格上视觉F1分数却从0.887降至0.067，最弱的模型甚至持续做出流畅、自信却忽略图像的决策。第二，未经审计地消费陈旧记忆是一种安全负担：在我们最主要的GPT-4o设置中，信任原始记忆的代理比完全没有记忆的同一代理死亡频率高出两倍以上。第三，审计虽有帮助但未能弥合差距：透明的读取时过滤器在文本模式下消除了大部分安全代价，然而即便是具有先见之明的陈旧标签在当前网格尺寸下也未带来进一步的显著收益；当视觉审计不可靠时，过滤无法带来一致的好处。综合这些结果，将空间记忆陈旧性定义为一种安全失效模式，并将可靠的视觉基础和记忆-观察冲突下的行动选择，确立为记忆增强代理面临的核心开放性挑战。

## Abstract
Memory-augmented VLM agents act on persistent spatial knowledge, yet that knowledge silently goes stale as the environment changes. We ask what happens when an agent must reconcile a confident memory claim with a contradicting observation, and whether current models can catch the conflict before it becomes a safety-relevant mistake. Using a dynamic FrozenLake testbed, we pair a staleness-detection task with a downstream navigation task across three closed-source models and three open-weight VLMs under both text and image inputs (1,800 detection runs, and 12,000 text-mode navigation episodes over four LLM navigators at a shared 50-seed scale). Three findings emerge. First, text solvability does not imply visual grounding: models that flag stale entries reliably from text nonetheless span vision F1 from 0.887 down to 0.067 on the identical grids, and the weakest keeps making fluent, confident decisions that ignore the image. Second, consuming stale memory without an audit is a safety liability: in our primary GPT-4o setting, an agent that trusts raw memory dies more than twice as often as the same agent given no memory at all. Third, auditing helps but does not close the gap: a transparent read-time filter removes much of the safety cost in text mode, yet even oracle stale labels bring no further significant gain on the current grid size, and when visual auditing is unreliable, filtering yields no consistent benefit. Together these results frame spatial-memory staleness as a safety failure mode and isolate reliable visual grounding and action selection under memory--observation conflict as the central open challenges for memory-augmented agents.

## 2. 方法论

### 2.1 核心思想

- 构建一个可控因果链测试平台 **SpatialSTALE**：将"固定自然语言记忆 + 可控变化的网格世界 + 可追溯至特定记忆条目的导航安全结果"三者结合，使每条记忆主张都成为可检验的命题。
- 将任务拆分为**两级**：
  1. **检测任务**（entry-level auditing）：判断每条记忆条目是否与当前观察冲突（stale vs. valid）；
  2. **导航任务**（downstream navigation）：对比不同记忆策略下，识别能力是否转化为更安全的行动。

### 2.2 关键技术与细节

- **记忆快照构建**：初始 8×8 网格约 25% 为洞（H），固定起点 (0,0) 和终点 (7,7)。在未变化前运行 20 次随机游走，首次访问位置记录类型；未访问位置由生成器补全，保证每格恰好一条记忆（N=64），例如 `"SAFE at (2,5): Frozen ice - safe to walk"`。
- **变化机制**：只翻转非终点的 F（冰面）与 H（洞）两类格子，且保证存在可达路径。**thaw**（F→H）使声称安全的格子变致命；**freeze**（H→F）仅使声称危险的格子变安全。
- **陈旧性形式化**：定义 hazard map h(H)=1，其余为 0。条目 mi 的陈旧标签通过比较存储类型与当前格子类型判定：
  ```
  yi(t) = I[h(c0_i) ≠ h(gt[pi])]
  ```
  无需主观语义匹配，SAFE 变 H 即 stale，DANGER 变 F 即 stale。
- **三种变化模式（regimes）**：
  - **L1（Spot）**：5~7 个随机孤立变化，stale 比例约 9.4%，一次性检测；
  - **L2（Cluster）**：12~16 个变化集中在半径 2 的邻域内，stale 比例约 14.1%，一次性检测；
  - **L3（Online）**：每 5 步有 70% 概率触发事件（每个事件翻转 2 格），stale 比例约 14.3%，需增量检测。
- **OMCD（Optimized Memory Consistency Detector）干预**：
  - 将 64 条记忆分成 B=10 的批次，每批让模型输出二元 is_stale 判断和简要理由，标记为 stale 的条目被移除；
  - L1/L2 在导航前审计一次；L3 在每个真实事件发生后重新审计；
  - 与 SelfVerify（一次性全量自检）形成对比，考察批次化、事件触发的审计是否更优。

## 3. 实验设计

### 3.1 基准（Benchmark）

- **SpatialSTALE**：基于 Gymnasium FrozenLake 改造的动态 8×8 网格世界，加入受控变化、自然语言记忆条目、文本/图像双模态观察，以及可追溯至特定记忆条目的安全结果（死亡/成功/超时）。

### 3.2 模型与输入

- **闭源模型**：GPT-4o、Claude-Sonnet-4.6、Qwen3.6-Plus；
- **开放权重 VLM**：GLM-5.1、InternVL3-2B、InternVL3-8B；
- **两种模态**：文本模式（坐标标注的全网格列表）与视觉模式（384×384 彩色渲染图，坐标标签），记忆始终为文本。

### 3.3 对比策略

- **NoMemory**：无记忆对照，仅依据当前观察行动；
- **NoFilter**：将所有 64 条原始记忆不加检查地提供给导航器，测量原始陈旧记忆的安全代价；
- **SelfVerify**：导航前一次性全量自检，删除自认为不一致的条目；
- **OMCD**：批次化、事件感知的过滤干预；
- **Oracle**：通过 OMCD 相同过滤接口注入真实陈旧标签，用于消融标签质量。

## 6. 主要结论与发现

1. **文本可解性不保证视觉扎根**：
   - 文本模式下，成熟模型（GPT-4o、Claude、Qwen、GLM-5.1）检测 F1 均高于 0.88；
   - 视觉模式下同一批网格，Qwen 保持 F1=0.887（∆F1=-0.011，不显著），Claude 中度下降（∆F1=-0.134），GPT-4o 严重下降（∆F1=-0.598），GLM-5.1 崩溃（F1=0.067，∆F1=-0.830）；
   - GLM-5.1 的失败并非图像不可读所致：它对"真安全"和"致命洞"两类条目的标记率几乎相同（5.0% vs 4.5%），且推理字符串流畅、100% 置信度、零拒答——表明其审计是**记忆主导**而非图像扎根。
2. **未经审计的陈旧记忆是安全负担**：
   - 在 GPT-4o L2 文本导航中，信任原始陈旧记忆的死亡率达 **74.4%**，而无记忆仅为 **28.0%**——陈旧记忆比无记忆**致命 2.7 倍**；
   - 轨迹分析揭示"rush-into-hole"机制：NoFilter 的死亡轨迹约 7.8~8.5 步即终止，远短于成功轨迹（14.5~14.6 步），说明陈旧记忆直接将代理引导到致命格子上；Claude 无记忆死亡反而最长（16.1 步），属于探索型失败。
3. **审计可移除大部分代价但无法完全弥补**：
   - OMCD 在 GPT-4o 每个 regime 上都优于 NoFilter 和 SelfVerify，L2 上将死亡率从 74.4% 降至 31.6%；
   - 但 Oracle 标签与学习得到的文本过滤在三个 regime 上均无显著差异（|∆|≤0.02，p>0.2），且检测 F1 与导航成功率几乎零相关（r ≤ 0.060，p>0.67）——当审计已可靠时，**剩余瓶颈是行动选择**而非标签质量；
   - 当视觉审计不可靠时（GPT-4o、Claude、GLM 的视觉模式），过滤无法带来一致的导航收益，Qwen 因视觉检测接近天花板而缺乏提升空间。

## 7. 优点

- **因果链设计与可控性**：将记忆、世界、结果三者独立可控，使每次死亡都能追溯到具体记忆条目，避免混淆因素。
- **任务配对设计**：检测任务与导航任务在相同实例上配对运行，清晰地区分了"识别陈旧"与"识别后安全行动"两个能力层次。
- **多模态对照**：文本与图像输入共享相同网格，有效隔离了"渲染问题"与"处理/审计问题"；GLM 案例通过"跨相反真值的恒定标记率"这一内置感知对照，强有力地证明了视觉审计失败而非低层识别失败。
- **透明的干预基线**：OMCD 是显式、可重复、可控的过滤器（不是让模型自行仲裁），并与 Oracle 标签对比，从而精确定位收益边界（上游视觉审计不可靠 + 下游行动选择瓶颈）。
- **轨迹分解方法**：用"结局条件化轨迹长度"区分 rush-into-hole（陈旧记忆直接致死）与 explore-until-death（无记忆探索耗尽），比单纯死亡率更能诊断失败机制。
- **结论表达谨慎**：论文在多数关键论断（如 Oracle 与 OMCD 无差异、视觉导航结论）上均附带了统计解释和适用边界说明，没有过度声称普适性。

## 8. 不足与局限

- **环境极简且单一**：8×8 符号化 FrozenLake 是"干净环境的下界估计"，不是现场估计；只有二值安全/危险语义、无部分可观测性、无感知噪声，与真实部署差距较大。
- **视觉导航规模过小**：仅 10 种子 × 3 episodes，无法支撑强结论；论文也只是将其作为探索性预览。
- **机制分析集中于单一模型**：Oracle 消融、F1-成功率相关、轨迹分解主要在 GPT-4o 文本模式上完成，Qwen 的例外行为（如 OMCD 死亡 3.1 步 vs NoFilter 6.8 步）未被纳入统一解释框架。
- **模型覆盖的时效性问题**：研究所用模型（如 Claude-Sonnet-4.6、GLM-5.1）为 2026 年版本，结论的跨时间稳定性未知；未报告 API 版本锁定策略。
- **自审计局限**：SelfVerify 与 OMCD 均是 LLM 自审计，未对比外部一致性校验器；二元输出虽规避了阈值校准问题，但也在附录 D 中可见连续分数在不同模型间异构严重，说明内部表征不稳定。
- **批量审计的成本-质量权衡**：B=10 带来 9× 推理调用缩减但以 2.7pp F1 为代价，对更大记忆存储的扩展性（B 是否需随 N 亚线性增长）未验证。
- **泛化性未验证**：更大网格、干扰记忆、多步记忆编辑、多智能体导致的陈旧性、连续控制环境（Habitat/AI2-THOR）等均为附录 K 中的未来计划而非已测结果。
