## 摘要
长时程LLM智能体需要能够从大型交互历史中恢复有用证据的记忆系统，同时避免向下游模型传递过多上下文。现有的记忆流水线通常依赖手工设计的启发式方法和重复的LLM调用，这可能导致冗余上下文和高推理成本。我们提出MemoryCPT，一种端到端可训练的智能体记忆流水线，涵盖离线记忆构建和在线查询条件上下文生成。MemoryCPT由两个阶段组成：查询无关蒸馏（QAD），利用显式推理轨迹将模块化的记忆构建流水线蒸馏为紧凑模型；以及查询感知检索与摘要（QAR），将倒数排名融合（RRF）与基于LoRA的摘要器相结合，该摘要器通过成本感知奖励下的组相对策略优化（GRPO）进行训练。我们进一步引入单位成本质量（QPC）来量化每单位推理成本下的答案质量。在LoCoMo和LongMemEval上的实验表明，与评估的基线相比，MemoryCPT改善了成本-性能权衡，而消融和敏感性分析则表征了其各组件的贡献及关键设计选择的影响。

## Abstract
Long-horizon LLM agents require memory systems that recover useful evidence from large interaction histories without passing excessive context to downstream models. Existing memory pipelines often rely on hand-crafted heuristics and repeated LLM calls, which can introduce redundant context and high inference cost. We propose MemoryCPT, an end-to-end trainable agent memory pipeline that spans offline memory construction and online query-conditioned context generation. MemoryCPT consists of two stages: Query-agnostic Distillation (QAD), which distills a modular memory-construction pipeline into a compact model using explicit reasoning traces; and Query-aware Retrieval and Summarization (QAR), which combines reciprocal rank fusion (RRF) with a LoRA-based summarizer trained via Group Relative Policy Optimization (GRPO) under a cost-aware reward. We further introduce Quality per Cost (QPC) to quantify answer quality per unit inference cost. Experiments on LoCoMo and LongMemEval show that MemoryCPT improves the cost-performance trade-off over the evaluated baselines, while ablation and sensitivity analyses characterize the contributions of its components and the effects of key design choices.

- 现有记忆系统（压缩、结构化组织、检索增强三类范式）大多依赖**手工设计的启发式规则**和**推理时反复调用外部LLM**，导致上下文冗余和成本激增

**核心挑战**：
1. **压缩阶段**：紧凑模型如何从原始历史中学习构建高质量长期记忆？直接用最终摘要监督会掩盖分段、合并、提取等中间决策，学习目标过于粗糙。

## 二、方法论

### 2.1 总体框架

MemoryCPT 将记忆系统 `fmem` 实例化为两个可训练阶段：

```
M = fQAD(H)          # 离线：查询无关蒸馏，构建记忆库
mq = fQAR(q, M)      # 在线：查询感知检索与摘要
ŷ = fans(q, mq)      # 冻结QA模型：Qwen3-14B
```

**关键设计**：只有 `fQAD` 和 `fQAR` 可训练，下游QA模型完全冻结，保证评估公平性。

### 2.2 阶段一：Query-agnostic Distillation (QAD)

| 组成 | 说明 |
|---|---|
| **教师模型** | deepseek-v3，将记忆构建分解为4个角色 |
| **角色分解** | BatchSegmenter（会话分段）、EpisodeGenerator（生成情节记录）、EpisodeMerger（合并相似情节）、SemanticExtractor（提取语义知识） |
| **推理轨迹** | 教师输出 `<think>` 推理轨迹 + 结构化JSON，学生不只学"做什么"，还学"为什么" |
| **训练目标** | LoRA（LoRA-A）上的标准因果语言建模，`L = -E[Σ log pθ(zt|x, z<t)]`，其中 `z = r ⊕ y`（推理轨迹+输出拼接） |
| **模型大小** | 学生模型仅Qwen2.5-7B / Llama-3.2-3B，蒸馏后merge为 `base_A` |

**优势**：模块化提供"难度脚手架"，将复杂映射任务分解为有明确中间目标的自包含子任务；外部运行时执行JSON结构化操作，模型学习显式决策（何时创建、合并、抽象）。

### 2.3 阶段二：Query-aware Retrieval and Summarization (QAR)

**（1）RRF检索（粗选）**：
- 同时使用稠密检索（Qwen3-Embedding）和稀疏检索（BM25）
- 通过倒数排名融合（RRF）统一不同分数尺度：
  ```
  sRRF(m;q) = Σ_{r∈{dense,sparse}} 1/(krrf + rankr(m|q))，krrf=60
  ```
- 对情节记忆和语义记忆分别融合，拼接top候选（默认top-20/50），限制摘要器的输入范围

**（2）GRPO训练（细摘要）**：
- 建模为**上下文强盗问题（contextual bandit）**：一次采样即终结，无转移动力学
- 状态 `sq = (q, MRRF_q)`，动作 `mq ~ πφ(·|sq)` 为一次性自回归生成的摘要
- 使用GRPO优化LoRA-B，KL正则约束 `β=0.001`

**（3）成本感知奖励设计**：
- 训练时代理成本：`C(q,mq) = |mq|·(p_out_7B + p_in_14B) + |ŷ|·p_out_14B`
- 归一化：`C̃ = min(1, C/Cref)`，`Cref = 1.392×10⁻⁵ USD`
- 奖励：`R(q,mq) = α·F1(ŷ,y*) + (1-α)·(1-C̃)`，默认 `α=0.8`
- 关键设计：F1提供稠密连续的训练信号（优于LLM裁判），加权和替代不稳定的 F1/Cost 比值

### 2.4 新指标：Quality per Cost (QPC)

```
QPC = F1(ŷ, y*) / Cost(q)
```
其中 Cost 为每查询平均推理成本（USD×10⁴）。更高QPC表示相同预算下获得更多正确信息。

### 2.5 训练流程总结

```
教师管线产出角色级推理轨迹和JSON → 转为SFT数据训练LoRA-A → 
merge得base_A构建记忆库 → RRF检索 → GRPO训练LoRA-B
```
推理时仅3步：RRF检索 → LoRA-B生成摘要 → 冻结QA模型作答。成本通过摊销公式 `Camortized(n) = CQAD/n + CQAR+QA` 公平计入离线构建。

## 六、主要结论与发现

1. **端到端训练优于手工规则**：在Qwen2.5-7B上，MemoryCPT相比BudgetMem，LoCoMo F1从0.373→0.479（相对提升28%），成本从24.11→3.46（降低约7倍），QPC提升超9倍（0.015→0.111）
2. **质量与成本可兼得**：MemoryCPT同时获得最高F1和最低成本，打破"质量-成本"二律背反；No-Memory、LightMem等基线在提升F1的同时成本暴涨，而Memory-R1控制成本却牺牲质量
3. **QAD是质量放大器**：移除QAD导致F1从0.479降至0.370（-23%），说明教师推理轨迹蒸馏显著提升记忆质量（代价仅增加少量处理成本）
4. **QAR是成本控制器**：移除QAR使成本从3.46升至11.10，QPC从0.138崩至0.038；GRPO训练的FS（fine summary）将成本从8.35压至3.46，同时不牺牲语义正确性（Judge约0.755）
5. **α=0.8为最优权衡点**：α→1.0时摘要过长成本飙升；α过小时过度压缩丢失证据；α=0.8位于Pareto前沿左上角
6. **检索深度20/50最优**：8/20已能恢复约96%峰值F1（仅用42-44%候选成本），超过20/50后引入噪声反噬性能

## 七、优点与亮点

1. **问题定义清晰**：将记忆系统置于成本-性能框架下，提出QPC指标，弥补了现有工作只报准确率的评估盲区
2. **两阶段分离设计精巧**：离线/在线分离使得RL动作空间大幅缩小（上下文强盗而非完整马尔可夫决策过程），同时离线成本摊销到多查询中
3. **推理轨迹蒸馏**：以"推理轨迹+结构化JSON"而非最终摘要监督学生，让紧凑模型内化模块化记忆操作技能（何时分段/合并/抽象），是有监督蒸馏用于复杂记忆任务的新范式
4. **奖励设计的工程智慧**：用连续性F1替代LLM裁判进行训练（稠密反馈），用加权和替代不稳的QPC比值，用相对优势估计消去固定成本项，成本归一化对齐F1量纲/尺度
5. **评估严谨性**：统一价格表、统一QA模型、统一judge、统一tokenizer；报告摊销成本而非仅在线成本；分token级（输入/输出）统计
6. **成本解析透明度高**：附录给出完整token和成本分解（离线/在线、summarizer/QA拆解），使结果高度可复现

## 八、不足与局限

1. **泛化性局限（已知且显著）**：在LongMemEval上，Llama-3.2-3B基座的MemoryCPT F1仅0.181（低于LightMem的0.293），说明3B模型在复杂基准上蒸馏能力不足，方法的跨规模泛化存疑
2. **训练-推理分布不匹配**：GRPO训练时使用金标答案计算F1作为奖励，而推理时无金标；奖励函数与部署环境的差异可能导致策略在训练分布外的次优行为
3. **记忆类别覆盖不完整**：LoCoMo排除了Cat5（建议类），LongMemEval的SS-Pref（偏好类）各方法均表现极差（F1约3-7%），说明偏好记忆提取可能是开放难题
4. **Judge指标的不一致性**：在长数据集上（如LongMemEval的Know-Upd），MemoryCPT的F1最高但Judge低于LightMem，说明F1优化与语义正确性目标并非完全一致
5. **论文发表时间存疑**：标注2026/2027（AAAI 2027），但引用了大量2026年文献，读者需留意论文真实性和时效性（或为未来时间设定的研究环境）
6. **未解决的安全与隐私问题**：记忆系统存储用户长期对话含敏感个人数据，论文未讨论记忆持久化、遗忘机制、访问控制和隐私合规
7. **应用的工程边界**：离线蒸馏依赖deepseek-v3教师生成大量轨迹（LoCoMo 1185条），对无API预算团队不友好；LoRA-A的更新要求merge后重构建记忆库，记忆更新的代价未讨论

MemoryCPT通过"离线推理轨迹蒸馏（QAD）+ 在线GRPO成本感知摘要（QAR）"的端到端两阶段训练，首次让智能体记忆系统在**成本与质量的联合优化**上取得显著突破（LoCoMo QPC达0.111，较最强基线Memory-R1提升约13%），其QPC指标与成本摊销评估框架也为该领域树立了更全面的评估标准；但在3B小模型上的泛化性能、训练的分布外稳健性以及隐私安全方面仍有明显改进空间。
