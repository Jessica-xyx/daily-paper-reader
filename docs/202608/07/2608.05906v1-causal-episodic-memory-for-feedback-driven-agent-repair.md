## 摘要
能够在失败后修复的LLM智能体通常会丢弃成功的修正，迫使后续回合重新发现类似的解决方案。我们研究在无参数更新的情况下，最终的修复结果是否能够改善后续的Text-to-SQL回合。我们引入MERIT，一个无需训练的智能体，它维护一个在线双极性记忆，记录经过oracle验证的修正和观察到的失败方向。在oracle辅助的基准反馈下，只有来自先前最终回合的记忆才可用于检索。一个确定性分类器分配一个粗略的失败类型，该类型在冻结模型生成每个修订前调节一个混合词汇-稠密检索器。使用Qwen2.5-7B-Instruct，在相同的初始预测和修复预算下，MERIT在Spider上的执行准确率从66.34%提高到69.79%，在BIRD上从47.35%提高到48.44%，优于无状态迭代修复。配对分析为Spider上的提升提供了清晰的证据，但在BIRD上的证据较弱。在两个基准测试上，MERIT与无类型动态检索没有可靠区分，而Reflexion风格的记忆在BIRD上达到了51.24%，但推理成本显著更高。消融实验表明，负面记忆的贡献有限，类型调节和词汇-稠密排序的价值取决于数据集，而模式局部经验提供最一致的收益。这些结果阐明了因果跨查询记忆何时能改善修复，以及何时更倾向于更广泛的记忆表示。

## Abstract
LLM agents that repair failures often discard successful corrections, forcing later episodes to rediscover similar solutions. We study whether finalized repair outcomes can improve subsequent Text-to-SQL episodes without parameter updates. We introduce MERIT, a training-free agent that maintains an online dual-polarity memory of oracle-verified corrections and observed unsuccessful directions. Under oracle-assisted benchmark feedback, only memories from earlier finalized episodes are eligible for retrieval. A deterministic classifier assigns a coarse failure type, which conditions a hybrid lexical-dense retriever before the frozen model generates each revision. Using Qwen2.5-7B-Instruct with identical initial predictions and repair budgets, MERIT improves execution accuracy over stateless iterative repair from \(66.34\%\) to \(69.79\%\) on Spider and from \(47.35\%\) to \(48.44\%\) on BIRD. Paired analyses provide clear evidence for the Spider gain but weaker evidence on BIRD. MERIT is not reliably separated from untyped dynamic retrieval on either benchmark, while Reflexion-style memory reaches \(51.24\%\) on BIRD at substantially higher inference cost. Ablations show that negative memory contributes modestly, the value of type conditioning and lexical--dense ranking is dataset dependent, and schema-local experience provides the most consistent benefit. These results clarify when causal cross-query memory improves repair and when broader memory representations remain preferable.

### 二、论文提出的方法论

#### 2.1 核心思想

- 将Text-to-SQL修复建模为**因果情景记忆**（causal episodic memory）驱动的反馈修复过程：当前查询只能访问**已终局的前序回合**产生的修复经验，不能访问自身未完成轨迹或未来经验。
- 记忆按**极性**（polarity）分为正向（oracle验证的成功修正）和负向（观察到的失败方向），按**失败类型**（failure type）组织候选池，通过**混合词法–稠密检索**选取先例，在冻结模型生成修复时作为上下文注入。

#### 2.2 关键技术细节

**（1）因果在线修复流程**（算法流程）：

- 每个查询有共享的初始SQL预测，使用贪婪解码一次性生成，所有方法共用，以隔离修复策略的差异。
- 若初始预测正确，直接终局，不产生修复记忆。
- 若不正确，进入修复循环：分类失败类型 → 从因果可用记忆池检索 → 构造提示词 → 冻结模型生成一次修复 → 提交benchmark oracle评估。循环直到正确或预算（K=7）耗尽。
- 修复成功时，存储最终"失败→正确"转换（failed-to-correct transition）为正向记忆；修复失败时，存储最终观察到的失败方向为负向记忆。记忆仅在终局后对后续查询可见。

**（2）确定性失败分类器**：

- 输出类别包括：Result Mismatch、Schema Linking、Aggregation、Filter/Value、Execution、Syntax、Unknown。
- 使用有序规则，仅依据DBMS错误文本与执行状态，不检查SQL AST或推断语义错误（如错误的JOIN、排序等）。
- 分类正确率约48%（Spider 48.71%，BIRD 48.10%），Macro-F1分别为0.317和0.355，说明标签是"粗略但有用"的检索先验。

**（3）在线双极性记忆**：

- 记忆条目结构：`⟨c, τ, Δ, o, ρ⟩`，包含源问题、模式、失败SQL、状态与反馈（c）、失败类型（τ）、观察到的SQL转换（Δ）、极性（o）、来源信息（ρ）。
- 每回合终局最多产生**一条**记忆。正向记忆记录oracle确认的失败→正确转换；负向记忆仅记录"在该源上下文失败了"这一观察事实，不断言普适性。

**（4）类型条件化的混合检索**：

- 同一极性池内，若相同类型候选数 ≥ 3，则仅在该类型子池内检索；否则回退到完整合法同极性池（公式1）。
- 稠密（bge-large-en-v1.5余弦相似度）与BM25分数在各极性池内独立做min-max归一化，按 `0.75 × dense + 0.25 × BM25` 综合排序（公式 r(x,u) = 0.75 bd(x,u) + 0.25 bb(x,u)）。
- 分别对正负记忆排序，最多取3条正向 + 1条负向。
- 检索查询由当前问题 + SQL + 失败上下文 + 失败类型拼接而成。

**（5）修复生成与验证**：

- 提示词包含问题、模式、可选证据、当前SQL、尝试状态、DBMS错误、预测失败类型、本地历史、检索到的正负记忆（不含参考SQL、参考结果或修正后的SQL）。
- 冻结模型（Qwen2.5-7B-Instruct）贪婪解码生成一次修订。

**（6）类型可靠性感知变体**（MERIT variant）：

- 预定义高可靠性类型（Syntax、Schema Linking、Execution），仅对这三种类型做硬过滤（需 ≥ 3 条同类型）；低可靠性类型回退到完整池并施加0.10的类型匹配软奖励。

### 六、论文的主要结论与发现

1. **跨查询记忆确实能改善修复**：在Spider上，MERIT相对无状态Iterative修复提升 +3.45个百分点（95% CI [1.97, 4.96]），证据明确；在BIRD上提升仅 +1.09（95% CI [0.00, 2.17]），证据较弱。
2. **结构化记忆并未可靠优于非结构化动态检索**：MERIT与Dynamic RAG在Spider上打平（69.79% vs 69.79%），在BIRD上仅领先0.28个百分点，无显著分离。这否定了"极性分离+硬类型条件化必然更好"的假设。
3. **Reflexion-style在不同数据集上表现不一**：在BIRD上最强（51.24%），显著优于MERIT（配对CI为[-4.15, -1.46]），但推理成本最高（2,240万token、13,568次调用）。
4. **类型条件化与检索通道的价值依赖数据集**：
   - Spider上类型过滤（+0.58）和稠密排序（移除后-1.12）均有正收益；BM25在Spider上甚至略有负面效果。
   - BIRD上这些组件均无可靠收益，词法匹配反而更相关。
5. **模式本地经验是最一致的收益来源**：跨库限制使Spider下降0.93、BIRD下降2.74个百分点，在两种数据集上均显著，说明同库经验（重复连接路径、表关系、领域术语）难以被跨库类比完全替代。
6. **负向记忆贡献有限**：移除负向记忆仅造成约0.1个百分点的下降，验证成功的正向修正承载了绝大部分有用信号。
7. **硬类型过滤与软类型奖励无显著差异**：两者置信区间均跨零，说明错误类型更适合作为**粗粒度检索先验**，而非严格划分边界。
