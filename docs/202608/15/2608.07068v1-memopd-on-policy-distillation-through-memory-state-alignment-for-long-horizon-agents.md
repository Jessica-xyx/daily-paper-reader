## 摘要
长时程智能体在交互过程中会积累不断增长的上下文，从而损害性能与稳定性。紧凑型记忆通过压缩和重写在模型调用之间保留的历史信息来缓解这一问题。学习应该保留什么通常依赖于带有最终任务奖励的近端策略优化（PPO），但稀疏奖励对单个记忆更新的指导作用有限。这一局限促使了策略内蒸馏（OPD）的出现，它为学生的轨迹提供密集的教师监督。要使这种监督有效，教师必须在生成每个采样动作的同一状态下对其进行评估。然而，在记忆压缩过程中进行的上下文重写可能会破坏这种对齐。当采样的响应被保留并重新编码以供后续调用时，将交互扁平化为持久历史可能会导致教师在学生轨迹中从未访问过的状态下对动作进行评分。因此，该动作在来源上仍是策略内的，但在状态上却不一定如此。为此，我们提出了记忆对齐的策略内蒸馏（MemOPD）。MemOPD记录每次模型调用的输入和采样输出，恢复其原始令牌位置和因果可见性，并打包重构的调用以实现高效的教师评分。教师在采样动作位置提供全词汇表监督，而PPO保留最终任务目标。实验验证了在多次上下文更新中的状态对齐，并表明在匹配对照中，相较于持久历史教师评分，该方法将F1提升了7.0%。总体而言，MemOPD-3B在F1上比PPO提升了高达416.2%，同时打包在训练期间实现了高达1.63倍的actor计算加速。该工作的代码公开可用：https://github.com/TPssp/MemOPD。

## Abstract
Long-horizon agents accumulate growing contexts during interaction, impairing performance and stability. Compact memory mitigates this problem by compressing and rewriting the history retained between model invocations. Learning what to retain typically relies on proximal policy optimization (PPO) with final task rewards, but sparse rewards provide little guidance for individual memory updates. This limitation motivates on-policy distillation (OPD), which supplies dense teacher supervision on student rollouts. For such supervision to be valid, the teacher must evaluate each sampled action under the same state in which it was generated. However, the context rewriting performed during memory compression can break this alignment. When sampled responses are retained and re-encoded for later invocations, flattening the interaction into a persistent history may cause the teacher to score the action under a state that the student never visited during rollout. The action therefore remains on-policy by provenance, but not necessarily by state. We therefore propose Memory-Aligned On-Policy Distillation (MemOPD). MemOPD records the inputs and sampled outputs of each model invocation, restores its original token positions and causal visibility, and packs the reconstructed invocations for efficient teacher scoring. The teacher provides full-vocabulary supervision at the sampled action positions, while PPO preserves the final task objective. Experiments verify state alignment across several context updates and show that it improves F1 by 7.0% over persistent-history teacher scoring in a matched control. Overall, MemOPD-3B improves F1 over PPO by up to 416.2%, while packing yields up to a 1.63x speedup in actor computation during training. The code for this work is publicly available at: https://github.com/TPssp/MemOPD.

## MemOPD 论文详细总结

### 1. 核心问题与整体含义

- **研究背景**：长时程智能体（long-horizon agents）在多轮交互中不断积累上下文，导致 Transformer 计算成本上升、模型难以定位关键信息。紧凑记忆（compact memory）通过压缩和重写模型调用之间的历史信息来缓解这一问题。
- **核心矛盾**：学习记忆保留策略通常依赖 PPO + 最终任务奖励，但奖励稀疏且延迟，对单个记忆更新缺乏指导。策略内蒸馏（OPD）本可提供密集教师监督，但其有效性要求教师评估每个采样动作时，所处的状态必须与学生生成该动作时完全一致。
- **关键问题**：记忆压缩中的上下文重写会打破这一对齐。当采样响应被保留并重新编码为后续调用的上下文时，同一内容在不同调用中具有不同的角色、token 位置和因果可见性。若将交互历史直接扁平化为单一序列，教师就会在"学生从未访问过的状态"下评估动作——动作在来源上是 on-policy（确实由学生采样），但在状态上不是 on-policy。
- **量化证据**：在 3B 模型的审计中，持久历史重构造成 p99 对数概率误差达 1.774，在 651 个采样动作位置改变了 top 预测，并对 13.29% 的动作错误触发了 PPO 剪裁。

### 2. 方法论

**总体框架**：MemOPD 通过"记录—重建—打包—对齐优化"四步流程，保证所有训练目标（PPO、OPD、价值学习、参考正则化）在状态对齐的前提下执行。该框架的核心思想在于**区分动作的"来源有效性"与"状态有效性"**——单纯由学生采样的动作不足以保证蒸馏有效，还必须确保评分时所处的状态与采样时一致。

**记忆状态的定义**：对于第 t 次调用，定义记忆状态为 σ_t = (z_t, ρ_t, V_t, γ_t)，其中 z_t 是精确 token 化的输入，ρ_t 是 token 位置，V_t 是因果可见性，γ_t(k) 标识预测动作 token a_{t,k} 的输出分布位置。**状态对齐要求**：重建状态 σ̃_{t,k} = 实际 rollout 状态 σ_{t,k} 对每个采样动作 token 都成立。

**具体技术流程**：
- **精确调用记录**：记录 rollout 中每次调用的输入 z_t 和采样的确切 token ID（而非重新解码和分词），保留动作的 token 边界。
- **状态重建**：将记录的各次调用放入一个物理序列 y = [q, x_0, a_0, x_1, a_1, ..., x_{T-1}, a_{T-1}]，但物理相邻性与因果可见性分开处理：
  - 稳定前缀 q 只保存一份物理副本，位置保持为 0,...,|q|-1，对所有调用块可见（因所有独立执行中完全相同）。
  - 属于不同调用的 token 块之间**阻断注意力**。
  - 位置 ID 从各独立调用的原始索引重新开始，而不是沿打包序列递增。
  - 同一响应若被保留为后续上下文，则出现两次：一次作为采样动作（策略轨迹），一次作为上下文（获得新调用的位置和可见性）。
- **采样动作域**：定义 m^act_j = 1[y_j 属于记录的 a_t 采样出现]，区分采样决策与后续上下文副本。策略损失、熵、参考正则化、价值学习、GAE 都只在采样动作域上进行；教师掩码 m^T 满足 m^T_j ≤ m^act_j。
- **Rollout Context Equivalence（RCE）**：验证标准，要求打包执行与独立执行在相同 token、位置和可见性下产生相同的全词表 logits（在数值容差内），即 ‖ℓ^pack_{g(t,k)} − ℓ^ind_{t,k}‖_∞ ≤ ε_num。这是离线正确性审计，而非训练损失。
- **教师监督**：在状态对齐后，使用冻结教师提供全词表反向 KL 散度损失：
  - ℒ_OPD = (1/Σ_j m^T_j) Σ_j m^T_j Σ_{v∈V} p_{θ,j}(v) log(p_{θ,j}(v)/p_{T,j}(v))
- **策略优化**：PPO 保留最终任务目标，在同样的对齐状态上计算策略比率和优势估计。GAE 沿有序采样动作递归传播，跳过仅作为上下文的存储位置。参考 KL 惩罚定义为 KL^ref_j = [ℓ_old,j − ℓ_ref,j]_+，构成 token 级奖励 eṟ_j = r_j − β·KL^ref_j。最终 actor 目标：ℒ_actor = ℒ_PPO − αH + λℒ_OPD。

### 6. 主要结论与发现

- **状态不对齐确实存在并有害**：持久历史重构造成显著的对数概率误差、top-1 预测改变和错误 PPO 剪裁，且越靠后的调用偏差越大（top-1 一致率降到 81.20%，p99 对数概率差达 19.854，平均 KL 达 0.793）。
- **对齐带来显著提升**：在匹配对照中，仅教师指导（持久历史版）即使状态不对齐也已提升 F1 5.6%、EM 4.4%；状态对齐再额外提升 F1 7.0%、EM 10.0%。
- **长地平线收益更大**：MemOPD-3B 在 Q2/Q8/Q16 上比 PPO 分别提升 F1 14.3%、283.2%、416.2%，说明对齐教师在更长交互中价值更大。
- **迁移能力良好**：在 Wiki-RAG 上 EM 和 F1 分别比 PPO 提升 6.1% 和 7.4%，依赖度降低 31.6%，推理时间降低 28.5%。
- **RCE 可达数值下限**：重建打包与独立调用在全词表 logits 上一致（p99 误差 ~10⁻⁵），且对多种上下文更新策略（MEM1、全响应保留、摘要替换、滑动窗口等）均成立。
- **效率提升**：打包策略在保持 RCE 的同时，实现最高 1.63× 的 actor 计算加速（含前向+反向时 1.08–1.63×）。
- **可见性比位置更关键**：状态损坏消融显示，破坏可见性比破坏位置造成的误差更大，但位置错误单独也会改变 260 个 top 预测并造成 4.97% 错误剪裁。

### 7. 优点

- **问题识别精准且形式化严谨**：清晰区分了"动作来源上的策略内"与"状态上的策略内"，并用形式化定义（σ_t、RCE）将问题刻画得可验证、可审计。
- **方法设计优雅**：将"重建状态"与"标记采样动作域"解耦为两个独立环节——正确的状态重建保证条件化正确，正确的动作域防止一个决策被计两次，两者分别可测。
- **RCE 提供了强有力的验证标准**：不只是声称"对齐"，而是直接与独立调用比较全词表 logits 到数值下限，证据扎实。
- **实验设计公平且层次丰富**：匹配对照消除变量混淆；5 种子统计提供可靠性；状态审计、损坏消融、打包效率三方面独立验证机制。
- **方法具有通用性**：编译接口消费"实际 token 上下文"而非特定记忆拓扑，对 5 种受控上下文更新策略均保持 RCE，说明可支持多种记忆管理系统。
- **效率与正确性可兼得**：打包共享稳定前缀在不改变优化状态的前提下加速训练，打破了"正确性牺牲效率"的常见权衡。

### 8. 不足与局限

- **任务覆盖有限**：实验集中于检索问答类基准（HotpotQA/NQ/Wiki-RAG），未涉及网页导航、代码执行、多模态交互等更广泛的长时程 agent 场景，结论的普适性有待验证。
- **底层记忆协议仍以 MEM1 为主**：虽然测试了多种上下文更新函数的 RCE，但完整的端到端训练实例仅基于 MEM1；其他协议下的完整 RL 训练收益尚未验证。
- **依赖外部教师**：使用 gpt-oss-120b 生成 SFT 轨迹、7B 教师做蒸馏，教师自身的偏差或错误会通过蒸馏传递给学生；蒸馏收益的上限取决于教师质量。
- **状态审计规模偏小**：64 条轨迹、12,083 个动作 token 的审计虽能揭示问题，但更大规模下的统计置信度有待提升。
- **算力信息不完整**：未报告训练时长和总 GPU 时数；教师（120B）数据生成的算力消耗也未披露，影响复现和成本评估。
