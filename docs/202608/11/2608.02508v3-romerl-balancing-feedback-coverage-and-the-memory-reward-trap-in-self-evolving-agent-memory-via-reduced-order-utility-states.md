## 摘要
基于学习的记忆系统用于自进化LLM智能体，面临两个紧密耦合的挑战。第一，轨迹索引的效用随交互历史增长，从而将有限的反馈分散到不断扩展的状态空间上。第二，由于轨迹级奖励被共同分配给共同检索的记忆，不相关的经验可能收到误导性的效用更新，从而进入记忆-奖励陷阱。为了解决这些挑战，我们引入了降阶记忆强化学习（RoMeRL），它使用一个固定维度的每任务记忆状态来表示不断增长的轨迹索引效用空间，该状态由结果极性和记忆动态进行分解。RoMeRL通过一组固定的语义坐标来整合新经验，这些坐标的内容随时间更新或替换，从而将反馈集中在有界的效用支持上。理论上，我们表明这种降阶参数化增加了每个效用坐标收到的平均反馈，并刻画了在一般坐标转移模型下错误坐标的稳态占用。实证上，在ALFWorld和LifelongAgentBench上，RoMeRL提高了任务性能，将Cold-Q比率降低了80.0%，反馈密度提高了约6.0倍，维护的记忆大小减少了84.4%，LLM调用减少了21.1%。这些结果表明，降阶效用状态支持高效的自进化智能体记忆，同时限制了持续奖励污染。代码可在以下网址获取：https://github.com/YOUNG-fnxm/RoMeRL

## Abstract
Learning-based memory systems for self-evolving LLM agents face two tightly coupled challenges. First, trajectory-indexed utilities grow with the interaction history, thereby dispersing limited feedback over an ever-expanding state space. Second, because trajectory-level rewards are jointly assigned to co-retrieved memories, irrelevant experiences may receive misleading utility updates and consequently enter the memory-reward trap. To address these challenges, we introduce Reduced-Order Memory Reinforcement Learning (RoMeRL), which represents the growing trajectory-indexed utility space using a fixed-dimensional per-task memory state factorized by outcome polarity and memory dynamics. RoMeRL incorporates new experiences through a fixed set of semantic coordinates whose contents are updated or replaced over time, thereby concentrating feedback over a bounded utility support. Theoretically, we show that this reduced-order parameterization increases the average feedback received by each utility coordinate and characterize the steady-state occupancy of erroneous coordinates under a generic coordinate-transition model. Empirically, across ALFWorld and LifelongAgentBench, RoMeRL improves task performance, reduces the Cold-Q ratio by 80.0%, increases feedback density by approximately 6.0 times, reduces the maintained memory size by 84.4%, and cuts LLM calls by 21.1%. These results show that reduced-order utility states support efficient self-evolving agent memory while limiting persistent reward contamination. **核心问题：** 论文指出，现有的端到端记忆优化方法——尤其是轨迹索引（trajectory-indexed）效用学习——面临两个紧密耦合的挑战：

- **反馈分散（Feedback Dispersion）：** 每条新存储的轨迹都会引入一个新的效用变量，导致可学习的记忆状态维度随交互历史不断膨胀，有限的反馈被分散到不断扩大的状态空间上，产生"效用冷启动"、更新集中和反馈密度低等问题。
- **记忆-奖励陷阱（Memory-Reward Trap, MRT）：** 由于轨迹级奖励是对共同检索到的多条记忆进行联合分配的，弱相关或不相关的记忆可能搭便车获得正向效用更新。更强的探索虽然能提高反馈覆盖，但也会让更多弱相关记忆暴露在成功情境中，加剧奖励错配。

**整体含义：** 论文论证了探索与奖励污染之间存在根本性矛盾，并指出这一困境的根源在于"轨迹索引效用学习"这一表征范式本身——每增加一条经验就增加一个效用变量，探索越多、暴露于错误奖励传播的变量也越多。因此，核心问题是：**在不扩大暴露于错误奖励传播的效用支持的前提下，如何提高记忆反馈覆盖率？**

## 2. 论文提出的方法论

**核心思想：** 论文提出**降阶记忆强化学习（RoMeRL，Reduced-Order Memory Reinforcement Learning）**，用固定维度的语义坐标状态取代不断增长的轨迹索引效用空间，从而将有限的反馈集中在一个有界的效用支持上，同时限制记忆-奖励陷阱的持久暴露。

**状态分解：** 对于每个任务，RoMeRL将记忆状态分解为结果极性（Outcome Polarity）与记忆动态（Memory Dynamics）两个维度的笛卡尔积：

- 结果极性 O = {+, −}：区分成功（+）与失败（−）证据
- 记忆动态 D = {C, A}：区分固化的历史证据（C, Consolidated）与自适应的状态转移证据（A, Adaptive）

由此得到四个固定的语义坐标（2×2 = 4，共四个）：

| 坐标 | 全称 | 作用 |
|------|------|------|
| PCC | Positive Consolidated Coordinate | 保留全局最优的成功参考（最有效率成功轨迹），按效率替换并继承效用 |
| PAC | Positive Adaptive Coordinate | 记录"失败→成功"的首次正向转移，捕获恢复模式 |
| NCC | Negative Consolidated Coordinate | 保留积累了正向效用证据的高价值失败经验，按效用提升和替换 |
| NAC | Negative Adaptive Coordinate | 追踪最近的失败状态，每次新失败直接替换旧内容 |

**核心公式：** 状态映射可写为：
- 轨迹索引表示：Z_g,t = Φ(D_g,t)，维度为 4（固定）
- 每个坐标存储一个代表性记忆及其效用：z^(o,d)_g,t = (m^(o,d)_g,t, Q^(o,d)_g,t)
- 检索评分：score = (1−ω_Q)·cosine_sim + ω_Q·Q
- 运行时效用更新：Q' = Q + α·1[m ∈ S_t]·(r_t − Q)

**理论分析：**
- **定理1：** 对轨迹索引记忆的Q值估计进行偏差-方差分解，证明额外反馈只降低方差项（σ²/n），不能消除任务基线 v⁰ᵢ 和观察归因偏差 aᵢ。
- **定理2：** 若要保持全池估计精度，反馈预算以 O(N_t/ε²·log(N_t/δ)) 增长，轨迹预算至少为 O(N_t/(kε²)·log(N_t/δ))，即维度成本是不可避免的。
- **定理3：** 维度从 N_t 降为4后，每个坐标的平均反馈从 O(σ²N_t/kT) 改善为 O(4σ²/kT)。
- **命题1：** 采用清洁-错误二态马尔可夫转移模型，稳态错误坐标占比不超过 γ/(γ+λ)，只要 d·γ/(γ+λ) < N_t·ρ_full 即可低于全池暴露。

## 6. 论文的主要结论与发现

1. **性能提升**：RoMeRL在10个评估单元上取得最高总体平均分0.753，比最强整体基线MemRL（0.724）高出2.9个百分点。在ALFWorld的6个任务类型中，5个达到最优；在AppWorld上SGC从0.286提升至0.326（+4.0个百分点），TGC基本持平（0.306 vs 0.313）。
2. **反馈利用效率显著改善**：Cold-Q比率从MemRL的44.9%降至9.0%（相对降低80.0%）；反馈密度从4.96提升至29.93（约6.0倍）。
3. **资源消耗大幅降低**：LLM调用减少21.1%（570K→450K），记忆池大小减少84.4%（45K→7K）。
4. **MRT鲁棒性**：在受控压力测试中，RoMeRL的噪声正更新仅2.4次（MemRL+UCB为7.2），最终噪声比例仅0.15%（基线为1.02%–1.20%），同时取得最高成功率82.0%。
5. **跨模型可迁移性**：冻结记忆状态可转移到更强或更弱的LLM推理模型上，四种模型-任务组合均获得正向收益（+1.4到+14.6个百分点）并减少平均执行步数。
6. **容量控制不足以解释全部增益**：与同样限制4条记忆/任务的MemRL-4相比，RoMeRL仍显著领先，说明因子化语义坐标结构本身提供了超出单纯容量控制的优势。
7. **因子化状态的角色互补性**：NCC贡献最大占用（OS 27.14%、DB 42.78%），其移除同时降低SR和CSR；PAC占用虽小（OS 8.21%、DB 5.05%），但对最后一轮SR有显著影响，表明正的自适应转换信号是稀疏但必要的。

3. **Q值质量分析**：通过点二列相关（r从0.493提升至0.673）和Q值分层组成分析，证明RoMeRL学到了超越二元成功/失败标签的、更细粒度的记忆效用信号。

## 8. 不足与局限

### 方法层面的局限
1. **因果归因不完整**：论文明确承认仍依赖结果级奖励（outcome-level rewards），未从根本上解决"奖励共指"引发的因果归因问题，只是缩小了效用支持的空间使其危害更小。
2. **γ和λ难以估计**：命题1中的转移概率需要在配套反事实轨迹或等价归因下才能估计，实际操作中缺乏可靠方法获取这些参数。
3. **状态表达能力有限**：每任务仅4个坐标，对于任务模式极其复杂的场景（如需要同时维护多个不同子策略的任务），4坐标可能无法捕获全部有用的经验。
4. **替换策略偏简单**：PCC按效率、NCC按效用、NAC按最近时间，这些规则是启发式的，没有端到端学习最优替换策略。

### 实验层面的局限
1. **消融范围不足**：NCC和PAC消融仅在OS任务上进行，没有在DB、ALFWorld或AppWorld上进行，结论的泛化性存疑。
2. **缺乏统计显著性报告**：未提供多次运行的标准差、置信区间或显著性检验，无法判断2.9个百分点的总体优势是否显著。
3. **时间跨度有限**：只在10轮内评估，未探索更长时间跨度的记忆退化和状态收敛行为。
4. **跨模型迁移方向有限**：全部是从DS-V4-flash迁移到其他模型，未检验反向迁移或其他模型间迁移。

### 应用方面的限制
1. **评测基准的生态位有限**：没有在代码生成、数学推理或开放域对话等更广泛智能体场景上验证。
2. **依赖高质量嵌入模型**：检索质量依赖语义嵌入的判别力，嵌入模型效果不佳可能导致坐标内容严重偏斜。
3. **开源代码的完整性问题**：虽然提供了GitHub链接，但论文中未见对应的Licensing或版本细节，复现完整度有待验证。
