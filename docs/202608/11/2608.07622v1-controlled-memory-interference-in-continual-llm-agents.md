## 摘要
长期记忆使AI智能体能够跨会话保持连续性、个性化行为，并通过积累的经验不断进化。然而，记忆进化并非简单地存储更多信息：新经验可能强化、修正或干扰已有的记忆状态。现有系统主要强调记忆构建和基于相关性的检索，但多个记忆可能同时相关，却在状态、时间有效性或权威性上有所不同。我们提出了受控记忆干扰（CMI），一个用于研究智能体记忆在不同记忆关系下如何进化的受控诊断与数据生成框架。在受控记忆进化中，良性积累影响有限，而特定关系的干扰会显著抑制更新可塑性，且几乎不带来稳定性增益——要么通过阻断目标记忆的暴露，要么通过破坏其下游使用。词汇检索与稠密检索展现出不同的干扰路径，而中毒攻击对更新权威线索的敏感性高于单纯的近因性。除诊断外，CMI还为干扰感知的记忆学习提供了针对性示例，在保持原始记忆任务性能的同时，改善有效更新与干扰诱导记忆之间的区分。这些发现表明，记忆进化不仅受记忆规模影响，还受积累经验之间相互作用的影响。更广泛地看，记忆干扰成为可靠持续智能体记忆系统中的一个重要因素。

## Abstract
Long-term memory enables AI agents to maintain continuity across sessions, personalize behavior, and evolve through accumulated experience. Yet memory evolution is not simply a process of storing more information: new experiences may reinforce, revise, or interfere with existing memory states. Existing systems mainly emphasize memory construction and relevance-based retrieval, but several memories may remain simultaneously relevant while differing in state, temporal validity, or authority. We introduce Controlled Memory Interference (CMI), a controlled diagnostic and data-generation framework for studying how agent memory evolves under different memory relationships. Across controlled memory evolution, benign accumulation has limited effects, whereas relationship-specific interference sharply suppresses update plasticity with little stability gain, either by blocking target-memory exposure or by disrupting its downstream use. Lexical and Dense retrieval exhibit distinct interference pathways, while poisoning is more sensitive to update-authority cues than to recency alone. Beyond diagnosis, CMI provides targeted examples for interference-aware memory learning, improving the distinction between valid updates and interference-inducing memories while preserving performance on original memory tasks. These findings show that memory evolution is shaped not only by memory scale, but also by interactions among accumulated experiences. More broadly, memory interference emerges as an important factor for reliable continual agent memory systems.

- **核心问题**：持续运行的大语言模型（LLM）智能体依赖长期记忆保持跨会话连续性、个性化行为与经验积累。然而，记忆进化并非简单的信息堆叠——新经验可能**强化、修正或干扰**已有记忆状态。当多个记忆同时与当前决策相关、却在**状态新旧、时间有效性和权威性**上存在冲突时，智能体应采纳哪一个状态？
- **现有方法不足**：主流记忆系统（Generative Agents、MemGPT、MemoryBank、Mem0、A-MEM）主要关注记忆的**构建、组织与相关性检索**，而未回答"被检索到的记忆是否仍适用于当前状态"这一关键问题。检索到的旧偏好可能已被合法更新取代，或重复经验过度强调了不再适用的状态。
- **概念界定**：论文将此类失败定义为**记忆干扰（Memory Interference）**，功能上类比人类记忆中的前摄干扰与线索过载现象，但不假设两者共享相同内部机制。
- **整体意义**：记忆干扰比传统检索失败更宽泛——干扰记忆可能阻止目标记忆进入检索上下文，也可能在目标被检索到后误导下游决策。论文强调：**记忆进化不仅取决于记忆规模，更取决于积累经验之间的相互作用**，记忆干扰是构建可靠持续智能体记忆系统的关键因素。

## 2. 方法论：核心思想、关键技术细节与算法流程

### 核心思想：受控记忆干扰（CMI）框架

- CMI 是一个**受控诊断与数据生成框架**，通过固定查询、目标状态和期望决策，只改变**记忆规模（load）**与**记忆间关系（relationship）**，从而将干扰效应从任务本身中分离出来。
- 实例化为 **CMI-Travel**，基于 MemoryArena 中的 Travel Planner 任务构建。

### 形式化定义

- 每个源案例包含查询 \(q_i\)、期望决策 \(y_i\)、记忆集合 \(M_i\)
- 记忆集合划分为三部分：
  - \(M^+_i\)：目标记忆（应影响当前决策）
  - \(M^c_i\)：竞争记忆（相关但不适用于当前状态，如被取代的状态、瞬时例外、同槽冲突或误导性更新）
  - \(M^o_i\)：其他受控/背景记忆
- 受控场景构造：\(M^{c,\ell}_i = B_i \cup \Delta^{c,\ell}_i\)，其中 \(B_i\) 为基记忆集，\(\Delta^{c,\ell}_i\) 为受控添加的记忆，所有变体共享相同的查询、期望决策和目标记忆集。

### 三个受控协议

1. **记忆规模增长（L0–L6）**：从约 3 条记忆逐步增长至 135 条，考察纯数量效应。
2. **关系受控组合**：在固定数量下对比四类关系——
   - **匹配中性（Matched neutral）**：模板和长度匹配但不改变状态
   - **无关记忆（Unrelated）**：估计容量压力
   - **重复历史（Repeated history）**：支持旧值的额外记忆
   - **同槽冲突（Same-slot conflict）**：同一实体-属性槽上的竞争值
3. **固定 L3 权威探针（P0–P3）**：将误导记忆分别框定为普通噪声（P0）、近期瞬时提及（P1）、显式持续更新（P2）、权威纠正（P3），分离近因性与更新权威性。

### 三个行为维度

- **可塑性（Plasticity）**：是否采纳合法持续更新
- **稳定性（Stability）**：面对瞬时/情境例外时是否保留既有状态
- **抗中毒性（Poisoning resistance）**：是否拒绝无效或误导性更新
- 不预设对称的稳定-可塑性权衡。

### 检索指标与路径分解

- 指标包括：**Target Recall@k**、**Preference Ordering（PO）**、**MRR**、**共暴露率（Co-exposure）**
- **检索到决策的分解**：\(\Pr(A=1) = \Pr(T=1)\Pr(A=1|T=1)\)，并报告 \(\Pr(A=1|T=1,C=1)\)，用于区分"目标未曝光"与"曝光后下游歧义"两类失败。

### CMI 引导的检索自适应（IAAR）

- 轻量级选择器 \(g\) 将**可观测检索状态特征**（分数差距、检索熵、词法重叠、语义相似度、重复密度、跨检索器一致性等 18 维特征）映射为混合权重 \(\alpha \in \{0, 0.25, 0.5, 0.75, 1\}\)
- 融合得分：\(s_i(m) = \alpha \cdot bs_L(q_i,m) + (1-\alpha) \cdot bs_D(q_i,m)\)
- 训练对比：仅干净数据 vs. **CMI 数据增强**（\(D_{aug} = D_{clean} \cup D_{CMI}\)），验证 CMI 生成案例能否提供有效监督信号；部署时选择器无法访问目标/竞争记忆标注。
