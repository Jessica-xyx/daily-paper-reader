## 摘要
长期记忆使语言代理能够复用过去的事实、偏好和任务经验。持久性也造成了一个核心的可证伪性问题：当世界发生变化时，过时的记忆仍可能被检索到并污染提示词。我们将这种失败模式定性为记忆污染：由较新的冲突证据所取代的活跃记忆引起的退化。我们提出了TEPA，一种可撤销的证据-记忆机制，将有效性作为记忆的显式状态。TEPA将观察表示为带键的先例，并在新证据在相同键下与活跃先例矛盾时撤销该先例，使检索能够从当前证据中获取信息，同时保留被撤销的历史以供审计。在受控的隐藏状态漂移、真实文件支持的可执行漂移以及偏好更新流中，撤销机制防止了过时的活跃记忆在反转后仍留在检索集中。在50个种子上的受控漂移中，完全反转期间，仅追加和最后写入优先记忆的性能低于无记忆（仅追加和最后写入优先均为0.210，无记忆为0.309，TEPA为0.950），同样的模式在真实文件执行下也得到重现（仅追加0.203，无记忆0.298，TEPA 0.950）。在干净的MemoryAgentBench SH-6k上，TEPA与强大的最后写入优先缓存相匹配，确认当前键替换是单跳事实合并的决定性操作。对多跳和超长上下文MemoryAgentBench设置的边界测试暴露了超出事实级有效性追踪的检索链和上下文选择瓶颈。总而言之，这些结果确立了生命周期撤销作为核心记忆操作，适用于必须证伪、审计并随后重新提升不断演进的知识的代理。

## Abstract
Long-term memory enables language agents to reuse past facts, preferences, and task experience. Persistence also creates a central falsifiability problem: when the world changes, stale memories can remain retrievable and pollute the prompt. We characterize this failure mode as memory pollution: degradation caused by active memories that newer conflicting evidence has superseded. We introduce TEPA, a revocable evidence-memory mechanism that makes validity an explicit state of memory. TEPA represents observations as keyed precedents and revokes active precedents when fresh evidence contradicts them under the same key, allowing retrieval to draw from current evidence while preserving revoked history for audit. Across controlled hidden-regime drift, real file-backed executable drift, and preference-update streams, revocation prevents stale active memory from remaining in the retrieval set after reversal. In controlled drift over 50 seeds, append-only and last-write-wins memory fell below no memory during full reversal (append-only and last-write-wins both 0.210, no memory 0.309, TEPA 0.950), and the same pattern reproduced under real file execution (append-only 0.203, no memory 0.298, TEPA 0.950). On clean MemoryAgentBench SH-6k, TEPA matches a strong last-write-wins cache, confirming that current-key replacement is the decisive operation for single-hop fact consolidation. Boundary tests on multi-hop and very long-context MemoryAgentBench settings expose retrieval-chain and context-selection bottlenecks beyond fact-level validity tracking. Together, these results establish lifecycle revocation as a core memory operation for agents that must falsify, audit, and later re-promote evolving knowledge.

## 2. 论文提出的方法论

### 核心思想

TEPA（全称未在论文中给出明确展开，指 Revocable Evidence-Memory Mechanism）将记忆视为一组**带键先例（keyed precedents）**，每个先例有**显式生命周期状态**（Hypothesis / Active / Revoked）。当新证据与同键的活跃先例冲突时，将旧先例**撤销（revoke）**，移出常规检索集，同时保留在归档中供审计。

### 关键概念与公式

#### 先例（Precedent）定义
一个先例表示为五元组：
p = (k, v, s, f, σ, τ)
- k：冲突键（conflict key）
- v：断言值或动作模式
- s / f：支持计数 / 冲突计数
- σ：生命周期状态（Hypothesis / Active / Revoked）
- τ：创建时间

#### 冲突定义
两个证据项冲突当且仅当它们共享同一键但值不兼容：
conflict(xᵢ, xⱼ) = 𝟙[κ(xᵢ) = κ(xⱼ) ∧ ν(xᵢ) ≠ ν(xⱼ)]

#### 有效性后验估计
使用 Beta-Bernoulli 模型估计先例的当前有效性后验均值：
q(p) = (s_p + α) / (s_p + f_p + α + β)
实验中取 α = β = 1。

#### 状态转移规则
- **撤销条件**：当后验均值 q(p) 低于 θ_rev（=0.3）且至少 n_min（=5）次观察后；或同键结果达到 n_rec（=3）次且近期成功率低于 θ_rec（=0.34）时，先例从 Active 转入 Revoked。
- **晋升条件**：当同键同值的累积支持达到 θ_prop（=3）后，创建候选先例（Hypothesis 态）；当后验 q(p′) ≥ θ_pro（=0.6）或通过试验验证后，转为 Active 态。

#### TEPA-Full（试验验证变体）
在晋升前通过"执行试验"验证候选先例：分配支持任务、反事实任务、污染检查各 1 个（共 3 个试验），60% 以上为正且至少一个支持任务成功才能晋升。

### 算法流程（文字描述）

1. 对每个 episode，先从活跃记忆中检索相关先例；
2. 执行策略并观察结果与新证据 x_t；
3. 提取键 k_t 和值 v_t；
4. 遍历活跃记忆中同键先例：同值则支持计数 +1；不同值则冲突计数 +1；
5. 检查撤销条件，满足则将先例移入 Revoked 归档；
6. 检查晋升条件，满足则创建/更新候选并激活。

### 理论支撑

论文给出一个风险视角的充分条件：设过时值 v⁻ 被检索暴露的概率为 ξ，下游策略跟随过时值的概率为 η，记忆污染发生时（ξη > b，b 为当前证据的相对收益），append-only 的期望错误高于无记忆。撤销正是消除这一有害项 ξη 的机制。

## 6. 论文的主要结论与发现

### 核心结论

1. **仅追加式记忆可能比无记忆更差**：在完全反转阶段，append-only 和 last-write-wins 均降至 0.210（受控）和 0.203（执行），低于无记忆的 0.309 / 0.298，产生正污染指数约 0.32。
2. **撤销机制有效防止记忆污染**：TEPA 在完全反转阶段达到 0.950 成功率，远高于所有基线。配对差异显著（d_z = 9.68，Holm p < 0.001）。
3. **当前键替换是单跳事实合并的决定性操作**：在干净的 MemoryAgentBench SH-6k 上，TEPA-Rev 与强大的 last-write-wins 缓存持平（均为 0.890），而无撤销变体仅 0.630。
4. **偏好更新需要试验验证 + 生命周期撤销的互补**：TEPA-Full 总体 0.910，与无记忆统计上不可区分（差异 0.002，p = 1.000）；仅靠验证不够，仅靠撤销也不够。
5. **边界瓶颈**：多跳（MH-6k 0.040）和超长上下文（SH-262k 0.000）显示，事实级有效性追踪之外，检索链构建和长上下文选择是下一步架构挑战。

### 设计与系统含义

- 持久记忆需要**显式有效性状态**：相关性、近因性都不足以判断证据是否被取代；
- 撤销应是**局部、键级**操作，而非全局重置；
- 被撤销的历史应保留在归档中，支持审计、诊断和之后的重新激活（re-promotion）；
- TEPA 将长期记忆重新定义为**可检查的生命周期系统**，每个先例携带键、证据、状态和矛盾历史。

## 7. 优点

### 方法层面的亮点

- **问题定义清晰**：将"过时记忆污染"形式化为可量化的概念（记忆污染指数 MPI），并给出理论下界（Proposition 1-3），衔接了系统层面的直觉与形式化保证；
- **机制设计优雅**：用 Beta-Bernoulli 后验作为状态转移信号，透明、可解释、无需训练；撤销保留历史（archive）而非删除，兼顾"当前正确性"与"可审计性"；
- **两级验证**：默认 TEPA 基于后验概率撤销，TEPA-Full 增加执行试验验证，适用于不同可信度要求的场景；
- **通用性**：该机制不依赖特定 LLM 架构或训练，可作为任何代理记忆系统的插件式生命周期层。

### 实验设计的亮点

- **配对检验设计**：同一 seed 和任务索引下比较所有方法，有效控制任务难度方差，显著提高统计功效；
- **基线学价值高**：每个基线隔离一种替代方案（无冲突键的遗忘、全局重置、当前键缓存等），精确回答"哪种操作缺失导致了失败"；
- **诚实边界报告**：主动报告方法在多跳和超长上下文上的失败，刻画出方法的适用边界，增加可信度；
- **确定性环境隔离**：自建基准使用确定性执行器，排除 LLM 采样噪声，使记忆状态成为唯一变量，因果归因干净；
- **可扩展性审计**：提供了百万级更新的微基准，回应了部署可行性问题。

---

## 8. 不足与局限

### 实验覆盖方面的不足

- **冲突键假设较强**：TEPA 假设可从证据中提取有用的冲突键，这对偏好槽位、实体属性、工具状态等结构化场景自然适用，但对开放域、隐式冲突关系的记忆则困难得多。论文虽然在附录做了键噪声审计（20% 噪声下 TEPA 降至 0.777），但未做开放域 LLM 解析键的系统性评估；
- **基准场景范围有限**：自建基准集中在"单一键的取代"这一特定冲突模式，未覆盖多键交互、记忆冲突的网络传播、不同粒度的知识层级冲突；
- **语义检索基线偏弱**：仅用词法相关性排名，未用稠密检索或重排序，可能没有充分代表当前 SOTA 检索系统；
- **确定性环境 vs 真实复杂度的差距**：受控基准故意最小化上下文变异性（"context is similar across phases"），而真实代理场景中区分"同键冲突"往往需要更复杂的语义理解；
- **任务规模限制**：每组仅 160 tasks/seed，虽然 50 seeds 增强了统计可靠性，但任务类型的多样性有限。

### 方法层面的局限

- **整体回复依赖后端模型**：TEPA 只保证检索集中的证据是"当前有效"的，不保证 LLM 正确使用这些证据（如 Oracle reset 只有 0.812 而非 1.0，表明基础执行器本身有弱点）；
- **适应性延迟**：TEPA 在反转后需要积累足够的反证才触发撤销（误差集中在反转后的最初几次同键试验），0.950 的得分离 1.0 仍有差距，对快速切换的环境可能反应偏慢；
- **不支持参数知识修正**：TEPA 仅操作显式记忆状态，当模型自身参数中的知识过时且未检索到相关证据时，无法修正；
- **多跳与长上下文能力缺失**：边界实验明确显示，TEPA 在 MH-6k（0.040）和 SH-262k（0.000）上基本失效，说明事实级撤销无法替代检索链构建和长上下文选择能力。

### 偏差风险

- **自证风险**：自建基准的设计者同时也是方法设计者，虽然配对设计和确定性环境提高了内部效度，但外部效度仍需更多第三方基准验证；
- **Last-write-wins 设计偏置**：论文承认在漂移基准中 last-write-wins 因"只写成功同键经验"而表现得像 append-only，这可能在某种程度上低估了 LWW 在真实场景中的表现；
- **模型单一性**：MemoryAgentBench 实验只用了 DeepSeek-v4-Flash 一个后端，未验证不同 LLM 下的稳定性。

---

## 总结性评价

TEPA 是一篇问题定义精准、方法设计优雅、实验论证严谨的机制研究。它将"过时记忆污染"从模糊的现象提炼为可度量的概念，并提出了一种轻量、可解释、无需训练的记忆生命周期管理方案。核心贡献在于确立了一个此前相对被忽视的论点：**持久记忆需要显式有效性状态，生命周期撤销应与记忆的写入、检索同等重要**。论文的诚实边界报告也为后续研究指明了方向——多跳检索链构建与超长上下文选择是比事实级有效性追踪更困难的下一层挑战。该工作将对语言代理记忆系统的设计产生持续影响，但距离真实开放域部署仍需解决冲突键自动提取、快速自适应和跨模型泛化等关键问题。
