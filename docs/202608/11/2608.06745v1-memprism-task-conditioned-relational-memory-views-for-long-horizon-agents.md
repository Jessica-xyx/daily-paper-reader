## 摘要
长时程智能体依赖记忆来复用经验，然而现有的记忆系统往往假设证据可以通过固定表示直接消费。这导致了表示不匹配问题：相关信息虽可用，但并未针对当前决策进行组织。为此，我们提出了MemPrism，一种任务条件化的关系记忆框架，将持久化的经验存储与决策时的工作记忆相分离。MemPrism将交互记录为事件流，并根据当前任务上下文动态构建关系视图。一个轻量级的视图策略选择关系结构、证据范围、结果条件和粒度，而一个确定性的组合器与渲染器将历史事实转化为临时的工作记忆视图，供冻结的任务策略使用。在长时程具身与Web智能体基准上的实验表明，MemPrism一致地提升了任务性能，尤其在轨迹变长时效果更为显著，同时减少了记忆token的消耗。此外，所学得的视图策略无需额外适配即可跨不同的VLM迁移，展示了任务条件化关系视图作为智能体通用记忆接口的有效性。

## Abstract
Long-horizon agents rely on memory to reuse experiences, yet existing memory systems often assume that evidence can be directly consumed through a fixed representation. This leads to representation mismatch, where relevant information is available but not organized for the current decision. To this end, we propose MemPrism, a task-conditioned relational memory framework that separates persistent experience storage from decision-time working memory. MemPrism records interactions as the event stream and dynamically constructs relational views according to the current task context. A lightweight view policy selects the relation structure, evidence range, outcome condition, and granularity, while a deterministic composer and render transform historical facts into a temporary optical working-memory view for a frozen task policy. Experiments on long-horizon embodied and web-agent benchmarks show that MemPrism consistently improves the task performance, especially as trajectories become longer, while reducing memory token consumption. Furthermore, the learned view policy transfers across different VLMs without additional adaptation, demonstrating the effectiveness of task-conditioned relational views as a general memory interface for agents.

- **核心问题**：论文提出并形式化了长时程智能体中一个被忽视的瓶颈——**“检索后表示不匹配”（post-retrieval representation mismatch）**。该问题与存储失败或检索失败不同：正确的证据已经被保存并被检索到，但其组织方式（固定表示）没有暴露当前决策所需的关系结构，导致智能体仍然做出次优决策。
- **背景动机**：随着 LLM/VLM 智能体在 Web 导航、软件工程、具身交互等领域中面临数十乃至上百步的长轨迹决策，记忆系统的重要性日益凸显。现有记忆方法沿着三个方向推进：持久化结构组织（层级摘要、知识图谱等）、可学习的记忆控制、光学记忆表示。它们改进的是记忆的存储、管理和访问，但普遍共享一个隐含假设——**检索到的证据可以用固定表示直接消费**。
- **关键洞见**：论文指出，同一段历史事实可能因任务不同而需要不同的组织方式：循环检测需要对齐重复动作与结果，状态跟踪需要按实体随时间聚合，失败分析需要连接动作与环境反馈，依赖分析需要连接远距离相关事件。时间线、状态表、动作-效果视图、依赖追踪等均可由相同事实构建，却突出不同类型的证据。因此，**“获取正确的证据”不等于“证据对当前决策有用”**。
- **核心主张**：持久记忆应保存稳定可复用的交互事实（事件流），而工作记忆应针对当前决策动态构建。“如何向策略呈现检索到的证据”本身是需要学习的决策问题。

## 2. 论文提出的方法论

### 核心思想

MemPrism 是一个**任务条件化的关系工作记忆框架**，将持久经验存储与决策时工作记忆完全分离。其核心思路是：用统一事件流保存客观交互事实，在每一步决策时根据当前任务上下文动态构建一个临时、任务专属的关系视图（光学图像），供冻结的任务策略使用；视图用完即弃，绝不写回持久记忆。

### 系统架构（五个模块）

1. **Recorder（记录器）**：持久事件记忆模块。保存原始事件：
   - 原始事件：`e_t = (o⁻_t, u_t, y⁺_t, r_t, m_t)`，即执行前观测、执行动作、反馈、奖励/步骤标签、元数据。
   - 结构化事件：`ẽ_t = (t, e_ent, e_act, e_out, Δs_t, ξ_t)`，即主实体、规范化动作类型、结果类型（异常/状态更新/无变化）、稀疏状态更新集、可选证据（标签、图像、框、裁剪）。**不要求提取器推断旧值**，只记录最新观测值。
   - 事件流通过时间追加方式更新，关系结构和渲染视图永不写回。

2. **Router（路由/视图策略）**：决定智能体应如何“看”历史而非产生环境动作。输入为当前观测、任务目标、近期事件特征和全局历史统计，编码为 `z_t`，输出一个联合视图动作：
   - 视图动作 `a_v = (τ_t, w_t, c_t, γ_t) ∈ A_v`，包含四个因子（联合动作空间共 144 = 4×3×4×3）：

| 因子 | 选项 |
|---|---|
| 关系类型 τ | TemporalTrace（时间轨迹）、ActionEffect（动作-效果）、EntityState（实体状态）、DependencyChain（依赖链） |
| 时间范围 w | Short（最近6个）、Long（最近10个）、All（全部） |
| 结果过滤 c | All、Exception（异常）、Update（状态更新）、No-change（无变化） |
| 粒度 γ | Coarse、Medium、Fine |

   - 采用联合 head 保持四个因子之间的依赖关系；训练时采样，评估时取 argmax。
   - 两个最近范围分别包含最近 6 和 10 个事件。

3. **Composer（组合器）**：将视图动作转换为关系结构。先按时间范围、结果过滤器和任务目标选择事件（同时恢复可能被严格过滤移除的任务相关事件），再构建关系特定结构。四种关系视图分别服务于不同的诊断问题：时间顺序、重复动作-结果模式、实体状态累积、以最新事件为锚点的局部依赖追踪。

4. **Render（渲染器）**：将关系结构映射为光学工作记忆视图，使用固定视觉语法：空间邻近表示分组、行列对齐支持比较、箭头表示变化/依赖、高亮标记失败和任务相关证据。渲染是确定性的——相同输入永远产生相同输出。

5. **Adapter（适配器）**：仅训练时使用，训练 Router 分两个阶段：
   - **决策条件初始化（SFT）**：视图教师根据决策状态与参考下一动作返回视图动作上的软分布 `q_T(a|t)`，Router 最小化 KL 散度与结构成本项的加权和（鼓励不过度使用大范围/细粒度）。
   - **结果引导优化（GRPO）**：由于教师监督可能不覆盖部署策略产生的状态，在在线环境中用分组 GRPO 微调 Router——同任务多条轨迹的回报归一化得到轨迹优势，目标函数包含裁剪的 PPO 项、参考策略 KL 惩罚和熵奖励。**只更新 Router**，其他模块全部冻结，使轨迹奖励专门用于学习“历史应如何呈现”。

### 与其他方法的关键区别

- 相比结构化记忆方法（关系结构在写入时形成并共享）：MemPrism 存规范化事件、按需构建关系视图。
- 相比可学习记忆控制方法（学习存什么、取什么、生成什么指导）：MemPrism 研究同一证据在交给任务策略前应如何组织。
- 相比光学记忆方法（关注存储/压缩效率）：MemPrism 用二维布局表达关系语义，光学只是任务条件化关系接口的输出空间。

## 6. 论文的主要结论与发现

1. **表示不匹配是真实且重要的瓶颈**：相同证据在不同关系结构下产生不同成功率（最大差距 5.71 个百分点），印证“正确的证据被检索到但未被正确组织”是独立的失败模式。
2. **动态组织与光学呈现互补增益**：动态文本组织独立贡献 5.00 点，光学呈现独立贡献 3.57 点，二者结合效果最佳（40.71%）。
3. **自适应粒度最关键**：固定细粒度导致最大降幅（-7.84 点），是四因子中影响最大的；固定 all 结果过滤器则最接近完整策略。
4. **长轨迹优势更显著**：轨迹达到 15 步后 MemPrism 反超 Full History，且在 ≤40 至 ≤50 步区间差距扩大至 9.3 个百分点；Full History 在 30 步后停滞，MemPrism 仍持续提升。
5. **提示压缩效果明显**：在 ≤50 步阈值，MemPrism token 消耗比 Full History 降低 33.6%（797 vs. 1,201），同时 SR 更高。
6. **跨 VLM 迁移**：在训练 VLM 上训练得到的视图策略零样本应用于三个未见 VLM 时，成功率全部提升（+2.26 至 +9.40 个百分点），token 减少 30.6% 至 48.2%，证明任务条件化关系视图可作为通用记忆接口。
7. **GRPO 优于纯 SFT**：在 ALFWorld 上 GRPO 较 SFT 提升 6.42 点，说明在线任务级反馈能有效对齐视图选择与下游任务成功。

## 7. 优点（方法或实验设计上的亮点）

- **问题定义清晰**：首次形式化“检索后表示不匹配”并将其与存储/检索失败区分，提供了新的记忆研究视角。
- **架构解耦合理**：持久事件流与临时工作视图完全分离，避免固定摘要的不可逆失真与重复压缩误差；视图用后即弃、不污染持久记忆。
- **光学视图设计巧妙**：二维布局本身就编码了关系语义（邻近、对齐、箭头、高亮），而非仅压缩文本。
- **严格归因实验设计**：保持任务策略冻结、只训练 Router，使最终增益可较直接地归因于记忆表示接口，而非任务策略本身的变化。
- **强大的可复现性保障**：附录包含详细的运行清单（代码版本、数据分割、随机种子、模型 ID、checkpoint 哈希、解码设置等），外部基线使用官方实现并在附录说明每个基线的具体版本和适配方式。
- **跨模型泛化验证**：用单点训练规划器在多个 VLM 上零样本迁移并观察一致增益，增强结论的外部有效性。
- **多维度效率分析**：区分 Phi 调用、渲染像素、视觉 token、提示 token、延迟等，不把“记忆成本”模糊为一个数字。
- **教师蒸馏 + 在线 RL 两阶段训练**：SFT 提供条件化初始能力，GRPO 进一步将视图选择与任务回报对齐，二者互补效果经消融验证。
