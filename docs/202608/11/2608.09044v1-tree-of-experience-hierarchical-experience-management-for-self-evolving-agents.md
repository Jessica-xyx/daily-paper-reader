## 摘要
持续自我进化要求LLM代理将环境交互转化为可靠且可复用的经验。现有方法通常细化单个轨迹或从相关轨迹中抽象出共享知识，但它们的经验表示往往与底层推理过程脱节。这限制了反馈归因、跨任务迁移以及更新和检索效率，尤其是在具有结果级反馈的复杂推理任务中。为克服这一局限，我们提出了经验树（ToE），一个结构化的经验管理框架，将经验组织与LLM代理的分层推理过程对齐。具体来说，ToE将经验组织为一个共享的分析视角和推理路径树，通过环境结果校准其可靠性，以支持系统性更新、迁移和高效检索。在Game of 24和FinEvolveBench上的实验结果表明，ToE显著提升了问题解决性能和效率。在Game of 24上，与无经验ToT基线相比，ToE的准确率相对提高了31.4%。在FinEvolveBench上，在12个评估设置中，与无经验流水线相比，ToE的tsIC平均提高了41.24%，而传统的经验管理方法往往不如无经验基线。

## Abstract
Continual self-evolution requires LLM agents to transform environmental interactions into reliable and reusable experience. Existing methods typically refine individual trajectories or abstract shared knowledge from related trajectories, but their experience representations are often disconnected from the underlying reasoning process. This limits feedback attribution, cross-task transfer, and update and retrieval efficiency, particularly in complex reasoning tasks with outcome-level feedback. To overcome this limitation, we propose \textbf{T}ree-\textbf{o}f-\textbf{E}xperience (ToE), a structured experience-management framework that aligns experience organization with the hierarchical reasoning process of LLM agents. Specifically, ToE organizes the experience into a shared tree of analytical perspectives and reasoning paths, whose reliability is calibrated through environmental outcomes to support systematic updating, transfer, and efficient retrieval. The experimental results on \textsc{Game of 24} and \textsc{FinEvolveBench} show that ToE substantially improves both problem-solving performance and efficiency. On \textsc{Game of 24}, ToE achieves a 31.4\% relative improvement in accuracy over the experience-free ToT baseline. On \textsc{FinEvolveBench}, ToE improves tsIC by an average of 41.24\% over the experience-free pipeline across 12 evaluation settings, whereas conventional experience-management methods often underperform experience-free baselines.

### 1. 论文的核心问题与整体含义（研究动机和背景）

- **研究背景**：大语言模型（LLM）已从纯文本生成器发展为通用问题求解代理。一个真正通用的代理应当具备**持续自我进化**的能力——通过与环境的持续交互不断积累经验并自适应改进。然而，交互历史本身并不会自动变成经验，经验需要被结构化地组织、过滤和提取。
- **核心问题**：现有经验管理方法（如 Reflexion、MemRL、ReMe、FLEX 等）在经验表示上存在一个共同缺陷——**经验表示与底层推理过程相脱节**。它们要么对单条轨迹进行碎化总结（上下文依赖、迁移性差），要么从一组相似轨迹中归纳抽象知识（缺乏统一结构、反馈归因困难）。在包含结果级反馈（outcome-level feedback）的复杂推理任务中，这种脱节会导致：
  - 反馈归因困难：难以将环境结果归因到具体推理环节；
  - 跨任务迁移差：过度依赖表面相似性而非深层分析逻辑；
  - 更新与检索效率低：经验积累碎片化，无法系统校准。
- **整体含义**：论文提出并验证了一个关键论点——**经验管理应当与 LLM 的层次化推理结构对齐**，即以树状结构组织分析视角和推理路径，用环境结果校准每条路径的可靠性，从而让代理在低重复性、反馈延迟且模糊的复杂任务中也能有效自我进化。传统经验管理方法在复杂推理任务中甚至可能劣于无经验基线，这一发现也揭示了现有方法的结构性局限。

### 2. 论文提出的方法论：核心思想、关键技术细节、公式与算法流程

#### 核心思想：Tree-of-Experience（ToE）

ToE 将经验池组织为**深度受限、宽度可扩展的树**，树中的每个节点表示一个分析视角（analytical perspective），根节点表示问题类别或任务目标，父节点捕捉通用分析维度，子节点对父节点进行细化、扩展或具体化。一条从根到叶的路径代表一个完整的层次化推理过程，与环境反馈相关的可靠性值被存储在每个经验单元上，支撑系统的更新、迁移与高效检索。

经验池的形式化表示为：
```
E = { (Πi, Qi, Mi) } |E|, i=1
```
其中每个经验单元包含：深度为 L 的分析路径 Πi = (p(1)_i, ..., p(L)_i)、反馈导出的可靠性状态 Qi、维护元数据 Mi。

#### 关键技术细节

**（1）分析视角的粒度（Granularity）**

- 树的语义和粒度由问题结构、任务目标和求解所需信息共同决定，而非预定义模板。例如在 Game of 24 中，分析视角对应运算符选择或数字分组；在金融投资任务中则对应宏观经济环境、公司基本面、地缘政治因素等。
- 新节点的构建需满足三条规则：与父节点有清晰的语义包含关系、引入具有真正判别价值的信息、粒度保持均衡（不过宽也不过细）。
- 初始层级可通过两种方式构建：对推理流程明确的任务手工指定；或从模型生成的多条推理路径中递归聚类、抽象得到。

**（2）推理路径选择与生成**

- 经验检索与 LLM 推理同步进行。给定当前推理上下文 Hl = (xt, Πl−1)，ToE 通过 prompt 形式的 LLM 重排序器在现有树中检索与当前推理节点相关的候选节点，选出 top-k 个：
```
Cl = Retrieve(Hl, E) = TopK(f_rerank_θ(Hl, Children(p_{l−1})))
```
- 若没有合适候选项，则调用 LLM proposer 生成最多 k 个新分析视角：
```
Al = f_propose_θ(Hl, k) = {p_new,1, ..., p_new,|Al|}
```
- 新路径的可靠性初始化为中性先验 q0；已有路径则恢复其存储的可靠性。最终答案由 LLM 基于任务输入、选定的分析路径及其可靠性生成：`at = fθ(xt, Et)`。

**（3）经验树演化（更新与维护）**

- **反馈转换**：环境延迟反馈通过任务特定函数转为经验级更新信号：`rt = ψτ(at, o_{t+h})`。在 FinEvolveBench 中 rt = at·o_{t+h}，由预测与未来收益的信息系数（IC）驱动。
- **两种可靠性更新机制**：
  - **公式化更新（Formula-based）**：可靠性 Q 值域为 [0, 2q0]，随环境反馈动态调整，更新公式为：
    ```
    Q(Et) ← Q(Et) + η · [1 − ((Q(Et)−q0)/q0)²] / [1 + log(1 + n_hit)] · rt
    ```
    其中 η 是学习率，n_hit 为历史使用次数。该公式实现三种特性：随证据累积降低单次反馈的影响、在中性先验附近更新幅度大而在边界附近小（软遗忘）、失败经验不被硬删除而逐渐降低激活强度。
  - **LLM-based 更新**：由 prompt 化的 LLM 根据观察结果和每条经验的估计贡献分配更新幅度。消融实验显示公式化更新在 FinEvolveBench 上优于 LLM 直接更新。
- **维护机制**：包括控制新节点生成的数量和质量、通过 embedding 搜索和 LLM merger 合并语义重叠的节点，且不因可靠性低于阈值而剪枝（低可靠性经验可提供"负面证据"防止重蹈覆辙）。

#### 两种问题结构的适配

- **顺序依赖结构**（如 Game of 24）：推理分阶段进行，每个阶段（如 4 数状态、3 数状态、2 数状态）分别检索经验。
- **独立并行结构**（如 FinEvolveBench）：同时检索多条相关推理路径并整合到单次推理中。

### 6. 论文的主要结论与发现

1. **ToE 大幅提升推理性能与效率**：在 Game of 24 上，ToE 达到 85.3% 准确率，比无经验 ToT 基线（64.9%）高出 20.4 个百分点（相对提升 31.4%），同时将 LLM 调用数从 51.7 次降至 11.0 次（减少 78.7%）。

3. **ToE 在低重复任务中的优势更加显著**：在 FinEvolveBench 上，ToE 在 Exploitation 阶段平均提升 tsIC 59.57%，在 Overall 期间平均提升 22.92%，12 个设置的平均相对提升为 41.24%。且 Exploitation 阶段（经验树已收敛）增益大于 Overall 阶段，验证了经验积累的有效性。
4. **ToE 的收益跨骨干模型稳健**：在 DeepSeek-V4-Flash 下平均提升 48.61%，在 Qwen3.6-35B-A3B 下提升 33.88%，说明方法不依赖特定骨干模型。唯一例外是 Qwen 下 10 日 Overall 设置，ToE 略低于 Pipe。
5. **公式化可靠性更新优于 LLM 直接更新**：在 FinEvolveBench 20 日地平线上，公式化更新（tsIC 0.0741）显著超过 LLM-based 更新（tsIC 0.0598），说明将隐式市场反馈转化为结构化数值更新比依赖 LLM 主观判断更稳定有效。
6. **ToE 在更长预测地平线上增益更大**：20 日和 40 日地线上提升显著大于 10 日，说明当新闻包含更多信息性信号时，ToE 更善于识别、积累和利用可迁移的预测模式。

  - **灵活性**：同一框架可适配顺序依赖的和独立并行的推理结构，可通过手工指定或自动归纳两种方式构建初始层级。
