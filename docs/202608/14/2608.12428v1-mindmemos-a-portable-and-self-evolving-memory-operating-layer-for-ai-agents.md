## 摘要
记忆是AI智能体的核心组成部分，使其能够积累经验、保持个性化，并在长期交互中不断适应。然而，现有的记忆系统在开发后往往保持固定，限制了其通过持续使用来调整记忆模型、组织策略和程序性知识的能力。我们提出了MindMemOS，一个便携且自进化的记忆操作系统层，它使用统一的实体-属性-时间结构来组织开放世界信息。MindMemOS支持场景自适应记忆建模、高阶模式发现、自主记忆精炼和持续技能进化。其MindMemEvolve算法采用验证驱动的进化搜索来优化目标场景的记忆模式，而dreaming通过合并冗余记录和解决冲突来巩固累积的记忆。此外，隐式纠正反馈作为人在回路中的信号，用于识别和修正潜在不准确或不对齐的记忆。其MindSkillEvolve算法进一步将智能体的执行轨迹转化为可重用且逐步精炼的技能。MindMemOS在LOCOMO上达到94.03%的准确率，在PersonaMem上达到70.63%。MindSkillEvolve在SpreadsheetBench上比初始技能基线提升了9.2个百分点的成功率。

## Abstract
Memory is a core component of AI agents, enabling them to accumulate experience, maintain personalization, and adapt over long-term interactions. However, existing memory systems often remain fixed after development, limiting their ability to adapt their memory models, organization strategies, and procedural knowledge through continued use. We present MindMemOS, a portable and self-evolving memory operating layer that organizes open-world information using a unified entity property timestructure. MindMemOS supports scenario-adaptive memory modeling, higher-order pattern discovery, autonomous memory refinement, and continuous skill evolution. Its MindMemEvolve algorithm employs validation-driven evolutionary search to optimize memory schemas for target scenarios, whiledreaming consolidates accumulated memories by merging redundant records and resolving conflicts. In addition, implicit corrective feedback serves as a human-in-the-loop signal for identifying and revising potentially inaccurate or misaligned memories. Its MindSkillEvolve algorithm further transforms agent execution trajectories into reusable and progressively refined skills. MindMemOS achieves 94.03% accuracy on LOCOMO and 70.63% on PersonaMem. MindSkillEvolve improves SpreadsheetBench success by 9.2 percentage points over the initial-skill baseline.

  3. **内容与技能割裂**：记忆内容和程序性技能往往分开管理，难以将执行经验转化为可复用且逐步精炼的智能体能力。

## 2. 方法论

### 2.1 核心思想
- 采用**统一实体-属性-时间（entity-property-time）三维记忆结构**组织开放世界信息，支持两种记忆生成策略（MindVanilla 和 MindSchema），配合紧凑图检索、离线巩固（dreaming）、反馈修正和技能进化，实现记忆系统在部署后的自我演化。

### 2.2 关键技术细节

- **三维记忆结构**：
  - **实体维度**：记忆锚定到人、组织、地点、事件等实体，实体间有语义关系边。
  - **属性维度**：描述实体的具体方面（偏好、活动、关系等），属性集合可随场景自适应调整，既支持显式事实，也支持跨观察合成的高阶模式。
  - **时间维度**：每条记忆记录带时间戳，同实体-属性对的记录构成时间线，支持更新和冲突版本共存而不覆盖历史。

- **MindVanilla**：无需预定义 schema，按对话轮次分块，结合内容哈希、实体重叠和 BM25 召回候选，通过 LLM 抽取扁平记忆记录并做去重和动作规划（Add/Reinforce/Update/Merge/Skip）。

- **MindSchema**：基于 schema 的生成流程，包含**情节切分**（LLM 分段器）、**记忆生成**（映射实体/属性、时间表达式解析）、**实体融合**（合并等价实体、更新属性值、合成高阶属性）、**图合并**（将子图并入全局记忆图）。

- **紧凑搜索**：
  - 外层 LLM 控制器做检索规划（判断时间范围、记忆类型、查询公式），内层工具层执行稀疏（BM25）与稠密（embedding）混合检索，经 RRF 融合。
  - 支持前向遍历（实体→属性）和后向遍历（属性→实体），可扩展时间前后版本和关系邻域；检索键可分解为多个字段来提升细粒度实体匹配。

- **Dreaming（离线巩固）**：
  - 以未巩固记录为种子，构建实体中心聚类；两阶段 detect-then-act：第一阶段识别冲突、重复、互补碎片、低价值内容等；第二阶段生成保守变更计划（新建、更新、合并、归档、加关系边），并通过标准写接口执行，保留溯源。实验显示可将约 20% 的活跃记忆归档而不损害检索质量。

- **反馈机制**：
  - **显式反馈**：用户直接给出自然语言修正，系统结合对话上下文和候选记忆生成 add/update/delete/no-op 动作。
  - **隐式反馈**：从用户对智能体输出的纠正中自动识别信号，按持久性分类（任务临时、场景特定、长期），只将合适的信息转化为记忆更新，避免将一次性指令过度泛化。

- **MindMemEvolve（记忆 schema 自进化）**：
  - 优化目标为最大化验证集上的 Judge 分数（公式 1），即对每个 QA 对，用候选 schema S 写入上下文、检索记忆、生成答案、与参考答案比对。
  - 采用 LLM 引导的进化算法（Algorithm 1）：初始化种群 → 每个 epoch 在每个 cluster 上做适应度评估 → 精英保留 + 锦标赛选择 → **诱导变异**（基于错误信息的定向修复）、**随机变异**（注入新实体/属性类型、剪枝低频项）→ **交叉** → 最终在训练集上选最优个体。

- **MindSkillEvolve（技能进化）**：
  - 通过 SDK 钩子将智能体执行轨迹绑定到具体技能版本，云边协同管理技能版本链。
  - 轨迹先转为证据驱动的分析，批量聚合后由 LLM 生成技能改进计划并转化为编辑操作。
  - 两种变体：**Unsup**（仅用轨迹分析）、**Sup**（额外用任务分数强化高得分轨迹模式、抑制低分错误模式）。

## 6. 主要结论与发现

- **主实验性能**：
  - LOCOMO：MindSchema 整体准确率 94.03%，优于 EverOS（93.05）和 Zep（85.22）；Open-domain 上以 82.29% 大幅领先；MindVanilla 也能达 87.60%，超过 MemOS 和 Zep。
  - PersonaMem：MindSchema 整体 70.63%，较 EverOS（67.57）提升 3.06 个百分点，主要来自 Recall Sha.（81.40 vs 74.42）和 Suggest.（47.31 vs 35.48）。
- **Dreaming 效果**：在 gpt-4o-mini 上将 overall 从 0.377 提升到 0.459；gpt-5-mini 下从 0.545 提升到 0.585，并超过 Infini Memory；同时压缩约 20% 的活跃记忆（AMCR 22.5%），说明巩固可去冗余而不损检索质量。
- **技能进化**：MindSkillEvolve-Unsup 将 SpreadsheetBench 成功率从 51.3% 提升到 55.3%；MindSkillEvolve-Sup 进一步提升到 57.2%，比初始技能基线（Init-skill 48.0%）高 9.2 个百分点。有趣的是，不演化的初始技能比无技能还差（48.0 vs 51.3），印证了未优化技能可能引入误导性约束。
- **MindMemEvolve 进化案例**：将 bootstrap 的 2 个动态属性扩至 49 个，自动区分一阶（单事件事实）和高阶（跨事件综合模式），测试集准确率从 61.07% 提升到 64.63%。
- **Dreaming 案例**：可正确解决“Nobuhiro Watsuki 以什么出名”的冲突——根据时间顺序保留最新事实《The Fairly OddParents》，将旧记忆《Rurouni Kenshin》归档，并通过 supersedes 边记录替代关系。
- **反馈案例**：通过隐式反馈将用户偏好（偏爱一对一、低压、易退出的社交）固化为记忆，使 PersonaMem 题目答案从错误选项 B 转为正确选项 A。

## 7. 优点

- **统一且可进化的记忆表示**：实体-属性-时间三维结构兼具开放域通用性和场景可定制性，同一系统支撑无 schema 和有 schema 两种生成路径，接口不变。
- **面向部署后的持续进化**：不止于在线读写，而是通过 MindMemEvolve 优化 schema、Dreaming 离线巩固、Feedback 利用纠正信号、MindSkillEvolve 将轨迹转为版本化技能，形成完整的记忆生命周期闭环。
- **可追溯、保守的记忆维护**：所有变更保留溯源，对不确定情况采用非破坏性更新，降低错误归档风险；Dreaming 的“实体中心范围构建”避免全局对比，计算代价可控。
- **技能进化与记忆解耦**：Skill 版本链支持云边同步、回滚，且轨迹绑定到具体技能版本，能适应不同 agent harness 的调用方式，实用性较强。
- **实验覆盖多维度**：同时评估了对话记忆、个性化、冲突巩固、任务技能进化，并辅以详细案例研究和完整技能/模式代码（附录），透明性好。
- **公平性细节到位**：Dreaming 评测移除时间戳以避免模型直接读时间戳；Skill 实验使用真实验证集和重复运行报告均值±标准差。

- **基线复现不完全**：部分基线结果引自其他论文，未全部本地复现，可能引入设置差异；对“配置完全对齐”的声明缺乏可验证的细节。
- **部分类别数据量过少**：如 PersonaMem 的 Recall Mem. 只有 17 题，类别准确率波动很大，结论稳定性有限。
- **MindMemEvolve 增益有限且验证单一**：仅在 PersonaMem 上测试，且改进幅度小，作者也承认该基准对推理依赖强、对模式演进不够敏感；没有在更多元场景（如工具调用、知识密集型任务）中验证。
- **缺少系统性消融**：未单独量化 MindVanilla vs MindSchema 的差距来源、Dreaming 各步骤贡献、反馈的独立收益（案例仅说明单点效果），也未分析组件间的交互影响。
- **统计显著性不足**：除 Skill 实验外，主实验未报告多次运行的方差或显著性检验，可能受模型随机性影响。
- **应用限制**：Dreaming 和反馈依赖 LLM 调用，成本较高；隐式反馈的持久性分类依赖模型判断，存在误分类风险；技能进化基于轨迹分析，对轨迹质量要求高，且无监督变体可能学到局部失败的过度泛化规则（论文中提到需要监督信号来约束边界）。
- **未来工作未实现**：文件系统级记忆、体验-技能更深度融合仍属规划，当前对文件和文档的支持较弱。
