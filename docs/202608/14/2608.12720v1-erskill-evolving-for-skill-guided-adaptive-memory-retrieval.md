## 摘要
虽然大型语言模型（LLM）智能体越来越依赖长期记忆进行持久交互，但管理这些记忆的检索机制却很少被视为可进化的组件。这种静态方法限制了在异构记忆查询上的性能，这类查询通常需要多样化的证据构建策略。为了解决这个问题，我们提出了ERSkill，一个以检索为中心的自进化、技能引导的内存访问框架。ERSkill将交互历史编译成结构化的记忆存储，并将检索行为表示为由基本原语组成的可执行技能。在推理时，训练好的路由器动态地将每个查询匹配到最优技能，以构建量身定制的证据用于答案生成。为了实现持续改进，ERSkill在训练过程中协同进化技能集和路由器。它采用经验字典树高效记录探索过的检索路径，并利用双前沿机制将新技能能力的扩展与稳定的、面向路由器的部署安全解耦。在多个智能体记忆基准上的实验表明，ERSkill显著优于强大的非进化和自进化基线。值得注意的是，在使用Qwen3-Next-80B-A3B-Instruct时，它在F1、BLEU-1和LLM-judge分数上的整体平均值提高了31.3%，在使用GPT-5.4-nano时提高了28.1%。

## Abstract
While Large Language Model (LLM) agents increasingly rely on long-term memory for persistent interactions, the retrieval mechanisms governing this memory are rarely treated as evolvable components. This static approach limits performance on heterogeneous memory queries, which often demand diverse evidence construction strategies. To address this, we introduce \textbf{ERSkill}, a retrieval-centric framework for self-evolving, skill-guided memory access. ERSkill compiles interaction histories into a structured memory store and represents retrieval behaviors as executable skills composed of fundamental primitives. At inference time, a trained router dynamically matches each query to the optimal skill to construct tailored evidence for answer generation. To enable continuous improvement, ERSkill co-evolves the skill set and the router during training. It employs an experience trie to efficiently record explored retrieval paths, alongside a double-frontier mechanism that safely decouples the expansion of new skill capabilities from stable, router-facing deployment. Experiments across multiple agent memory benchmarks demonstrate that ERSkill substantially outperforms strong non-evolving and self-evolving baselines. Notably, it improves the overall average across F1, BLEU-1, and LLM-judge scores by 31.3\% with Qwen3-Next-80B-A3B-Instruct and by 28.1\% with GPT-5.4-nano.

## 2. 方法论：ERSkill 框架

### 2.1 核心思想

将记忆访问建模为**技能引导的证据构建**过程：记忆存储是"可执行的基板"，检索行为被表达为一系列由基础原语组合而成的可执行技能；推理时由训练好的路由器动态匹配查询与技能，由技能控制证据的收集、扩展与组织，最终支撑答案生成。

### 2.2 结构化记忆存储

- 将交互历史 D 编译为原子级记忆记录集合 A，并构建记忆存储 M(D) = (A, I, G)：
  - **A**：原子记忆记录，每条包含原子文本、时间戳、实体集合；
  - **I**：索引集合，为检索提供入口（嵌入索引、实体-原子索引等）；
  - **G**：图集合，用于证据扩展（相似度图、关系图，其中关系图包含规则式时间邻接边与 LLM 抽取的语义关系边，关系类型包括 Changed、Cause、Reason、HinderedBy、React、Want 等）。

### 2.3 检索原语库（固定不变）

- **搜索原语**：
  - `entity_search`：基于实体锚点检索；
  - `lexical_search`：BM25 风格字面匹配；
  - `dense_search`：基于语义嵌入相似度检索。
- **扩展原语**：
  - `temporal_focus_expand`：按时间跨度扩展；
  - `similarity_expand`：沿相似度边扩展；
  - `relation_expand`：沿类型化关系边扩展。
- **处理原语**：
  - `llm_process`：查询改写、证据过滤、状态归一化等动态控制操作。

### 2.4 检索技能与路由器

- **技能定义**：技能 κ = (c_κ, ρ_κ)，其中 c_κ 为技能描述与信息偏好，ρ_κ = (p_κ,1, …, p_κ,L) 为原语序列。技能以 Markdown 文件存储，可执行、可解释、可复用、可改进。
- **技能路由器**：使用共享编码器 Enc(·) 对查询和技能编码，通过可学习打分函数 u_θ(q, κ) 度量兼容性，并归一化为技能分布：
  - R_θ(κ|q, K) = exp(u_θ(q, κ)) / Σ_{κ'∈K} exp(u_θ(q, κ'))
  - 文本编码器保持冻结，仅优化路由参数；新进化的技能可从文本描述直接评分，无需改变输出空间。
- **推理流程**：查询 q → 路由器选技能 κ̂ = arg max R_θ → 执行技能得到证据状态 s_L → 生成答案 ŷ = f_LLM(q, s_L)。

### 2.5 技能-路由器协同进化（核心创新）

采用两个 Pareto 式前沿实现安全的持续进化：

- **能力前沿 C_t**：保留具有 oracle 侧价值的技能（即每个查询选择最佳技能时的最优可达效用），追踪已发现的检索能力边界。
- **部署前沿 B_t**：面向路由器的技能集合，只包含经验证、路由器能可靠选择的技能，用于实际推理。

**四个关键组件**：

1. **技能候选生成**：通过编辑能力前沿中的既有路径（增删/替换原语）生成新技能候选；LLM 驱动多阶段流程（analyzer → designer → generator）完成案例诊断、进化决策与技能物化。
2. **经验字典树 T**：记录探索过的原语路径、回滚结果与前缀共享，避免重复提出等价检索程序；被接受和被拒绝的候选均被保留以指导后续进化。
3. **能力前沿更新**：先训练批计算临时前沿，再在验证集上基于前沿重算算子 Φ 更新；Φ 保证不降低任何查询的最佳分数（oracle 性能无损）。
4. **路由器更新**：基于历史回滚实例构成的训练窗口，以回滚分数导出的软目标分布进行软标签交叉熵训练：
   - L_router = − Σ_{(q,K_q,·)∈M} Σ_{κ∈K_q} p̃(κ|q,K_q) log R_θ(κ|q,K_q)
5. **部署前沿更新**：仅当能力前沿变化时才考虑刷新；计算候选部署前沿的路由性能增量 Δ_route，满足路由增益阈值 γ_route 或满足"性能小降 + 集合更紧凑"（紧凑度容忍 ξ_drop）条件时接受，否则保持原部署前沿。

**命题 2.1（Oracle 安全的两级前沿更新）**：每一步进化都保证验证集上的 oracle 覆盖率 OCov(K;Q) = (1/|Q|)Σ_q max_{κ∈K} r(q,κ) 对能力前沿和部署前沿均非递减，且已给出形式化证明。

## 5. 主要结论与发现

1. **显著增益**：ERSkill 在两个骨干模型下均取得最佳综合表现，整体平均（F1/BLEU-1/L-J）相对最强基线提升 31.3%（Qwen3-Next-80B-A3B-Instruct）和 28.1%（GPT-5.4-nano）。
2. **证据密集任务优势更明显**：在需要精确定位证据点的 Single Hop 与 Multi Hop 类别上，ERSkill 增益最大，说明自适应检索行为能有效提升证据搜索能力。
3. **跨数据集迁移有效**：直接在 LongMemEval 上复用 LoCoMo 训练成果仍为最佳，证明学到的检索技能捕捉了可迁移的检索行为模式。
4. **成本表现领先**：在 LLM 构建型记忆中 token 消耗最轻（仅在记忆原子间做关系抽取）；推理成本处于低位的同时取得最高 L-J 分数，说明增益来自精准证据构建而非喂入更多检索内容。
5. **组件设计均有效**：消融中损失最大的是移除技能进化与路由器，证明"发现有效技能"与"学习查询-技能匹配"二者缺一不可；双前沿稳定技能接收，经验字典树减少重复探索。
6. **进化稳定**：5 次独立运行的变异系数低于 5.4%，进化过程鲁棒。

## 6. 主要优点

1. **问题定位精准且新颖**：将检索行为（而非仅内容或推理）作为自进化的对象，填补了现有智能体记忆研究的关键空白。
2. **框架设计精巧**：技能抽象（原语组合）使检索行为可执行、可解释、可复用；双前沿机制在能力扩张与部署稳定间取得优雅平衡；经验字典树以数据结构视角解决探索效率问题。
3. **理论保证**：命题 2.1 以形式化证明支撑前沿更新的 oracle 安全性，增强了方法的可信度。
