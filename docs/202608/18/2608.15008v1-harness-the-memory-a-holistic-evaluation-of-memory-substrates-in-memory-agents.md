## 摘要
记忆正在成为长视野LLM智能体的核心基础设施，然而现有评估对在不同运行机制下应使用哪种记忆基质，即记忆表示和存储的底层介质，提供的指导有限。我们针对记忆增强型智能体的记忆基质提出了一种受控的测试平台评估，涵盖了密集和稀疏索引、文本记录、结构化存储、分层存储、基于精炼的记忆、参数更新以及兼容激活的上下文机制。在三种主干模型和四个涵盖以用户为中心的事实型问答和以智能体为中心的决策制定的基准套件中，我们在统一测试平台下测量了26项性能和效率指标。我们的结果表明，没有单一基质能持续占据主导地位：广泛检索有利于长上下文事实型问答，而过度的检索可能通过将注意力从动作关键上下文转移而损害顺序决策制定。可扩展性引入了另一个路由轴，因为在中等历史长度下表现良好的基质在更长视野下可能变得代价高昂或脆弱。这些发现促使基质路由成为自适应智能体记忆系统的必要组件，并为设计高效、可靠且机制感知的LLM智能体长期记忆提供了实证指导。代码将在录用后提供。

## Abstract
Memory is becoming core infrastructure for long-horizon LLM agents, yet existing evaluations offer limited guidance on which memory substrate, namely the underlying medium in which memory is represented and stored, should be used under different operating regimes. We present a controlled harness evaluation of memory substrates for memory-augmented agents, covering dense and sparse indices, text records, structural stores, hierarchical stores, refinement-based memories, parametric updates, and activation-compatible context mechanisms. Across three backbone models and four benchmark suites spanning user-centric question answering and agent-centric decision-making, we instrument 26 performance and efficiency metrics under a unified harness. Our results show that no single substrate consistently dominates: broad retrieval benefits long-context factual QA, while excessive retrieval can harm sequential decision-making by shifting attention away from action-critical context. Scalability introduces a further routing axis, as substrates that perform well at moderate history lengths can become costly or brittle at longer horizons. These findings motivate substrate routing as a necessary component of adaptive agent memory systems and provide empirical guidance for designing efficient, reliable, and regime-aware long-term memory for LLM agents. ## 一、核心问题与研究动机

- **背景**：LLM 智能体正从单轮助手演进为需要持久记忆的长视野系统（编码助手、Web 智能体、个性化陪伴、科学发现智能体等），它们共同面临"写入新经验、决策时读取相关知识、在有限算力与存储预算下管理不断增长的记忆"这一挑战。
- **核心问题**：现有评估对"在何种运行机制（operating regime）下应选用哪种记忆基质（memory substrate）"缺乏指导。记忆基质是记忆智能体脚手架（harness）的基础设施层，其设计约束了写入成本、读取延迟、可检查性以及随历史增长的系统退化方式。
- **现有评估的三大缺陷**（作者对 52 个记忆增强 LLM 系统（2023–2026）的 landscape 分析）：
  1. **基准集中**：62% 的基准-系统配对集中在 LoCoMo 和 LongMemEval 两个对话数据集上，agentic 任务几乎未被考察。
  2. **指标与骨干模型覆盖窄**：所有系统都报准确率，但仅 21% 报告任何效率指标；81% 的系统仅使用 GPT 系列骨干模型，无法将基质效应与模型特定行为分离。

## 二、方法论

### 核心思想
- 将**记忆基质作为唯一实验变量**，在统一 harness（保持骨干模型、提示模板、辅助 LLM 设置固定）下进行受控对比评估，回答两个问题：(1) 智能体行为（任务性能与效率）中有多少可归因于基质本身；(2) 这种归因是否跨运行机制稳定。

### 记忆基质分类（11 种方法 × 7 个家族）
基于外部记忆（信息存储在模型外的数据结构中）与内部记忆（信息编码在模型权重或激活中）的分类法：

**外部记忆（8 种方法）**：
- **扁平索引（Flat Index）**：M1 稠密向量（1536 维 text-embedding-3-small，余弦相似度 top-k）；M2 稀疏向量（BM25）。两者写入/读取均不调用 LLM。
- **文本记录（Text Record）**：M3 Gist Index（实现 ReadAgent）——写入时用辅助 LLM 为每页生成一句话要点；读取时 LLM 阅读全部要点并选择展开哪些页面。
- **结构化（Structural）**：M4 Evolving Notes（实现 A-Mem）——写入时 LLM 生成结构化笔记并建立语义链接，进化触发器触发邻居重写；M5 Dual-Level Graph（实现 LightRAG）——构建实体-关系知识图谱 + 块级向量索引的混合检索。
- **层级（Hierarchical）**：M6 Hierarchical Tree（实现 RAPTOR）——递归聚类与摘要形成多层树，通过折叠树稠密搜索检索。
- **精炼（Refinement）**：M7 Distilled Strategies（实现 ReasoningBank）——LLM 判断轨迹成败并提炼可复用策略；M8 Skill Bundles（实现 MemSkill，但将 PPO 控制器替换为零样本 LLM）——将经验聚类为技能包。

**内部记忆（3 种方法）**：
- **权重（Weight）**：M9 Adapter Tuning（LoRA-FA，r=8）——辅助 LLM 合成 QA 对，微调 LoRA 适配器，无显式检索。
- **激活（Activation）**：M10 Full Context——全历史拼接基线，超出窗口则截断最旧条目；M11 Episode-Clustered Re-prefill（实现 EpiCache，但将原位 KV 编辑改为话语级重新预填充）——将对话轮次聚类为情景组，保留 25% token 预算，读取时匹配情景质心并重新预填充。

### 关键指标（26 项）
- **性能（12 项）**：精确匹配（EM）、Token F1、BLEU-1、LLM 评判（P4，GPT-4o-mini 按基准特定模板打分）、压缩比、Recall@k、任务成功率（TSR）、目标条件成功率、到达目标步数、Pass@1、子串精确匹配（SubEM）等。
- **效率（15 项）**：内存大小、推理时间、写入延迟、检索延迟、写入 token/调用数、检索 token/调用数、管理 token/调用数、总 token/调用数、总墙钟时间、每查询延迟（E15）等。

## 六、主要结论与发现

1. **无单一基质全面占优**：最优基质随机制反转——结构化图（M5）在对话 QA 上领先但智能体任务上被 Pareto 支配；精炼记忆（M7）在具身规划上领先但在 QA 上落后。跨骨干模型均观察到"最佳基质随能力变化"的模式。
2. **检索广度在不同机制下方向相反**：
   - LoCoMo 上 P4 随 k 单调上升（检索到更多证据提高答案命中率，多余上下文可被动忽略）；
   - ALFWorld 上任务成功率随 k 下降（过度检索的智能体不只是失败，而是"游荡"——步数攀升至上限）。
   - **注意力机制解释**：两种任务上注意力均从 Context 流向 Retrieved（机制相同），差异在于答案负载区域——QA 的答案在检索内容中，所以注意力转移是期望行为；ALFWorld 的负载区域是当前观察和合法动作列表，所以同一转移饿死了决策。
3. **可扩展性构成第三路由轴**：精炼家族（M7、M8）质量随历史增长而提升且延迟增长温和（固定大小技能包，读取成本与输入长度无关）；结构化家族（M4、M5）在 262K token 时因图重建和实体抽取随输入规模增长而付出高昂延迟代价；M10 质量随上下文增长但读取成本线性上升；M9 无选择性时间更新机制，在冲突消解上表现平平。
4. **性能-延迟的 Pareto 前沿跨机制不相交**：QA 前沿由结构化和层级记忆占据（M5 以 10–30× 延迟换取最高 P4）；智能体前沿由扁平检索（M2 在 BCB）和精炼蒸馏（M7 在 ALFWorld）占据。两个前沿无共享基质。
5. **设计规则**：**"用读取广度换写入深度"**（每条查询检索更少条目，在写入时投入更多精力蒸馏和结构化记忆）；通用记忆必须实现为多基质或多智能体系统，按角色组合（精炼基质策展抽象、结构与文本基质持有事实、激活与扁平基质保留原始经验），按机制路由。

## 七、方法或实验设计的亮点

1. **首次对智能体记忆做整体式受控 harness 评估**：将记忆基质隔离为唯一实验变量，这是在现有文献中缺失的关键实验范式。
2. **26 项指标的双族体系**（性能 + 效率），首次使写入/读取/管理三阶段的延迟、token、调用数、内存占用等部署关键成本对记忆基质研究可见，打破了此前"只用准确率评价记忆"的惯例。
3. **跨机制对偶基准设计**：LoCoMo/LME-S/MAB（用户中心记忆回忆）对 ALFWorld/BCB（智能体中心决策），且两个 agentic 基准经语义对齐验证（真实 bank 与随机 null 相差一个数量级），确保检索有信号可用。
4. **三骨干模型交叉验证**（含量化模型和 MoE 模型），能分离基质效应与模型特定行为；不像此前 81% 的研究只用 GPT 家族。
5. **消融 + 机制诊断结合**：检索广度扫描叠加注意力探针，从注意力分配层面解释"为什么检索广度在不同机制下方向相反"，提供了可操作的记忆设计启示。
6. **诚实的成本披露**：报告生产级系统（MemGPT/Mem0/Zep）的辅助 LLM 成本并解释排除理由；明确声明实现偏差及其动机。

2. **统计严谨性不足**：主表仅报告点估计，无置信区间或显著性检验。作者虽辩称样本量大（LoCoMo 1,986 问、BCB 148 任务等）使得 ≥0.05 的差距不太可能因随机性翻转，但检索广度扫描等子实验中部分配置的样本量较小（如 ALFWorld 每配置 134 任务按 k 分档后），波动风险未被量化。

3. **实现偏差影响可比性**：M8（MemSkill）将原始 PPO 控制器替换为零样本 LLM，M11（EpiCache）将 KV 编辑改为话语级重新预填充——两者都偏离原始方法的设计，作者虽声明动机（降低实现复杂度、避免依赖特定推理引擎），但结果反映的是"近似版本"而非"原始方法"的能力，与文献中报告的原始性能不可直接对照。

4. **部分配置缺失导致结论不完整**：M9 与 Gemma-4 的 MoE 路由不兼容、M10 因上下文溢出从两个智能体基准中省略，造成设计矩阵中的系统性空洞。这意味着"内部记忆（权重、全上下文）在智能体任务上的表现"这一问题的答案仍不完整。

5. **辅助 LLM 单点化引入潜在偏向**：所有基质的写入/管理/评判统一使用 GPT-4o-mini。若某种基质的设计依赖更强的辅助模型（如更复杂的图构建、策略蒸馏），低能力辅助 LLM 可能系统性压低其表现；反之，依赖较少辅助调用的方法（如 M1/M2 纯检索）则不受此限制。

6. **基准覆盖仍有盲区**：
   - LoCoMo 仅 10 个多会话对话，规模偏小且类别分布可能不足以支撑细粒度结论；
   - 四个基准均为合成或受限环境，缺乏真实世界的长时在线部署场景（如真实用户数周交互、生产环境代码仓库）；ALFWorld 的会话间机制依赖预构建 bank，与真实系统"边运行边积累"的动态写入过程仍有差距；
   - 没有覆盖需要多模态记忆或跨会话复杂推理（如规划、反事实推理）的基准。

7. **骨干模型代表性受限**：测试的三个模型均为开源模型（且 Qwen3-32B 为 AWQ 量化版、Gemma-4 为 26B 激活 4B 的 MoE），未包含研究界和工业界最常用的闭源前沿模型（GPT-4o、Claude 等）。作者承认基质效应可能与骨干模型能力交互，但该交互在最强模型上是否成立仍属未知。

8. **时间尺度有限**：所有实验局限于单一评估会话或预构建的记忆 bank，未真正考察数天至数周的持续写入、遗忘与记忆整合的动态过程（如 Evolving Notes 的进化触发器在极长历史上的行为）——而这正是"持久记忆"概念的核心诉求。

9. **LLM 评判（P4）引入循环依赖**：用 GPT-4o-mini 既做辅助 LLM 又做评判器，若某个基质的输出风格恰好更迎合评判模板（如结构化摘要与模板措辞更匹配），可能产生系统性偏差；论文未报告评判器与人类判断的一致性校验。

10. **效率指标的口径统一性**：部分效率指标（如压缩比、管理 token）在不同基质间的定义存在细微差异（结构化基质的管理成本被计入写入阶段、激活基质的管理成本被计入读取阶段），横向比较时需谨慎解读。

## 九、总体评价

**贡献层面**，这是迄今对 LLM 智能体记忆基质最系统、最严谨的一次受控对比研究：它首次将"记忆基质"从"模型 + 提示 + 记忆系统"的混杂评估中剥离出来，确立了统一的实验范式（固定 harness、多骨干、多机制、双族指标），并以注意力探针和数据驱动的 Pareto 分析给出了可操作的工程结论（读取广度换写入深度、按机制路由多基质）。其"如何在预算约束下选择记忆基质"的提问方式，直接回应了部署级系统的真实需求。

**局限层面**，论文的结论强度受到统计严谨性（无置信区间）、实现偏差（两处方法替换）、模型覆盖（无闭源前沿模型）和时间尺度（无非单会话长时实验）的制约。此外，生产级系统（MemGPT/Mem0/Zep）的缺失意味着最贴近实际部署的一类架构未进入主排名。

**适用性判断**：其设计规则（如"检索广度反向效应"、"Pareto 前沿不共享"）对开源骨干（Qwen/Gemma 系列）和中等规模预算的部署场景具有较强指导意义；但在引入更强大的闭源骨干、不同辅助 LLM 或多模态记忆时，具体排名可能变化，需按论文提供的框架重新校准。总体而言，论文的价值不在于给出"最优记忆系统"的终极答案，而在于提供一个可复用的实验基座和一套维度分析语言，推动记忆增强智能体从"点状 benchmark 竞赛"走向"机制可解释的工程科学"。
