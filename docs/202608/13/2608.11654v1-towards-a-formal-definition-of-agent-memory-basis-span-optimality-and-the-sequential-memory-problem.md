## 摘要
尽管记忆在大模型智能体中广泛部署，但关于记忆是什么或何时最优，尚无统一的形式化描述。本文朝这一描述迈出了第一步。核心思想是：记忆是一种基，知识是其张成，可回答性是一个覆盖问题——智能体从材料中提取事件；一个生成算子将任何事件集合转换为其所蕴含的知识；当且仅当张成中的某个单项覆盖该查询时，该查询是可回答的。于是，最优记忆便是容量约束下期望覆盖的最大化，其价值描绘出一条效用-容量前沿，这是比较记忆系统的共同标尺。接下来，我们考虑记忆中的噪声，并讨论噪声下的覆盖与精确度：记忆可能存储虚假陈述，因此写入策略必须推断其所存储内容的真实性。借鉴生物记忆的类比——生物记忆是通过持续体验连续形成的——我们在一个覆盖多个层次的顺序MDP中形式化连续智能体记忆问题，其中记忆是状态，写入是动作，查询时结算的效用是驱动学习的延迟奖励。为使框架具体化，我们将其实例化于荷马的《奥德赛》，将前沿、压缩区以及覆盖与精确度的分歧转化为具体数字。最后，我们将现有系统置于该框架中，使“记忆有多好”可度量，并将构建和学习智能体记忆的开放问题重新表述为具体的研究问题。

## Abstract
Despite the wide deployment of memory in large-model agents, there is no unified formal account of what a memory is or when it is optimal. This paper takes a first step toward this account. The central idea is that memory is a basis, knowledge is its span, and answerability is a coverage problem: an agent stores events extracted from a material; a generation operator turns any event set into the knowledge it entails; and a query is answerable exactly when some single item in the span covers it. The optimal memory is then the capacity-constrained maximizer of expected coverage, and its value traces a utility--capacity frontier, the common yardstick on which memory systems can be compared. Next, we consider noise in the memory and discuss coverage versus precision under it: a memory may store false claims, so the write policy must infer the truth of what it stores. Drawing an analogy with biological memory, which is formed continuously through ongoing experience, we formalize the continual agent-memory problem in a sequential MDP that covers multiple levels, where memory is the state, writing is the action, and the utility settled at query time is the delayed reward that drives learning. To make the framework concrete, we instantiate it on Homer's \emph{Odyssey}, turning the frontier, the compression zone, and the divergence of coverage from precision into concrete numbers. Finally, we position existing systems within the framework, making ``how good is a memory'' measurable and recasting the open problems of constructing and learning agent memory as concrete research questions.

## 2. 方法论

### 核心思想：记忆是基，知识是张成，可回答性是覆盖问题

- **事件、知识与生成算子**：
  - 事件（event）：关于材料的原子陈述，如“供应商三月提价”。
  - 知识（knowledge）：一组事件所蕴含的原子、自包含信息单元。
  - 生成算子 Φ：将任意事件集合映射到其生成的知识集合，即 Φ(A) ⊆ N。
- **记忆定义**：记忆 M_D 是材料 D 所包含事件集合 E_D 的子集；被存储的事件构成“基”，其生成的知识 R_MD = Φ(M_D) 称为“张成”。
- **单条目支持假设**：每个查询均由单个知识条目回答，回答时不进行组合推理；组合被推入生成算子 Φ 内部。这使可回答性成为纯覆盖问题。
- **覆盖效用**：对查询 q，记忆的覆盖效用为 1 当且仅当该查询被记忆张成中某个知识条目覆盖；期望效用即随机查询的可回答概率。

### 最优记忆与效用–容量前沿

- **容量约束最优记忆**：给定容量上界 S，最优记忆是使期望覆盖效用最大化的、不超过 S 个事件的子集。
- **效用–容量前沿**：最优记忆所达到的期望效用随 S 变化的曲线，即 U*_D(S)。前沿在 S ≥ |E_D| 时饱和于“全上下文基线”，即存储全部材料可达到的效用；S 小于材料规模时是“压缩区”，压缩代价为前沿与基线之间的垂直差距。
- **复杂度结果**：
  - 若 Φ 可分解（即 Φ(M_D) = ∪_{e∈M_D} Φ({e})），最优记忆问题等价于加权最大覆盖问题，NP-hard，贪心算法提供 (1−1/e) 近似。
  - 一般情况下，目标是单调集函数但未必子模；跨事件协同可能使边际收益递增，贪心近似保证不成立。

### 噪声记忆：覆盖与精度

- 引入候选事件“声明”（claim），每个声明有真值 τ(e)；真声明构成事件集。
- 记忆的张成（认为自己所知）与“好张成”（仅由真声明生成）分离。
- **覆盖效用**忽略真值，**精度效用**只依赖好张成；精度被覆盖所界定。
- **水膨胀度** Δ(π) = 期望覆盖 − 期望精度，衡量有多少报告质量是由虚假声明“灌水”而来。
- 噪声下的最优记忆目标改为最大化精度效用；关键困难不是优化本身，而是估计声明真值这一隐变量。

### 顺序记忆问题：问题设置分类与 MDP

- **渐进式问题设置分类**：
  - Level 0：单材料、单查询，本质是检索而非记忆。
  - Level 1a：单材料、多查询、已知查询分布，等于一次性最优记忆问题。
  - Level 1b：单材料、多查询、未知查询分布，需要顺序学习。
  - Level 2：多材料、多查询，学习可跨材料迁移的写入规则。
- **两种写入模式**：查询无关写入（先写后判，持久记忆）与查询感知写入（见查询再写，等于检索）。
- **顺序记忆 MDP**：每集新材料、记忆为状态、写作为动作、查询时结算的效用为延迟奖励；更新规则为 M_{m,t+1} = π_write(M_{m,t}, D_m, q_{m,t}, a_{m,t})。该 MDP 统一各层级，暴露延迟奖励、信用分配、探索–利用等核心学习问题。

## 6. 主要结论与发现

- 记忆可形式化为事件的子集（基），其价值由生成算子产生的知识张成决定；可回答性等价于覆盖问题。
- 最优记忆是容量约束下的期望覆盖最大化，其价值形成效用–容量前沿；前沿饱和于全上下文基线，压缩区内的垂直差距即压缩代价。
- 在可分解生成算子下，最优记忆是加权最大覆盖，贪心有 (1−1/e) 保证；跨事件协同可破坏子模性，使该保证失效。
- 噪声提取使覆盖与精度分开，水膨胀度量化虚假声明带来多少虚高记忆质量；噪声下的最优目标是精度而非覆盖。
- 顺序记忆问题统一为 MDP，延迟奖励、信用分配、信任估计成为核心学习难题。
- 现有记忆系统的差异主要在于生成、写入、读取与推理组件的选择，均可在该框架下映射；记忆质量可用在“大小–效用”平面上的位置与到前沿的差距来度量。
