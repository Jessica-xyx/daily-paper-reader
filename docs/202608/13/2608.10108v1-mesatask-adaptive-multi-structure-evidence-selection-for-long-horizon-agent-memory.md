## 摘要
长时程智能体会累积跨越数百个交错推理、行动和观察步骤的轨迹，回答查询时往往依赖于历史深处埋藏的证据。外部记忆以结构化表示存储此类轨迹，但每种结构仅提供独特且不完整的视图。现有的多记忆系统要么对每个查询读取固定的结构集合，导致上下文膨胀并引入噪声；要么将每个查询路由到单一结构，阻碍互补证据的组合。在AMA-Bench上的受控分析表明，最优记忆配置通常既不是单一结构，也不是全部结构的并集，而是随查询和任务需求变化的多结构化记忆的定制组合。受这些发现启发，我们提出了结构级动态选择：从专门记忆结构库中选择并融合查询自适应的子集。我们提出MESA（面向长时程智能体的多结构证据选择框架），为每条轨迹构建五个互补的结构视图，并利用端到端的答案级反馈学习，为冻结的答案模型选择和融合查询特定的子集。为在这种弱监督下学习，MESA采用带先验引导搜索的约束优化和UCB引导调度，以平衡探索与利用。在AMA-Bench上，MESA以比最强基线少41%的证据token，性能提升8.5%。

## Abstract
Long-horizon agents accumulate trajectories spanning hundreds of interleaved reasoning, action, and observation steps, where answering a query may depend on evidence buried far back in the history. External memory stores such trajectories as structured representations, yet each structure provides a distinct and incomplete view. Existing multi-memory systems either read a fixed set of structures for every query, inflating context and introducing noise, or route each query to a single structure, preventing the composition of complementary evidence. A controlled analysis on AMA-Bench shows that the optimal memory configuration is typically neither a single structure nor the full union, but a tailored composition of multiple structural memories that varies with query and task demands. Motivated by these findings, we formulate structure-level dynamic selection: selecting and fusing a query-adaptive subset from a library of specialized memory structures. We propose MESA (a Multi-structure Evidence Selection framework for long-horizon Agent), which builds five complementary structure views of each trajectory and learns from end-to-end answer-level feedback to select and fuse a query-specific subset for a frozen answer model. To learn under this weak supervision, MESA employs harness optimization with prior-guided search and UCB-guided scheduling to balance exploration and exploitation. On AMA-Bench, MESA outperforms the strongest baseline by 8.5% while using 41% fewer evidence tokens than the all-structure alternative.

## 1. 核心问题与整体含义（研究动机与背景）

- **问题背景**：长时程智能体（long-horizon agent）在执行过程中会累积跨越数百个交错推理、行动与观察步骤的轨迹，后续查询往往依赖历史中极早期产生的证据。直接将完整轨迹馈入长上下文 LLM 既昂贵，又难以可靠地定位深层证据（"lost in the middle"问题）。
- **现有方法的不足**：外部记忆将轨迹转译为多种结构化表示（如文本摘要、时序存储、知识图谱、向量库、原始轨迹），但每种结构都只提供不完整视图。现有系统存在两极分化：
  - **全量融合**（如 Hindsight）：对每个查询固定读取全部结构，无条件膨胀上下文并引入噪声；
  - **单结构路由**（如 StructRAG、Learning-to-Route）：每次只选一个结构，无法组合互补证据。
- **核心发现（受控分析）**：作者在 AMA-Bench 上穷举扫描五种结构的全部 31 个非空子集，发现两个关键规律：
  1. **最优组合通常是中间子集**——既不是单一结构，也不是全集；
  2. **最优组合随任务变化**——不同领域与能力类别的最优子集不同，不存在普遍最优的固定组合。
- **整体含义**：记忆读取应当实现**结构级动态选择（structure-level dynamic selection）**——根据查询需求，动态选取并融合一组互补的结构化记忆，在证据覆盖率、上下文效用与开销之间取得平衡。

## 2. 方法论：核心思想与技术细节

### 2.1 总体框架

MESA 为每条交互轨迹离线构建**五种互补的记忆结构**，并学习一个查询自适应的选择策略，其余组件（构建器、检索器、组合器、答案模型）全部冻结。

### 2.2 五种记忆结构

| 结构 | 构建方式 | 访问机制 |
|------|----------|----------|
| **摘要（S）** | 将轨迹分段压缩为状态记忆，保留关键状态变化、命令、标识符、错误等 | 直接作为全局上下文 |
| **时序存储（T）** | 保留原始动作-观察序列，带轮次索引 | 按查询中的显式步骤引用或词法匹配返回相关步骤 |
| **知识图谱（G）** | 基于 OpenIE 抽取实体-关系三元组，锚定到轨迹步骤 | 查询实体链接 + 1/2 跳邻居扩展，返回焦点关系 |
| **向量库（V）** | 每股（动作+观察）经 Qwen3-Embedding-4B 编码为向量 | 余弦相似度检索 Top-k 轮次 |
| **原始轨迹（R）** | 按滑窗切分为重叠片段，无语义压缩 | BM25 检索相关窗口 |

### 2.3 问题形式化

- 选择向量：\(\mathbf{z} \in \{0,1\}^K\)，非空约束 \(\|\mathbf{z}\|_0 \geq 1\)，K=5 时共 31 种组合；
- 选择策略：\(\mathbf{z}_i = S_\rho(q_i, c_i)\)，其中 \(c_i\) 为问题上下文（含任务/领域/问题类型信息，不含答案相关变量）；
- 证据合成：\(E_i(\mathbf{z}_i) = \text{Compose}(\{\Gamma_k(q_i, M_i^{(k)}) | z_i^{(k)}=1\})\)；
- 答案生成：\(\hat{y}_i = F(q_i, E_i(\mathbf{z}_i))\)，其中 F 为冻结答案模型；
- 优化目标：\(\tilde{J}_{\text{val}}(\rho) = J_{\text{val}}(\rho) - \lambda C_{\text{val}}(\rho)\)，在验证集准确率与证据 token 开销之间权衡，\(\lambda = 10^{-6}\)（每额外 10k token 须带来至少 1% 准确率提升）。

### 2.4 先验引导的约束优化（Prior-Guided Harness Optimization）

- **核心思路**：传统的提示词或完整 harness 搜索空间过大，在稀疏答案级反馈下方向性差。MESA 将搜索限制在一组**先验方向（prior directions）**上，每个方向描述一种可执行的选择策略生成/修改机制，分为五组：
  - 需求推断（能力、领域-任务、词法信号、查询分解）；
  - 后端价值估计（边际价值、条件价值、分层收缩、学习门控）；
  - 子集构建（独立门控、基数优先、前向选择、互补性选择）；
  - 证据感知（可用性、相关性、覆盖度、冗余度）；
  - 鲁棒性与成本控制（置信回退、冲突消解、简约控制、支持度感知路由）。
- **UCB 调度**：每个先验方向作为一个 UCB 臂，平衡探索与利用。UCB 得分 = 该方向候选的平均验证目标 + 探索奖励（\(\beta\sqrt{\log(N+2)/(n_a+1)}\)，\(\beta=0.08\)）。
- **迭代过程**：每轮由 LLM 提议器生成三个候选——利用候选（基于历史有效方向）、探索候选（基于未充分探索方向）、失败修复候选（针对当前策略的反复错误）。候选经训练集拟合、验证集评估后进入策略档案（policy archive），搜索结束后返回验证目标最高的策略。

### 2.5 与现有方法的关键区别

| 维度 | 现有方法 | MESA |
|------|----------|------|
| 组织方式 | 语义角色或统一 schema | 按访问模式区分异构结构 |
| 读取方式 | 固定策略或单一结构 | 查询自适应的互补子集 |
| 返回证据 | 广而不精或单源 | 异构结构的融合子集 |
| 策略优化 | 规则/静态或离线监督 | 答案级反馈的在线演化 |

## 6. 主要结论与发现

1. **结构级动态选择有效**：MESA 在 AMA-Bench 上以 Qwen3-32B 达到 65.1% 总体准确率，比最强基线 AMA-Agent 高 **8.5 个百分点**，比长上下文直接读取高 12.5 个百分点；用 Gemma-4-31B 同样高 6.4%。
2. **效率与精度双赢**：MESA 平均选择 2.8 个结构，每查询 11.0k 证据 token，比全结构方案（18.7k token，63.7%）高 1.4% 准确率的同时**节省 41.2% 的 token**。
3. **跨领域稳定提升**：在 Web、Text2SQL、Software、Embodied AI 四个领域均为最优，Software 领域提升达 15.5%；Open-World QA 与 Gaming 仅以 0.7% 微弱差距居第二。
4. **可迁移到对话记忆**：LoCoMo 上 F1 达 49.0%，超过此前最强基线 EMem（47.2%）1.8 个百分点。
5. **消融验证各组件必要性**：去除先验方向使准确率降 2.0%，去除 UCB 使准确率降 0.8% 且方差从 0.8 增至 2.2（稳定性下降）；route-to-one 仅 57.0%，证明组合互补结构而非选单一是核心。
6. **学习到的策略可解释**：演化出的选择规则表现为可读的条件式路由（如"time/sequence/history/event → {S,T,V}"、"database/sql → {S,T,R}"），便于分析与审计。

## 7. 优点与亮点

- **问题定位精准**：通过受控的穷举子集扫描，用数据证明"中间子集 + 任务自适应"的必要性，为问题形式化提供了实证基础，而非凭空假设。

- **token 成本被显式纳入目标**：将证据 token 数纳入正则化验证目标，同时优化准确率与效率，并给出可解释的权衡校准（10k token ↔ 1% 准确率）。
- **策略可解释性**：最终策略为显式的规则式路由，而非黑箱，有助于领域专家审计和后续改进。
- **实验覆盖全面**：多种骨干、多领域、多能力、跨数据集 + 多组消融 + judge 鲁棒性 + 划分敏感性 + 构建成本分析，工作量扎实。

## 8. 不足与局限

- **弱监督学习的固有局限**：答案级反馈是稀疏的二值信号（正确/错误），无法为单个结构的选择提供细粒度归因；尽管先验方向缓解了这一问题，但策略仍可能收敛到次优组合，因果推理类问题上的微弱劣势（低于 AMA-Agent 1.4%）即为例证。
- **结构种类固定**：仅覆盖 5 种代表性结构，未探索更多结构类型（如程序化检索、多模态记忆等）或不同结构粒度的影响；构建方式（摘要、图抽取等）依赖特定工具链（如 AMA-Agent 与 HippoRAG2 的人工产物）。
- **数据规模有限**：AMA-Bench 仅 208 个轨迹、LoCoMo 仅 10 个对话；5 次划分虽降低方差，但 LoCoMo 的跨会话泛化结论仍较脆弱（标准差 3.3%）。
- **跨数据集基线公平性存疑**：部分基线（如 MemGPT、Mem0）原设计面向对话，未针对 AMA-Bench 调优；虽然作者声称适配了提示与输入格式，但"尽力而为"的基线适配程度难以完全客观衡量。
- **算力透明度不足**：未报告 GPU 数量、训练时长和推理成本，MESA 的 30 轮优化需要大量验证集前向传播，实际训练成本可能高于一次性基线，文章未作成本-收益的全面对比。
- **评估指标的局限**：LLM-as-judge 虽经 3 模型交叉验证，但 judge 本身可能偏离人类判断；F1 指标仅用词面重叠衡量，对语义等价的不同表达可能误判。
- **工程依赖较强**：图记忆依赖 OpenIE 抽取质量、摘要依赖提示工程，实际部署时这些上游组件的稳定性可能影响整体效果。
- **未建模跨结构证据间的依赖**：当前 Compose 仅做拼接，未显式建模不同结构证据间的冲突或互补关系，未来工作提及此点但尚未解决。
