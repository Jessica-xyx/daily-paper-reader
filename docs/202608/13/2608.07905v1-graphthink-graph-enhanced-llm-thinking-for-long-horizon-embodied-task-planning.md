## 摘要
基于大语言模型规划器的具身代理常常面临物理幻觉、对长时程任务泛化能力差以及缺乏环境感知等问题。我们提出GraphThink，一种新颖的框架，它集成任务图以提供结构化知识支持稳健规划，并利用场景图维护环境记忆以支持事件驱动的重规划。具体而言，任务图通过上下文提示和迭代细化引导大语言模型思考，有效缓解规划幻觉。此外，在GRPO框架内，任务图提供了精细的奖励设计来训练大语言模型规划器，增强长时程规划能力并改善泛化性。最后，由场景图驱动的事件驱动重规划模块实现了闭环的环境感知和错误纠正。GraphThink在ALFRED基准上达到了最先进的性能。特别地，我们的高层规划器在验证集和保留的长时程任务上均超越了领先的基于API的大语言模型，凸显了其强大的零样本和少样本能力。额外的评估进一步证明了其对新颖任务和环境的强分布外泛化能力。

## Abstract
Embodied agents using LLM-based planners often struggle with physical hallucinations, poor generalization to long-horizon tasks, and lack of environmental awareness. We propose GraphThink, a novel framework that integrates a task graph to provide structured knowledge for robust planning and a scene graph to maintain environmental memory for event-driven replanning. Specifically, the task graph guides LLM thinking through contextual prompting and iterative refinement, effectively mitigating planning hallucinations. Furthermore, within the GRPO framework, the task graph offers delicate reward design to train the LLM planner, enhancing long-horizon planning capabilities and improving generalization. Finally, an event-driven replanning module, powered by the scene graph, enables closed-loop environment awareness and error correction. GraphThink achieves state-of-the-art performance on the ALFRED benchmark. In particular, our high-level planner surpasses leading API-based LLMs on both the validation set and held-out long-horizon tasks, underscoring its robust zero-shot and few-shot capabilities. Additional evaluations further demonstrate strong out-of-distribution generalization to novel tasks and environments.

- **核心问题**：现有基于 LLM 的具身规划器仍存在三大局限：
  1. **物理幻觉**：通用 LLM 缺乏物理常识，容易产生指令误解和规划幻觉，任务复杂度增加时失败率上升；
  2. **泛化差**：在有限域内数据上做监督微调，对未见长时程任务泛化能力差，且标注成本高昂；
  3. **环境感知不足**：现有重规划策略多只针对低层执行失败，缺乏高层指令对齐的检测能力，容易陷入短视决策和低效重试。
- **整体含义**：论文提出 **GraphThink** 框架，通过“任务图”提供结构化知识缓解物理幻觉、增强长时程泛化；通过“场景图”维护动态环境记忆，实现事件驱动的闭环重规划，从而显著提升具身任务规划的鲁棒性和泛化能力。

## 2. 论文提出的方法论：核心思想、关键技术细节

### 2.1 总体架构
GraphThink 包含三个核心模块：
- **高层规划器**：基于任务图（Task Graph）生成初始子任务序列；
- **低层动作策略**：带记忆的导航与交互执行器；
- **动态重规划模块**：基于场景图（Scene Graph）的事件驱动闭环调整。

### 2.2 任务图构建与作用
- **节点定义**：子任务表示为 `Ai(oi)` 或 `Ai(oi, oj)`，如 Pickup(object)、Put(object, receptacle)、Slice(object) 等；为增强泛化，使用元类 `C = {obj, rec, mov, spec}` 抽象对象类别（如可抓取物、固定容器、可移动容器、特殊操作目标）。
- **边构建**：通过“LLM 辅助的转移兼容性分析”构造有向边——每个子任务被抽象为 `⟨P_i, E_i⟩`（前置条件与效果），若前一子任务效果满足后一子任务前置条件且语义可行，则添加边 `v_p → v_q`。此方法不依赖轨迹演示，可泛化到未见任务。
- **可扩展性**：新增动作时，可通过同样的兼容性分析自动扩展边，无需新轨迹数据。

### 2.3 任务图的三重作用
1. **引导提示**：将任务图的节点和边编码为符号关系（如“A→B”）注入 prompt，指导 LLM 按图拓扑生成子任务序列。
2. **GRPO 奖励设计**：在 GRPO（Group Relative Policy Optimization）框架中，基于任务图设计多粒度奖励，包括：
   - **格式奖励** `R_fmt`：鼓励 XML/JSON 结构合法；
   - **节点级奖励** `R_node`：按元类动态加权，检验物体是否属于环境物体集合；
   - **边级奖励** `R_edge`：乘积形式，惩罚不符合任务图边的相邻子任务转移；
   - **指令跟随奖励** `R_inst`：两阶段设计——先检查关键子步骤覆盖，再检查与 GT 计划完全匹配；
   - 总奖励：`R_total = R_fmt + R_node + R_edge + R_inst`。
3. **外部验证器**：推理时对节点合法性和边合法性进行校验，若失败则反馈错误信息，循环“验证→反馈→修正”，最多迭代 3 次。

### 2.4 记忆感知的低层动作策略
- 主动缓存：在导航过程中，除记录目标物体的位置和分割掩码外，还缓存途中遇到的未来可能需要的“任务相关物体”位置作为候选路标；
- 实例级区分：对同类型多个物体维护独立交互记录，避免重复移动或放错位置。

### 2.5 基于场景图的动态重规划
- **任务感知场景图**：在线构建紧凑语义三元组 `(oi, r_ij, oj)`，仅保留任务相关对象（通常 <20 节点）；通过视觉语言模型（VLM）结合分割图生成候选关系，并加入物理合理性过滤与冲突消解。
- **事件驱动重规划**：
  - **低层动作错误触发**：如物体找不到、探索失败等；
  - **高层子任务完成触发**：在子任务完成检查点主动评估计划是否仍与指令对齐，可纠正“可执行但目标错位”的计划；
  - 重规划时以任务图约束可行性，以场景图提供环境上下文，保证修订方案的合理性。

## 6. 论文的主要结论与发现

1. **ALFRED 上显著超越 SOTA**：GraphThink 在测试集 unseen 上 SR 达到 68.52%（比之前最好方法高 6.17 个百分点），seen 上 SR 67.71%，均排名第一。

3. **任务图是核心**：去除任务图 prompt 或 GRPO 后性能大幅下降；边级奖励（R_edge）尤为关键，缺乏时 long-horizon 成功率从 86.25% 降至 50.50%。
4. **图奖励提升泛化与零样本能力**：仅依赖图奖励（无指令奖励）在验证集上仍能达到平均 84.47%，说明任务图本身能传授规划能力；加入指令奖励后防止“奖励黑客”，兼顾语义对齐。
5. **事件驱动重规划有效**：低层错误和高层子任务完成两个触发源均显著提升成功率，去除任一都会造成约 4-5% 的性能下降。
6. **跨环境泛化可行**：ALFRED 上训练的高层规划器可直接迁移到 VirtualHome（Ours(ALF) SR 90.00%/76.67%），且域内适配后达到最优（93.00%/88.89%），表明高层规划先验具有跨模拟器复用性。
7. **记忆机制提升执行可靠性**：低层记忆策略尤其对同类型多实例任务有效，避免重复探索或放置错误。

## 7. 优点

- **结构化的物理世界知识**：任务图将 LLM 开放生成约束为可执行的子任务转移路径，有效减少物理幻觉；构建过程不依赖轨迹演示，具备可扩展性。
- **多粒度奖励设计**：在 GRPO 中融合节点、边、指令、格式奖励，尤其是两阶段指令奖励和基于任务图的边奖励，兼顾多解性和语义对齐，缓解了奖励稀疏/奖励黑客问题。
- **闭环动态重规划**：提出“低层错误 + 高层子任务完成”双事件驱动机制，配合场景图作为紧凑的环境记忆，既能纠正执行错误，也能主动发现指令错位，弥补了以往重规划策略的短视缺陷。
- **记忆感知的低层策略**：主动缓存与实例级区分设计具有实用价值，减少了重复探索和交互错误。
- **实验体系完善**：不仅做标准基准，还构建长时程数据集、引入新动作、跨环境迁移、按 horizon 细粒度分析，有力支撑了泛化性论断。
- **性价比高**：使用 7B 规模模型即可超越大规模 API 模型，且推理时间更低（长时程任务约 7-10s，远低于 GPT-5.2+RAG 的 32-47s），说明方法高效实用。

## 8. 不足与局限

- **算力信息缺失**：未报告训练所需的 GPU 型号、数量、时长等资源消耗，难以评估部署成本。
