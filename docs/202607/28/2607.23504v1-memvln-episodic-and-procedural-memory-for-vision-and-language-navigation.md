## 摘要
连续环境下的视觉与语言导航（VLN-CE）要求智能体在低延迟执行动作的同时，维护长程视觉历史以保持轨迹一致性。现有的基于视频的VLN方法通常难以同时满足这两项需求。为应对这些挑战，我们提出MemVLN，一种新颖的VLN框架，在实现实时推理效率（14 FPS）的同时达到了最先进的性能。MemVLN利用视觉编码器处理连续观测，并借助大型语言模型（LLM）解释指令和生成动作。我们方法的核心是一种采用金字塔分辨率的情景记忆管理机制。该机制将计算集中在当前感知上，同时保留压缩后的长期历史。作为这一设计的补充，我们引入程序记忆以实现快速动作，通过使用紧凑的原子级中层动作词汇来绕过自回归解码延迟。在VLN-CE上的实验表明，MemVLN-4B在R2R和RxR上分别比基线Qwen3-VL-4B架构高出5.8%和9.7%的成功率（SR），同时推理延迟加速了7倍。

## Abstract
Vision-and-Language Navigation in Continuous Environments (VLN-CE) requires agents to maintain long-horizon visual history for trajectory consistency while executing actions with low latency. Existing video-based VLN approaches typically struggle to satisfy both demands simultaneously. To address these challenges, we propose MemVLN, a novel VLN framework that achieves state-of-the-art performance with real-time inference efficiency (14 FPS). MemVLN utilizes a visual encoder to process continuous observations and a Large Language Model (LLM) to interpret instructions and generate actions. Central to our approach is an Episodic Memory management that applies pyramidal resolutions. This mechanism concentrates computation on immediate percepts while retaining compressed long-term history. Complementing to this design, we introduce Procedural Memory for fast action with a compact vocabulary of atomic mid-level actions to bypass auto-regressive decoding latency. Experiments on VLN-CE show that MemVLN-4B surpasses the baseline Qwen3-VL-4B architecture by 5.8\% SR in R2R and 9.7\% SR in RxR, while achieving a 7$\times$ speedup in inference latency.

## 1. 核心问题与整体含义（研究动机和背景）
- **研究背景**：视觉与语言导航在连续环境（VLN-CE）中要求智能体在无地图情况下，根据自然语言指令从起点导航至目标。该任务需要同时维护长程视觉历史（保持轨迹一致性）和低延迟执行动作（实时控制）。
- **核心问题**：现有方法难以兼顾二者——固定帧采样（如均匀采样8帧）牺牲了时间密度，而通过池化或合并压缩视觉令牌的方法则损失空间细节。
- **动机**：受到人类情景记忆（对近期高分辨率、远期压缩存储）和程序性记忆（无意识、自动化的技能执行）启发，提出MemVLN框架，旨在实现高效长程视觉管理的同时达到实时推理。

## 2. 方法论：核心思想、关键技术细节
- **整体架构**：采用Qwen3-VL作为LVLM骨干，输入为RGB视频流和指令，输出为离散动作。包含三个模块：视觉编码器、情景记忆（金字塔分辨率管理）、程序性记忆（快速动作词汇）。
- **情景记忆（Episodic Memory）**：
  - 基于注意力分析：最近几个观察帧占据大部分注意力权重，早期帧权重极低。
  - 提出**金字塔分辨率策略**：将历史帧分为三个时间层级——即时帧（immediate）、短期帧（short-term）、长期帧（long-term），分别以高、中、低分辨率处理（如512×512、256×256、128×128）。
  - 通过调整分辨率，使得长期序列的总令牌数不超过一帧即时帧，从而在不增加令牌预算的情况下扩大有效回溯窗口。
  - 对比不同金字塔类型（U形、降序、升序），实验表明升序（越近分辨率越高）效果最佳。
- **程序性记忆（Procedural Memory）**：
  - 解决自回归解码延迟瓶颈：生成首令牌耗时最长（预填充），后续令牌生成线性增长。传统方法预测文本序列（如“左转30度”）需要多次迭代。
  - 提出**快速动作（Fast Action）**：将中层动作（如“前进25cm”、“左转15°”等）映射为单个特殊令牌，形成紧凑的原子动作词汇表（包含10种动作）。
  - 实现单次前向传播即可预测动作，绕过自回归解码，推理速度提升至14 FPS（较基线2 FPS加速7倍）。
  - 动作词汇表详见附录E：Stop、前进短/中/长距离、左转15°/30°/45°、右转15°/30°/45°。
- **训练目标**：交叉熵损失最大化地面真实动作的对数概率。训练数据包括R2R、RxR及其EnvDrop增强、ScaleVLN（416K对）、人类导航轨迹（557K）和DAgger合成数据（278K）。

## 6. 主要结论与发现
- MemVLN在R2R-CE和RxR-CE上达到SOTA（MemVLN-8B：SR 58.4% R2R，66.0% RxR；SPL 51.2% R2R，57.3% RxR），且仅使用单目RGB输入，优于使用深度/全景/里程计的方法。

- 金字塔分辨率在固定令牌预算下有效提升SR和SPL（最多1.2% SR增益），升序方案最优。
- 训练数据规模与多样性对性能至关重要，DAgger数据带来显著提升。

## 7. 优点
- **创新性**：首次将生物启发的双记忆系统（情景+程序）引入VLN，设计简洁有效。
- **效率**：实现实时推断（14 FPS），远超现有VLM方法（通常<5 FPS），实用性强。
- **通用性**：仅需单目RGB，不依赖深度、全景或里程计，降低传感器要求。
- **实验完整性**：系统消融了各个组件，验证了每个设计选择的必要性。

## 8. 不足与局限
- **计算资源**：依赖8×H200 GPU，训练成本较高；推理仍需GPU，难以部署在边缘设备或低功耗平台。
