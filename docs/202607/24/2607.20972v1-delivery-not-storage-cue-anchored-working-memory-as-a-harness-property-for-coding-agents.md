## 摘要
编码代理自带一种记忆：文档。指令文件、计划工件和自动写入的记忆目录是刻意编写且刻意检索的：代理必须选择写入它们，并选择重新读取它们。人类专业知识运行在第二层，这一层从未被写下：情境绑定的操作事实（陷阱、位置、本地约定）作为工作的副产物被编码，并在情境触发时不由自主地检索。我们论证这一第二层是长期运行代理的承重层，且必须是框架属性，而非代理选择。我们贡献了：(1) 基于记忆卸载、偶然编码和基于事件的前瞻记忆等认知文献的两层设计理论，每种都映射到架构需求；(2) 一个线索锚定的记忆模型，其中记忆携带基于可组合词汇表（路径、符号、语义、事件、时间）的一等触发条件，由框架确定性评估，这种组合是任何被调查的学术或已部署系统都不提供的；(3) 在一个真实编码任务上的控制评估显示，即使有预先种子的存储，自愿记忆使用也几乎为零（114轮中0次记忆操作），确定性注入在每次种子运行中均成功实现且零误报，39%的会话内重读在压缩边界之前重新购买了已付费的内容；(4) 一个重复压缩衰减探测：仅保存在对话中的十个事实在第一次摘要时消失，并在108次压缩中的106次中持续缺失，被剥夺的代理通过grep框架自身的会话文件来重建它们，而同一事实从框架拥有的存储注入则完好地通过所有138次压缩恢复，最终摘要不携带任何事实。交付而非存储才是产品：代理的可靠记忆通道是代理永远无需思考的那个通道。

## Abstract
Coding agents ship with one kind of memory: documents. Instruction files, plan artifacts, and auto-written memory directories are deliberately authored and deliberately retrieved: the agent must choose to write them and choose to read them back. Human expertise runs on a second tier that never gets written down: situationally-bound operational facts (gotchas, locations, local conventions) encoded as a side effect of the work and retrieved involuntarily when the situation cues them. We argue this second tier is the load-bearing one for long-running agents and must be a harness property, not an agent choice. We contribute: (1) a two-tier design theory grounded in the cognitive literature on memory offloading, incidental encoding, and event-based prospective memory, each mapped to an architectural requirement; (2) a cue-anchored memory model where memories carry first-class trigger conditions over a composable vocabulary (path, symbol, semantic, event, temporal), evaluated deterministically by the harness, a composition no surveyed academic or shipped system provides; (3) a controlled evaluation on a real coding task showing that voluntary memory use is near zero even with a pre-seeded store (0 memory operations in 114 turns), that deterministic injection delivered in every seeded run with zero false alarms, and that 39% of intra-session re-reads re-buy content paid for before a compaction boundary; (4) a repeated-compaction decay probe: ten facts held only in conversation vanish at the first summary and stay absent from 106 of 108 compactions, and the deprived agent greps the harness's own session files to rebuild them, while the same facts injected from a harness-owned store arrive intact through all 138 compact-resumes as the final summary carries none. Delivery, not storage, is the product: the reliable memory channel for agents is the one the agent never has to think about.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：当前编码代理（coding agents）只依赖显式文档记忆（指令文件、计划工件、自动写入的记忆目录），这些是刻意编写和刻意检索的。但人类专家真正依赖的是第二层记忆——情境绑定的操作事实（小技巧、文件位置、本地约定），这些事实作为工作副产物无意识编码，并在情境触发时自动检索。
- **研究动机**：现有代理系统仅提供第一层（存储），缺少第二层（交付）。即便给代理提供记忆工具，自愿使用几乎为零（实验显示114轮中0次记忆操作）。长期运行中，对话压缩（context compaction）导致事实丢失，代理被迫自己构建记忆。
- **整体含义**：论文提出第二层记忆必须是框架（harness）属性，而非代理主动选择。记忆的可靠交付（delivery）比存储（storage）更重要——代理无需思考的记忆通道才是可靠的。

## 2. 论文提出的方法论

- **核心思想**：双层记忆设计理论。第一层是显式文档（Tier 1），第二层是线索锚定工作记忆（Tier 2，文中称为“brain memory”），基于认知科学中的偶然编码、编码特异性、前瞻记忆等机制。
- **关键技术细节**：
  - **cue-anchored记忆模型**：每个记忆是一个元组 `(content, kind, triggers, scope, decay)`。类型分为指令（directive）、陷阱（gotcha）、发现（finding）、任务（task）、引用（reference）。
  - **触发条件（triggers）**：可组合的词汇表，包括路径（path glob）、符号（symbol，需代码符号图）、语义（semantic）、事件（event，如会话启动、提交、编辑、运行、压缩前/后）、时间（temporal，如冷却期）。触发器内合取，触发器间析取。
  - **确定性评估**：所有触发条件由框架侧决定性地评估，不依赖模型判断。这是为了解决TriggerBench发现的模型无法自我触发的问题。确定性也带来可审计性（每次评估和注入都有日志记录）。
  - **交付纪律**：注入有预算（两层级：默认紧凑索引，按需或线索触发时全内容）；会话内火记录器去重，压缩边界重置；注入内容携带来源标注（“由AI会话记录，未经人类验证”）；自动检查陈腐性并警告。

## 6. 论文的主要结论与发现

- **自愿记忆使用近乎为零**：即使存储预先填充了任务相关知识，且提供工具和明确指导，代理在114轮中未进行任何记忆调用。
- **确定性注入工作且零误报**：无论通过代理通道还是原生钩子，注入每次都能在正确时机到达，且审计日志显示零误报触发。
- **压缩下会话记忆迅速消失**：重复压缩衰减探测中，对话中仅存的10个事实在第一次摘要时全部丢失，并在后续108次压缩中的106次持续缺失；代理被迫使用考古shell指令从框架的磁盘会话文件中重建它们。
- **注入记忆持久生存**：同样10个事实通过框架拥有的存储注入，在所有138次压缩恢复中完好送达（139次审计日志记录的交付，包括初始启动和每次恢复），而最终摘要却一个都不携带——代理的记忆从未依赖于摘要器的不稳定选择。
- **交付而非存储**：可靠记忆通道是代理无需思考的那个通道。

## 7. 优点

- **理论贡献**：将认知科学中的偶然编码、线索驱动检索等机制系统映射到架构要求，提出双层记忆理论，具有生成性价值。
- **机制创新**：提出可组合的多词汇表（路径、符号、语义、事件、时间）作为一等触发条件，且由框架确定性评估、提供审计表面。目前无其他系统具有这种组合。
- **实验设计**：
  - 使用审计日志作为机制证据，而非仅靠模型输出信任。
  - 自然主义任务（真实功能开发）与受控衰减探测相结合。
  - 知识恒等比较（相同种子比较注入 vs 自愿）设计清晰。
  - 重复压缩下的生存曲线测量为首次系统性分析。
  - 完全开源（代码、数据、分析工具）。
- **结论有冲击力**：论证了记忆系统不是内容问题而是控制面问题，对于代理长期运行有实际指导意义。

## 8. 不足与局限

- **样本量小**：主要任务只有12次运行，衰减探测每臂一次运行。论文明确声明方向性而非效应量。
- **外部有效性局限**：仅一个语料库（Apache Camel），一个任务家族，一个代理产品（Claude Code），一个模型家族（Sonnet 5 / Haiku 4.5）。其他模型（如GPT-4）和任务类型未测试。
- **触发词汇覆盖面不完整**：实验中只使用了路径、语义和事件触发器；符号和时间触发器虽已实现但未在任何分级运行中激活，因此组合新性质部分未被完全验证。
- **捕获侧未评估**：论文只测量了注入和自愿读取，但未评估记忆的自动捕获能力（即代理能否自主写回记忆），这是“开放半面”。

- **作者偏差**：实现和实验为同一作者，尽管有缓解措施（固定版本、审计日志、公开原始数据），但仍需独立复现。
- **衰减探测使用小模型（Haiku）**，更大模型的摘要行为可能不同。
