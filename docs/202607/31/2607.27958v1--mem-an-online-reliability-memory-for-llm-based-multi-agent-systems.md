## 摘要
记忆对于长期运行的LLM智能体至关重要，然而现有的记忆系统主要保存交互内容，而非建模哪些智能体可以被信任以及信任的条件。这种局限性在多智能体系统中尤为重要，因为中心模型可能无法直接验证看似合理或相关的同伴响应。我们提出了Σ-Mem，一种在线可靠性记忆，它记录个别同伴的历史能力证据以及整个同伴集合中的同伴关系证据。两种形式的证据都作为实对称状态维护，并根据决策后的正确性反馈进行更新。根据Weyl不等式，每次事件级更新引起的光谱变化是有界的，从而无需重新训练底层模型即可实现稳定的在线自适应。Σ-Mem提供了通用的读写接口：同一记忆可用于中心模型的残差引导、无响应同伴路由或可靠性加权投票。在五个Qwen系列模型上，Σ-Mem能够适应反事实可靠性变化，并泛化到未见过的同伴和任务领域。在整个OOD评估集上，直接记忆读出也优于多数投票和最佳固定同伴。此外，随着更多正确性反馈的可用，性能持续改善，表明Σ-Mem逐步积累可操作的可靠性信息。这些结果确立了可靠性记忆作为基于LLM的多智能体系统中自适应协调的可重用基础。

## Abstract
Memory is central to long-horizon LLM agents, yet existing memory systems primarily preserve interaction content rather than modeling which agents can be trusted and under what conditions. This limitation is particularly important in multi-agent systems, where a central model may be unable to directly verify plausible or correlated peer responses. We introduce $Σ$-Mem, an online reliability memory that records historical competence evidence for individual peers and peer relationship evidence across the peer set. Both forms of evidence are maintained as real symmetric states and updated from post-decision correctness feedback. By Weyl's inequality, the spectral change caused by each event-level update is bounded, enabling stable online adaptation without retraining the underlying models. $Σ$-Mem provides a general write-and-read interface: the same memory can be used for residual steering of a central model, response-free peer routing, or reliability-weighted voting. Across five Qwen-family models, $Σ$-Mem adapts to counterfactual reliability shifts and generalizes to unseen peers and task domains. Direct memory readouts also outperform majority voting and the best fixed peer over the full OOD evaluation set. Moreover, performance improves consistently as more correctness feedback becomes available, indicating that $Σ$-Mem progressively accumulates actionable reliability information. These results establish reliability memory as a reusable foundation for adaptive coordination in LLM-based multi-agent systems.

## 1. 核心问题与研究动机

- **背景**：长期运行的 LLM 智能体依赖外部记忆来保存和检索历史交互信息，现有记忆系统主要以**内容记忆**（content memory）为主，即记录“说了什么、做了什么、尝试了什么”。
- **核心问题**：在多智能体系统（MAS）中，中心模型协调多个同伴模型时，关键决策不仅取决于同伴“说了什么”，还取决于**该同伴是否值得信任、在何种条件下值得信任**。内容记忆无法回答“谁可以被信任，以及何时可以信任”这一根本问题。
- **具体困难**：
  - 中心模型常常无法直接验证同伴的回答（如支撑上下文不可用，或验证难度不亚于作答）；
  - 多个同伴给出相互一致的回答时，可能反映的是**相关偏差或共同错误**，而非独立佐证；
  - MAS 的失败往往发生在信任决策环节——错误地拒绝了正确的同伴回答，或接受了错误的回答。
- **研究意义**：作者提出，可靠性记忆（reliability memory）应当与内容记忆互补，成为 MAS 中自适应协调的持久基础设施。

## 2. 方法论：Σ-Mem 机制

### 2.1 核心思想
Σ-Mem 在线记录两类互补的可靠性证据：
- **历史能力证据**（per-peer competence evidence）：记录每个同伴在不同任务条件下随时间的可信度，存于实对称矩阵 M_p（维度 r×r）。
- **同伴关系证据**（peer relationship evidence）：建模同伴间正确性模式的关联（如倾向于同时成功或共同失败），存于实对称矩阵 G（维度 P×P）。

### 2.2 关键技术细节
- **事件级写入**：
  - 对给定输入 x_t，计算归一化能力方向 φ(x_t)，获得外部正确性标签 c_{p,t} ∈ {+1, −1}。
  - 能力记忆更新式：
    \[
    M_p^{(t+1)} = \gamma M_p^{(t)} + \eta c_{p,t} \phi(x_t)\phi(x_t)^\top
    \]
  - 关系矩阵更新式（中心化正确性向量 q_t 后）：
    \[
    G^{(t+1)} = \gamma_G G^{(t)} + \eta_G q_t q_t^\top, \quad \text{diag}(G)=1
    \]
  - 两个状态均为实对称矩阵，更新项为秩一对称矩阵，保持对称性。

- **稳定性保证**：
  - 利用 Weyl 不等式 \(\lambda_i(M+E) - \lambda_i(M) \le \|E\|_2\)，单次更新的谱扰动有界，防止单次反馈过度扭曲记忆。
  - 定理 1 证明：在固定能力方向上，持久信号的增长与噪声界无关（噪声以 \(1/\sqrt{1-\gamma^2}\) 为界，不随 T 增长），因此一致证据在谱中累积，孤立噪声被衰减。

- **读取与残差引导**：
  - 决策时计算读出向量 \(r_{p,t} = M_p^{(t)} \phi(x_t)\)，经投影矩阵 P 和标量增益 g 得到同伴特有的残差引导向量 \(\delta_{p,t}\)，仅注入中心模型的上层解码器块（ℓ ∈ [⌊L/2⌋, …, L−1]）。
  - 中心模型在同伴条件化的残差流下评估每个候选回答，计算“Yes/No”对数似然差作为效用分数 U_{p,t}。

- **选择机制**：
  - 结合同伴关系矩阵 G，定义关于潜在正确性状态 y_t 的后验分布（Ising 模型形式），以精确枚举计算后验期望，选择期望最高的同伴。
  - 该过程将**选择**与**记忆写入**分离：选择依赖效用、历史引导和同伴关系；写入仅依赖外部反馈。

- **额外直接读取**（无需中心模型实时判断回答）：
  - M-Routing：选择 \(s_{p,t} = \phi(x_t)^\top M_p^{(t)} \phi(x_t)\) 最大的同伴，直接采用其回答。
  - M-Weighted Voting：以可靠性分数作为投票权重，对相同规范答案的同伴分数求和并选择最高者。

1. **适应反事实可靠性变化**：Σ-Mem 能显著改善同伴选择，尤其 Qwen3-0.6B 在 CF@90 将准确率从 46.22% 提升至 71.10%（Σ w/ G）。
