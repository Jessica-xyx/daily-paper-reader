## 摘要
近期推理时间扩展的进展显著解锁了大语言模型（LLMs）的复杂推理能力。然而，对于智能体而言，这些方法存在关键的低效问题，即以无状态方式运行并进行冗余搜索。现有记忆机制主要依赖LLMs的推理能力，导致计算成本过高。在本文中，我们提出一种新框架——GAMER（基于图的动作中心记忆与情节推理），旨在弥合推理扩展与情节记忆之间的差距。我们的方法将历史推理建模为动态的“动作中心图”。通过将记忆机制与LLMs解耦，我们的方法相比记忆机制基线能够节省token/资金消耗，因为它需要更少的记忆上下文。为了有效从图中提取知识，我们使用双流时间差分学习机制，基于过去的成功与失败估计动作节点的正（建议）与负（规避）价值。在推理阶段，这一学习到的价值函数双向优化决策，使得正价值提供动作建议，而负价值指示高风险动作。通过在图上进行高效搜索，我们的方法显著提升了推理扩展的效率。在多个基准上的实验表明，与普通基线相比，GAMER在成功率/进展率上分别实现了20.81%/6.17%的显著性能提升。

## Abstract
Recent advancements in inference-time scaling have significantly unlocked the complex reasoning capabilities of Large Language Models~(LLMs). However, for agents, these approaches suffer from a critical inefficiency, operating in a stateless manner and engaging in redundant search processes. Existing memory mechanisms largely rely on the reasoning capabilities of LLMs, leading to prohibitive computational costs. In this paper, we propose a novel framework, \textit{GAMER}~(Graph-based Action-centric Memory with Episodic Reasoning), that bridges the gap between inference scaling and episodic memory. Our approach models historical reasoning as a dynamic \textit{Action-Centric Graph}. By decoupling the memory mechanism from LLMs, our method can save token/money usage by providing less memory context than memory mechanism baselines. To extract knowledge from the graph effectively, we use a dual-stream Temporal Difference learning mechanism to estimate the positive~(suggestion) and negative~(avoidance) value of action nodes based on past successes and failures. During the inference phase, this learned value function optimizes decision-making bi-directionally, so that positive values provide action suggestions, while negative values indicate high-risk actions. By performing efficient searches on the graph, our method significantly improves the efficiency of inference scaling. Experiments on multiple benchmarks demonstrate that \textit{GAMER} achieves superior performance by \textbf{20.81\%/6.17\%} for success/progress rate compared to vanilla baselines.

## 论文核心问题与整体含义

- **研究背景**：推理时间扩展（Inference-time Scaling）通过增加测试时计算来提升大语言模型（LLM）的复杂推理能力（如 CoT、ToT 等方法），但现有方法以**无状态（stateless）**方式运行——每次面对新任务时都从零开始搜索，无法利用过去的经验。
- **核心矛盾**：① 推理扩展的低效：即使新任务与已解决的任务结构相似，智能体仍会重复探索大量搜索空间，造成巨大的 token 开销和延迟；② 现有记忆机制（如 A-MEM、G-MEM）虽能增强长期信息保留，但本质上只是"检索静态事实并注入上下文"，并未剪枝搜索空间或直接优化决策过程，且高度依赖 LLM 自身的推理能力，计算成本高昂。
- **核心问题**：如何将"推理时间扩展的高探索能力"与"情节记忆的持久性优势"结合起来，使智能体在长时程、不可逆的环境中避免重复劳动，并实现高效推理？
- **整体思路**：将记忆从"被动存储的日志"转变为"主动的动作中心图（Action-Centric Graph）"，用强化学习方法解耦记忆机制与 LLM 推理过程，以此实现低成本的、结构化的经验复用与决策引导。

## 方法论

### 核心思想
- 将历史交互轨迹（trajectories）定义为动作中心图 G = (V, E)，其中**节点**表示不同的动作（actions），**边**表示动作间的时序依赖（temporal transitions）。
- 区别于基于文本或实体的记忆系统，该方法将"推理步骤"抽象为可查询、可评估的图中节点，使得记忆不仅能被检索，更能**主动指导决策**。

### 关键技术细节：三个主要阶段

1. **图构建（Graph Construction）**
   - 从轨迹池 D 中聚合 N 条轨迹 τ = (o₀, a₀, r₀, ..., a_T, r_T)，节点 V = {a | a ∈ τ}，边 e_ij = (v_i, v_j) 表示历史中 v_i 之后紧接 v_j。
   - 该图浓缩了离散的线性经验，分支点表示历史探索过的不同策略，环表示递归推理回路。

2. **双流时序差分价值学习（Dual-Stream TD Learning）**
   - 为解决单一 Q 值会中和风险信息的缺陷（如某动作 50% 成功得 +1、50% 失败得 -1，期望值为 0，无法反映风险），提出两个独立的价值函数：
     - **Q+(v)**：正向价值，估计动作的期望成功率，用标准环境奖励 r_t 更新；
     - **Q−(v)**：负向价值，估计失败风险，引入阈值化奖励：r⁻_t = -1（若 r_t < ϵ_r）否则 0。
   - 更新规则：Q^(+/−)(v_t) ← Q^(+/−)(v_t) + α[r^(+/−)_t + γ · max/min_{v′∈Succ(v_t)} Q^(+/−)(v′) − Q^(+/−)(v_t)]（δ_t 为 TD 误差，γ = 0.95，α = 0.05）。

3. **图引导的推理扩展（Graph-Memory Guided Inference Scaling）**
   - **参考轨迹引导**（全局）：从轨迹池中检索历史最优轨迹 τ* = argmax R(τ)，作为 few-shot 示例。
   - **双流动作注入**（局部）：每一步根据当前节点 v_t 的后继节点生成两个列表：
     - 建议动作 A_suggest = TopK_{a∈Succ(v_t)} Q+(a)；
     - 规避动作 A_avoid = TopK_{a∈Succ(v_t)} |Q−(a)|。
   - **提示集成**：将上述结构化信号以自然语言形式注入 Prompt（"这是当前任务的最佳历史轨迹……你应该避免这些动作……"），引导 LLM 的概率分布偏向高价值区域、抑制高风险分支，且**无需修改底层解码过程或额外调用 LLM**。

### 理论保证
- **定理 4.2**：若 Q+、Q− 与真实奖励分布 ε-一致，则记忆引导策略的奖励分布对基策略具有一阶随机占优（First-order Stochastic Dominance, FSD）。
- **定理 4.3**：对于任意采样预算 N，期望最大奖励 J_mem(N) ≥ J_base(N)；达到目标奖励 x* 所需样本数 N_mem ≤ N_base，即以更低采样预算达到相同性能。

## 实验设计

### 数据集 / 场景（Benchmarks）
评估采用 AgentBoard 框架下的四类环境：
- **AlfWorld**：134 个测试任务，文本具身环境，家庭任务，需长时程动作序列、稀疏奖励、强前后期动作依赖；
- **ScienceWorld（SciWorld）**：90 个测试任务，模拟科学实验环境，强调因果推理、假设检验、长期依赖追踪；
- **PDDL**：60 个符号规划任务，确定性转移动力学，强调结构化状态转移和精确动作依赖；
- **Tool-Query（Tool）**：60 个工具调用任务，强调工具选择、调用组合和输出集成。

### 后端 LLMs
- 三个开源模型：Qwen2.5-7B、Llama3.1-8B、Gemma3-12B；一个闭源模型：GPT-4o-mini。

### 对比方法（三类共 9 种）
- **推理扩展方法**：Vanilla Best-of-N、Linear Search（Reflexion）、Scattered Forest Search（SFS）；
- **记忆机制方法**：Voyager、MemoryBank、Generative Agents；
- **自进化方法**：A-Mem、ReasoningBank、AWM。

### 实验设置
- 最大步数 10，推理预算 N = 64（前 32 条轨迹作为 warm-up 知识，后 32 条应用 GAMER）；
- 默认 K = 3（建议/规避动作数）；TD 学习 100 次迭代；
- 指标：成功率（Success Rate, SR）和进展率（Progress Rate, PR）；
- 采用 Best-of-N 设置（所有方法取最高分轨迹作为最终结果）以保证公平比较。

## 主要结论与发现

- GAMER 在四个 benchmark 上平均 **SR 31.60% / PR 60.01%**，相比 Vanilla 基线分别提升 **20.81% / 6.17%**（引言部分对比 best-of-N 报告 15.4% / 5.47%，两处口径略有差异），全部 16 组实验中几乎一致优于基线；
- 在 **AlfWorld** 上提升最显著（SR 提升 53.17%），在 **Tool**、**SciWorld**、**PDDL** 上均有持续增益；
- 缩放行为分析显示：GAMER 在全部 N 值域内保持最高性能且斜率最陡，表明继续增加推理预算仍可持续拉开差距；
- **Token 效率**：相比 A-Mem 平均节省约 50% token；仅比 Vanilla、SFS 和 AWM 略高，但远低于其他记忆类方法；
- **消融结果**：建议动作与规避动作单独使用均有效；历史轨迹单独使用效果不稳定（在 Tool 上甚至降低 SR），但与建议/规避结合时产生协同增益，说明三模块缺一不可；
- 不同 LLM 骨干下性能稳定性差异明显：A-Mem 在 Gemma3-12B 上因推理能力较强而表现较好，但在 Llama3.1-8B 上显著下降；GAMER 则在不同模型上保持一致的提升，表明其对模型推理能力依赖更低、泛化性更强。

## 优点

- **方法设计的创新性**：将记忆机制从"检索静态文本"重构为"查询动态动作值"，用图结构 + TD 学习双向利用成功/失败经验——正向建议提升高价值路径选取概率，负向规避作为"软屏障"剪枝高风险搜索空间。这一设计从计算层面（而非仅上下文层面）优化推理，理念新颖。

- **完备的实证体系**：覆盖 4 类 benchmark × 4 种 LLM × 9 种基线、全 N 缩放曲线、token 与时间分析、组件/超参数消融，形成了从性能到效率到鲁棒性的立体验证。
- **理论支撑**：提供 FSD 和采样复杂度定理（附录 B），为方法的高效性提供数学保障。
- **合理的适配性思考**：论文注意到"思维级推理可逆可回退，而智能体动作级推理不可逆"的关键差异，据此从树搜索重构为动作图引导，问题建模精准。

## 不足与局限

- **对 warm-up 轨迹数量的依赖**：论文在 Limitation 中明确指出，若初始 warm-up 集过小（如仅 4 条轨迹），智能体可能收敛至次优行为模式，甚至性能低于 Vanilla 基线，这限制了其在冷启动场景下的直接应用。
- **Hyperparameter 敏感性验证不足**：建议/规避动作数与 warm-up 量的分析主要集中于 AlfWorld；在其他更复杂场景中高 K 值是否导致"过载提示"从而降低性能并未充分讨论。
- **实验覆盖缺口**：消融实验未涵盖 PDDL benchmark；未在所有 benchmark 上提供统一的大规模消融；未与其他基于图的记忆方法（如 G-MEM）或更强的推理扩展基线（如 MCTS、思维树变体）直接对比。
- **理论假设的实证缺失**：定理部分依赖"Q+、Q− 与真实奖励 ϵ 一致""概率单调再分配"等假设，论文未通过实验验证这些假设在真实环境中的成立程度。
- **可解释性有限**："动作节点"的定义依赖 LLM 生成动作的文本表述，不同模型对同一操作可能产生不同的动作表达，可能影响图构建的一致性（论文仅简要提及 LLM 的上下文过滤作用，未做深入分析）。
- **未报告统计显著性**：缺少多重运行的标准差/置信区间，对于部分小差距基准（如 PDDL 上 7.08 vs 6.25）难以判断是方法优势还是随机波动。
