## 摘要
记忆对于LLM代理积累任务经验和复用特定任务执行策略至关重要。然而，在边界无关且不断演变的任务流中进行实际部署，会暴露出一个基本的稳定性-可塑性困境。基于外部检索的记忆可以快速吸收新证据，但往往难以内化重复出现的执行模式，并产生推理时的检索开销。参数记忆一旦学习完成，能够实现稳定高效的执行，但通常依赖明确的任务边界和固定的参数预算。受人类大脑通过互补的情景存储和渐进巩固来平衡可塑性与稳定性的启发，我们提出了UniMem，一种用于自主记忆管理的自路由框架。UniMem使用可学习的路由令牌作为记忆控制器，实现互补记忆通路之间的自适应协调：新颖或稀疏的任务保留在情景缓冲区中以供检索增强执行，而重复且可靠的模式则整合到可扩展的参数记忆中。通过使用路由令牌和参数记忆块将任务识别与任务执行解耦，UniMem在部署过程中无需任务标签即可按需扩展记忆，且不会导致参数失控增长。在长时程流式任务序列上的实验表明，UniMem在保持执行准确性的同时，持续优于基线方法，在三个骨干模型上平均获得4.0个EM点的提升。

## Abstract
Memory is essential for LLM agents to accumulate task experience and reuse task-specific execution strategies. However, real-world deployment over boundary-agnostic and evolving task streams exposes a fundamental stability-plasticity dilemma. External retrieval-based memory can rapidly absorb new evidence, but it often fails to internalize recurring execution patterns and incurs inference-time retrieval overhead. Parametric memory enables stable and efficient execution once learned, but typically relies on explicit task boundaries and fixed parameter budgets. Inspired by the human brain, which balances plasticity and stability through complementary episodic storage and gradual consolidation, we propose UniMem, a self-routing framework for autonomous memory management. UniMem uses learnable routing tokens as memory controllers, enabling adaptive coordination between complementary memory pathways: novel or sparse tasks are retained in an episodic buffer for retrieval-augmented execution, while recurring and reliable patterns are consolidated into expandable parametric memory. By decoupling task identification from task execution with routing tokens and parametric memory blocks, UniMem expands memory on demand without task labels during deployment or uncontrolled parameter growth. Experiments on long-horizon streaming task sequences show that UniMem consistently outperforms baselines while maintaining execution fidelity, achieving an average gain of 4.0 EM points across three backbone models.

- **动机**：受认知科学中的**互补学习系统理论**（CLS, Complementary Learning Systems）启发——人类大脑通过海马体（快速情景存储）和新皮层（渐进巩固至长时知识）的互补协作解决这一矛盾。
- **整体含义**：提出 UniMem，一个统一的自路由记忆框架，旨在让 LLM 代理在开放世界任务流中自主协调情景检索与选择性参数巩固，无需任务标签即可按需扩展记忆。

## 2. 方法论：核心思想、关键技术细节、算法流程

### 核心思想
UniMem 通过**可学习的路由令牌**（routing tokens）作为记忆控制器，将输入查询引导至两条互补记忆通路：
- **情景通路**（Episodic Buffer）：处理新颖或稀疏任务，采用检索增强生成（RAG）方式执行。
- **参数通路**（Parametric Memory）：处理重复且可靠的任务模式，调用关联的**程序性 KV 记忆**（Procedural KV Memory）进行参数化执行。

### 关键技术细节

#### 2.1 自路由记忆架构
- **路由令牌矩阵** \(E = [e_1, \dots, e_K, e_{\text{NOVEL}}]\)：
  - 已知任务令牌 \(e_k\) 与一个参数记忆单元 \(u_k = (e_k, P_k)\) 绑定，\(P_k\) 为可插拔的程序性 KV 记忆（层间可学习键值对）。
  - 新颖哨兵令牌 \(e_{\text{NOVEL}}\) 捕获不匹配已知任务的查询，路由至情景缓冲区。
- **路由决策**：基于最终隐藏状态 \(h_q\) 计算分布，激活已知单元的条件：
  - \(p_{\text{top-known}} > p_{\text{novel}}\) 且 \(p_{\text{top-known}} \ge \tau_{\text{route}}\)（\(\tau_{\text{route}}=0.7\)）。
  - 否则路由至新颖通路。
- **参数执行**：选定的程序性 KV 记忆通过可学习门控 \(g^{(l)}\) 注入冻结骨干网络的自注意力输出：
  \[
  H_{\text{out}}^{(l)} = H_{\text{orig}}^{(l)} + g^{(l)} \cdot \text{CrossAttn}(Q^{(l)}, K_k^{(l)}, V_k^{(l)})
  \]
- **解耦优化目标**：
  - 路由损失 \(\mathcal{L}_{\text{route}}\) 仅更新路由令牌。
  - 执行损失 \(\mathcal{L}_{\text{exec}}^{(k)}\) 仅更新选中任务的参数记忆块和门控。

#### 2.2 增量记忆扩展（两阶段生命周期）
- **阶段 I：路由空间初始化与新颖校准**
  - 为初始已知任务集学习路由令牌。
  - 计算平均路由范数 \(\bar{r}\)，初始化 \(e_{\text{NOVEL}}\) 靠近已知令牌质心（加高斯噪声并归一化）。
  - 保留部分任务作为伪未见过任务，用 \((K+1)\) 路交叉熵训练路由层，教会它区分已知与新颖。
- **阶段 II：自主任务发现与参数巩固**
  - 新颖路由的查询存入情景缓冲区，暂时由 RAG 支持。
  - 缓冲区满时触发无监督聚类：
    - 使用 **NCD**（归一化压缩距离）度量过程相似性。
    - 应用 **HDBSCAN** 发现密度簇（无需预设簇数）。
    - 通过嵌入质心离群过滤和 NCD 内聚检查（阈值 \(\tau_{\text{cluster}}=0.85\)）筛选高质量簇。
  - 每个合格簇分配新路由令牌 \(e_{\text{new}}\) 和参数记忆块 \(P_{\text{new}}\)，在簇样本上通过 SFT 联合优化。
  - 不合格簇保留在缓冲区，继续由 RAG 服务。

## 3. 实验设计

### 数据集与场景
- **Super-Natural Instructions (SNI)**：构建 10、50、100 任务流，模拟长尾分布（10% 任务仅 10 个训练样本）。评估生成能力，指标为 **Exact Match (EM)** 和 **ROUGE-L**。
- **SuperGLUE Mixed Stream**：混合 BoolQ、CB、RTE、COPA、MultiRC、WiC 六个推理任务，边界无关流式呈现。指标为 **Average Accuracy (A)**。

### Backbone 模型
| 实验 | 模型 |
|------|------|
| SNI | LLaMA-3.2-3B, LLaMA-3.1-8B, Qwen3-8B |
| SuperGLUE | LLaMA-1B-Instruct, LLaMA-3B-Instruct |

### 对比基线
- **Base (Zero-Shot)**：原始预训练模型。
- **Standard RAG**：检索 top-3 近邻示例作为上下文。
- **Replay LoRA**：LoRA 微调 + 10% 重放先前样本。
- **Adapted TOKMEM**：单令牌程序记忆，与 UniMem 相同的路由/缓冲/巩固流程，但无额外参数记忆块。

### 实验结果概要
- **SNI**：UniMem 在所有 backbone 和任务规模上平均 EM 最优，比 TOKMEM 高 7.02 EM（LLaMA-3.2-3B/100任务），比 Replay LoRA 高 2.44 EM（LLaMA-3.1-8B）。路由准确率保持在 75-91% 以上。
- **SuperGLUE**：UniMem 在 LLaMA-1B 和 LLaMA-3B 上均获最高平均准确率（73.89% 和 85.95%），显著优于 LoRA（64.91%/77.49%）和 TOKMEM（44.27%/78.98%）。

## 6. 主要结论与发现

1. **一致性优势**：UniMem 在所有设置下优于基线，平均 EM 提升约 4.0 点（三个 backbone 均值），且保持执行准确性（任务遗忘少）。
2. **解耦路由与执行有效**：相比单令牌 TOKMEM，分离路由令牌和高容量参数记忆块显著提升复杂任务表现。
3. **门控机制关键**：去除门控导致性能大幅下降（如 LLaMA-3.2-3B 在 10 任务上 EM 从 51.60% 降至 35.80%），证明需学习适量注入程序性记忆。
4. **情景缓冲区作用**：为稀疏/长尾任务提供非参数覆盖，避免过早参数分配。
5. **记忆自主扩展合理**：系统根据任务结构（而非每新任务固定分配）创建参数单元，整体动态合理（16k 样本中发现 76 个新簇，合并一些相似任务，10 个稀疏任务留在缓冲区）。
