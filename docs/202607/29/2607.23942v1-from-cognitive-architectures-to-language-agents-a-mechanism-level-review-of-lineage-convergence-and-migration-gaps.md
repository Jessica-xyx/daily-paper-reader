## 摘要
记忆、规划、反思与工具使用常常被作为特征标签进行比较，这掩盖了决定智能体实际运行方式的控制语义。本综述连接了十个历史认知架构、八个语言智能体运行时家族以及四十二个聚焦机制的现代系统。我们通过状态、控制、转换、持久性、失败、学习与资源治理对每个机制进行重构，然后分别从证据关联（E1-E4）和迁移深度（D0-D4）进行编码。由此呈现的图景是不均匀的。现代智能体已经实现了自适应记忆、失败恢复、动态团队选择、工作流搜索、技能归纳、资源调度以及不确定性条件下行动的操作化，尽管这通常是通过独立趋同而非有据可查的继承实现的。最显著的剩余机遇在于机制之间的耦合。最近基准筛查填补了一个提议的缺口：GraSP已经结合了校准的多技能选择、类型化编译、验证、有界修复以及重新规划或ReAct回退。五个残留的束集仍然存在：带有延迟与行动效用的激活；带有孤立子状态与解决编译的类型化僵局；带有广播与接纳学习的有界内容竞争；带有重新考虑与实时方法权威的持久意图；以及带有资源分配、中断与停止的不确定性。我们贡献了一个独特的机制目录、一个可审计的证据深度框架，以及一个可证伪的议程，用于测试这些束集作为可组合运行时不变性。

## Abstract
Memory, planning, reflection, and tool use are often compared as feature labels, obscuring the control semantics that determine how an agent actually runs. This review connects ten historical cognitive architectures, eight language-agent runtime families, and forty-two mechanism-focused modern systems. We reconstruct each mechanism through state, control, transition, persistence, failure, learning, and resource governance, then code evidence relation (E1-E4) separately from migration depth (D0-D4). The resulting landscape is uneven. Modern agents have operationalized substantial parts of adaptive memory, failure recovery, dynamic team selection, workflow search, skill induction, resource scheduling, and uncertainty-conditioned action, although often through independent convergence rather than documented inheritance. The strongest remaining opportunities lie in couplings among mechanisms. Closest-baseline screening closes one proposed gap: GraSP already combines calibrated multi-skill selection, typed compilation, verification, bounded repair, and replanning or ReAct fallback. Five residual bundles remain: activation with latency and action utility; typed impasse with isolated substates and resolution compilation; bounded content competition with broadcast and admission learning; persistent intention with reconsideration and live method authority; and uncertainty with resource allocation, interruption, and stopping. We contribute a distinctive-mechanism catalog, an auditable evidence-depth framework, and a falsifiable agenda for testing these bundles as composable runtime invariants.

## 2. 论文提出的方法论

### 核心思想
通过**七字段机制表示**对每个机制进行结构化重构，并引入**双轴独立编码框架**（证据关系与迁移深度），再通过**残差提取规则**识别未迁移的控制耦合。

### 关键技术细节

#### 七字段机制表示 ⟨S, C, T, P, F, L, R⟩
| 字段 | 含义 |
|------|------|
| S | 操作状态基片（operative state substrate） |
| C | 控制焦点（control locus） |
| T | 转换触发器（transition trigger） |
| P | 持久性边界（persistence boundary） |
| F | 失败语义（failure semantics） |
| L | 学习算子（learning operator） |
| R | 资源或治理策略（resource/governance policy） |

#### 证据关系轴（E1-E4）
- **E1**: 有据可查的谱系（modern source明确引用历史架构）
- **E2**: 结构迁移（实现了类似的状态和对应控制/转换/学习边缘）
- **E3**: 功能近似（解决相同控制问题，但内部组织不同）
- **E4**: 结构趋同（节点-边缘组织相似但未发现迁移证据）

#### 迁移深度轴（D0-D4）
- **D0**: 概念相似，无可调用接口或持久机制状态
- **D1**: 接口对应（运行时暴露可调用操作，但无映射状态-转换组织）
- **D2**: 状态/组件结构明确，但触发器未自主执行历史控制边缘
- **D3**: 运行时控制律（显式触发器自主执行映射控制动作并改变状态）
- **D4**: 自适应控制律（经验更新未来调用、选择或控制策略）

#### 残留束生成规则
1. 每个映射行贡献其最小的缺失状态、触发器、权威、转换或学习不变性
2. 原子残留仅在共享运行时插入边界且一个原子为另一个提供所需状态/权威时才合并
3. 当具有独立触发器、基线或证伪器时拆分
4. 仅当每个组成边缘都有已审查的现代先例、耦合不在冻结语料库内、且组合允许具体插入点和拒绝条件时才保留

### 算法流程（文字说明）
1. **架构重建**：从历史认知架构提取⟨S, C, T, P, F, L, R⟩
2. **现代系统分析**：从运行时家族和机制聚焦系统提取七字段
3. **对应映射**：建立历史机制→现代实现的联系，识别匹配状态/触发器/控制边缘
4. **证据与深度编码**：独立分配E码和D码
5. **残留提取**：从每个映射的最小缺失不变性生成原子残留
6. **束合并/拆分**：应用合并/拆分规则生成候选束
7. **最近基线筛选**：用现有系统测试候选束是否已被实现
8. **生成干预议程**：保留残留束并指定插入点、基线和证伪条件

|--------|------|----------------|
| **B1** | 激活-延迟-效用 | 统一的访问时间、记忆值、行动效用耦合律 |
| **B2** | 类型化僵局-子状态-编译 | 隔离子状态、类型化返回、解析编译 |
| **B3** | 内容竞争-工作空间-广播学习 | 基于内容的接纳学习与广播周期集成 |
| **B4** | 意图-重新考虑-方法权威 | 可移植的承诺生命周期（继续、重新考虑、委托、暂停、废弃、方法切换权威） |
| **B6** | 不确定性-资源-中断-停止 | 经校准的不确定性跨阶段传播，分配所有资源类型并授权认知边界的中断 |

#### 迁移停滞的三大结构障碍
1. **控制所有权碎片化**：状态、上下文、工具、评估、记忆、生命周期钩子分割在独立设计接口之间
2. **模型生成表示语义不稳定**：自然语言摘要、计划、反思的含义依赖后续模型调用，显式字段不保证可执行不变性
3. **当前评估偏向局部能力而非跨组件不变性**：组合运行时需测量因果状态完整性、中断、重复失败、漂移、迁移和成本

## 7. 优点

### 方法论亮点
- **机制级分析**：超越功能标签，深入控制语义，提供可测试的操作性假设
- **双轴编码框架**：E码分离“怎样关联”与D码分离“实现多深”，避免历史谱系与功能性能的混淆
- **透明化程序**：搜索模板、排除规则、编码规则、声称包均文档化，结果可审计
- **残留束生成**：基于原子缺失不变性，非直接选择架构名称，减少主观偏见
- **最接近基线筛选**：用现有D3/D4系统测试候选束，提高研究效率

### 分析深度
- **完整历史提取**：10个架构的7字段重建，揭示各核心控制问题
- **现代系统分类**：区分通用运行时（可插入点）与机制聚焦系统（深度先例）
- **缺失不变性明确**：每个映射都识别保存和缺失不变性，指导未来研究

### 实践价值
- 提供可移植的合成运行时设计
- 明确依赖关系和实施顺序
- 每个残留束都有具体插入点、基线、证伪条件，可直接转化为预注册实验

## 8. 不足与局限

### 语料库相关局限
- **有界且快速变化**：冻结于2026年7月26日，后续系统可能改变D级或打开新的残留
- **文献来源不均**：arXiv论文与官方仓库审查状态不一；仓库证明建立实现表面，但机制和性能声称依赖对应论文
- **无系统搜索召回率**：未作PRISMA完整性声称；不推断流行率

### 编码相关局限
- **无独立间站可靠性**：当前论文不声称间站可靠性；预备第二审查包但尚未产生争议记录
- **编码主观性**：七字段抽取、声称包、排除测试使判断可检查，但不能替代独立编码
- **分数暂定性**：所有D3/D4结果暂定，需等待独立双编码完成

### 分析范围局限
- **无因果性能声称**：仅建立可行性和架构假设，不声称历史机制比现代方案更优
- **无跨域因果价值证明**：现有系统在其自身设置报告局部增益，不证明五个残留束在组合时提高可靠性或效率
- **领域用途区别**：认知架构寻求稳定认知解释，现代智能体优化特定任务组合；相似行为可源于不同过程

### 威胁有效性
- **历史与现代目的不同**：为认知建模有用的机制可能增加不必要工程开销
- **控制干预测试标准苛刻**：需要保持模型、提示、工具、环境和任务预算固定，内部状态仪器化，至少三种消融（去除新状态对象、去除控制边缘、去除学习更新）
- **实际实施障碍**：五组残留束要求组合运行时，在现有碎片化系统中实现具有挑战性

### 可复制性问题
- 部分系统只有研究原型，未发布工程边界
- 代码仓库仅用于建立执行接口和审查版本；科学主张来自主要论文
